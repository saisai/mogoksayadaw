မွန္းေျခေပါက္အလုပ္ အပိုင္း(၂)
(၁၀-၃-၆၁)

နိဗၺာန္၏အရသာ အပိုင္း (၂)

စာအုပ္ေခါင္းစဥ္ = နိဗၺာန္၏အရသာ
အသံဖိုင္ေခါင္းစဥ္= နိေရာဓသစၥာအနက္မွဝိေဝကေ႒ာတရားေတာ္(၁၅.၁၂.၁၉၅၇)

ေက်းဇူးေတာ္ရွင္အဂၢမဟာပ႑ိတ
မိုးကုတ္ဆရာေတာ္ဘုရားႀကီး ေဟာၾကားေတာ္မူေသာ
“နိဗၺာန္၏ အရသာ”
(၁၆၊ ၁၂၊ ၅၇)

ျဖစ္ပ်က္မရွိေတာ့ ဘာရွိမွာတုံးလို႔ေမးရလိမ့္မယ္၊ ဒကာ ဒကာမတို႔ ျဖစ္ပ်က္ဆိုတာ အရႈပ္ေတာ္ပုံလို႔မွတ္ထားရမယ္၊ ျဖစ္ ပ်က္ဟာဘာပါလိမ့္၊ (အရႈပ္ေတာ္ပုံပါဘုရား) အရႈပ္ေတာ္ပုံပဲ၊

ခႏၶာကိုယ္စိုက္ၾကည့္ပါ။

ဒကာ ဒကာမတို႔ သုံးဆယ့္တစ္ဘုံကို စိုက္ၾကည့္လိုက္၊ ေမြးလိုက္၊ ေသလိုက္၊ ေမြးလိုက္၊ ေသလိုက္မရွိဘူးလား (ရွိပါတယ္ဘုရား) မိမိခႏၶာကိုယ္ကို ဉာဏ္မ်က္လုံး၊ မွန္ေျပာင္းနဲ႔ လွည့္ၾကည့္လိုက္ျပန္ေတာ့လဲ ဘာေတြေတြ႕မယ္ထင္တုံး... (ျဖစ္ပ်က္ေတြ႕မယ္ဘုရား)၊ ျဖစ္ပ်က္ခ်ည္းလွည့္ေနမယ္ဆိုတာ၊ ဦးဘၾကည္တို႔ စဥ္းစားၾကည့္ၾကေပါ့၊ ဒို႔ခိုင္းတာအရႈပ္ေတြ အၾကည့္ခိုင္းတာ မလာေပဘူးလား (လာပါတယ္ဘုရား)။
ေကာင္းၿပီ ဒါျဖင့္ ရႈပ္တာအၾကည့္ခိုင္းတာသည္ ဒကာ ဒကာမတို႔ ဘာေၾကာင့္ ဘုရားက ဒီဉာဏ္စဥ္ အတက္ခိုင္းရပါ လိမ့္မတုံးလို႔ ေမးခြန္းထုတ္ခဲ့သည္ရွိေသာ္ ရႈပ္တာသိမွ မင္းတို႔ရွင္း တာႀကိဳက္မယ္၊ ရွင္းတာႀကိဳက္တဲ့စိတ္ အမွန္ေပၚမယ္ဆိုၿပီး ေရွးဦးစြာ ရႈပ္တာျပရတယ္၊ ရွင္းၿပီလား ... (မွန္ပါဘုရား) ရႈပ္တာ ဘယ့္ႏွယ့္ေၾကာင့္ ျပရပါလိမ့္... (ရွင္းတာကိုသိေအာင္ လို႔ပါဘုရား)။
ဒီခႏၶာႀကီးဟာ ခိုင္တယ္၊ ၿမဲတယ္၊ တည္တံ့တယ္လို႔ ထင္ေနေတာ့ ရႈပ္တာေတြေတြ႕ေသးရဲ႕ လား ... (မေတြ႕ပါ ဘုရား)၊ မေတြ႕ေတာ့ ခင္ဗ်ားတို႔ ဒီအရႈပ္မွမသိတဲ့ပုဂၢိဳလ္ဟာ အရွင္း နိဗၺာန္ကို ဘယ္လိုအာ႐ုံျပဳမလဲ ... (မျပဳႏိုင္ပါဘုရား) ႀကိဳက္လဲ မႀကိဳက္ႏိုင္၊ အာ႐ုံလဲမျပဳႏိုင္၊ ဒါျဖင့္ နိဗၺာန္ဆိုတာ ဘယ္သူမွ အိပ္မက္ မမက္ဖူးဘူး၊ ယုံၿပီလား ... (ယုံပါၿပီ ဘုရား)။
နိဗၺာန္ကို ဒကာ ဒကာမတို႔ အိပ္မက္ မက္ဖူးၾကရဲ႕လား (မမက္ဖူးပါဘုရား) ဒါျဖင့္ နိဗၺာန္သည္ အိပ္မက္မွ မမက္ဖူးဘူး ဆိုတာ မေသခ်ာဘူးလား ... (ေသခ်ာပါတယ္) အဲဒီေတာ့ နိဗၺာန္ကို မဆိုထားပါနဲ႔၊ ကိုယ္ရႈပ္ေနတဲ့ အရႈပ္ေတာင္မွ ရႈပ္တယ္လို႔ သိတဲ့ဉာဏ္ေပၚဖူးရဲ႕ လားလို႔ေမးအုံး။ ခႏၶာထဲဘာေတြရႈပ္ေန လဲ (ျဖစ္ပ်က္ပါဘုရား)။ ကိုယ့္ခႏၶာ၊ ႐ုပ္ဘက္က ျဖစ္ပ်က္ေကာ ရပ္စဲရဲ႕ လား (မရပ္စဲပါဘုရား)။ နာမ္ဘက္က ျဖစ္ပ်က္ကေကာ (မရပ္စဲပါဘုရား)၊ မရပ္စဲေတာ့ အဲဒီ ရႈပ္ယွက္ခတ္တာကို ခင္ဗ်ား တို႔ကလဲ မျမင္ဘူး ... (မွန္ပါ့ဘုရား)။ ဟို - အရွင္းဆိုတဲ့ နိဗၺာန္အသာထားစမ္းပါအုံး၊ ကိုထြန္းဦးရာ ရႈပ္ယွက္ခတ္တာကို ဘယ့္ႏွယ္ေနတုံး ... (မျမင္ပါဘုရား)။
ဒါျဖင့္ ဘာအျမင္ျပမွ နိဗၺာန္ရွင္းမတဲ့တုံး ....... (ရႈပ္ယွက္ ခတ္တာျပမွပါဘုရား)။ ရႈပ္ယွက္ခတ္တာျပမွ ရွင္းတာကို၊ ခင္ဗ်ား တို႔ ျမင္ရေတာ့မယ္ (မွန္ပါ့ဘုရား)၊ ရႈပ္ယွက္ခတ္တာကို ျမင္ရတဲ့ အခါက်လို႔ရွိရင္၊ ရႈပ္ယွက္ခတ္တာေကာ၊ မႀကိဳက္ဘူးဆိုတဲ့ မဂ္ေပၚ ရမယ္... မွန္ပါ့ဘုရား။
ကဲ ဒါျဖင့္ အေသအခ်ာမွတ္ပါ၊ သုခေဝဒနာရႈေတာ့ ဘာ ေတြ႕ၾကတုံး ... (ျဖစ္ပ်က္ပါဘုရား)၊ အဲဒါရႈတဲ့ပုဂၢိဳလ္မွ ေတြ႕ မယ္ေနာ္၊ မရႈတဲ့ပုဂၢိဳလ္မွာ မေတြ႕ပါဘူး၊ မရႈတဲ့ ပုဂၢိဳလ္မွာ ရွိတာ လဲ မသိဘူး၊ မရွိတာလဲ မသိဘူး၊ အဲဒီပုဂၢိဳလ္ကို အ႐ူးလို႔မွတ္ပါ.. (မွန္ပါ့ဘုရား)၊ မရႈေတာ့ ရွိမွန္းေကာသိရဲ႕လား (မသိပါဘုရား)၊ မရွိမွန္းေကာ (မသိပါဘုရား) ဒါျဖင့္ ရွိ-မရွိမွ မသိတဲ့ပုဂၢိဳလ္၊ ဦးခ်စ္ခတို႔ ဘယ္အထဲသြင္းမွာလဲ ... (အ႐ူးထဲပါဘုရား)။
အဲ အဝိဇၨာ အုပ္ခ်ဳပ္ေနေတာ့ ေမာဟုမၼတၱကဆိုတဲ့ ေမာဟတို႔သည္ ရွိတာလဲ မသိဘူး၊ မရွိတာေကာ ... (မသိပါ ဘုရား)။ မသိတာကို ဒကာ ဒကာမေတြသည္ ေမာဟုမၼတၱက ဆိုတဲ့အတိုင္း ေမာဟ႐ူး၊ ႐ူးေနတယ္လို႔ ဦးဝ ဆိုလိုက္စမ္းဗ်ာ၊ (မွန္ပါ့ဘုရား) ဦးခင္ေမာင္ မဆိုထိုက္ဘူးလား ... (ဆိုထိုက္ ပါတယ္ဘုရား)။ ဘာျပဳလို႔တုံးလို႔ေမးတဲ့အခါက်ေတာ့ သူမ်ား သႏၲာန္မွာရွိတာ၊ မရွိတာ အပထား ကိုယ့္သႏၲာန္မွာ ရွိ၊ မရွိ ခဏခဏ ရွိ၊ ရွိၿပီး၊ ေပ်ာက္ေပ်ာက္သြားတာေတြ၊ ခဏခဏ မေပၚဘူးလား ... (ေပၚပါတယ္ဘုရား)။
သူတို႔တေတြ ထိုကဲ့သို႔ ေပၚျငားေသာ္လည္း ဦးဘအုန္း က မသိလိုက္ဘူးလားဆိုေတာ့၊ ကိုက်င္တို႔သည္ သူတပါးသႏၲာန္ ကို မရွိတာ - မသိတာ ကိစၥမရွိပါဘူး၊ (တင္ပါ့ဘုရား) ဦးခ်စ္ခေရ ကိုယ့္သႏၲာန္မွာျဖစ္ၿပီး မရွိတာေလးေတြ မသိလိုက္ေတာ့ ေၾသာ္ ငါ အ႐ူးထေနတဲ့အခ်ိန္နဲ႔ ႀကဳံလို႔ပဲလို႔သာ ဆုံးျဖတ္ခ်က္ခ်ပါ၊ မခ် ထိုက္ဘူးလား... (ခ်ထိုက္ပါတယ္ဘုရား)။
ေမာဟုမၼတၱက ဗ်၊ ေမာဟဆိုတာ အ႐ူး၊ မသိတာဟုတ္ လား၊ မသိ႐ူး-႐ူးေနတဲ့အတြက္ ကိုယ့္သႏၲာန္မွာ ျဖစ္ေပၚသြားတဲ့ သုခေဝဒနာလဲ မသိလိုက္၊ ဒုကၡေဝဒနာေကာ ..(မသိလိုက္ ပါဘုရား)။
ဦးခ်စ္ခ၊ မသိလိုက္တာမဆိုးဘူးလား ... (ဆိုးပါတယ္ ဘုရား) ခင္ဗ်ားတို႔က မသိလိုက္ ျငားေသာ္လဲ မသိသလိုေတာ့ ျဖင့္ အႏွိပ္စက္ခံရမယ္...(မွန္လွပါဘုရား)။ မခံရေပဘူးလား ...(ခံရပါတယ္ဘုရား)၊ ဦးဘၾကည္ ခံရလိမ့္မယ္ (မွန္ပါ့)။ ဘယ္လိုခံရမတုံးဆိုေတာ့၊ ခင္ဗ်ားတို႔က မသိလိုက္ေတာ့ ေဝဒနာ က သူေက်းဇူးျပဳစရာရွိတဲ့ ေက်းဇူးျပဳသြားမယ္ (တင္ပါ့ဘုရား)။
ေဝဒနာပစၥယာတဏွာ ... (တင္ပါ့ဘုရား) ဒီလို ေက်းဇူးျပဳသြားတယ္၊ ခင္ဗ်ားတို႔က မသိလိုက္ဘူး၊ သူကေတာ့ တဏွာျဖစ္ေအာင္ ေက်းဇူးျပဳတယ္, ..(တင္ပါ့) တဏွာျဖစ္တာ လဲ မသိလိုက္ျပန္ဘူးဆိုေတာ့၊ တဏွာပစၥယာ ဥပါဒါနံ၊ ဥပါဒါန္ ျဖစ္တာလဲမသိလိုက္ျပန္ေတာ့ ဘဝ၊ ဘဝ ပစၥယာဇာတိက်ေအာင္ ခင္ဗ်ားတို႔ေတာ့ မသိလို႔ လုပ္မိေပမယ့္လဲ၊ မသိေတာ့၊ မသိလိုက္ မသိဘာသာ ေနျငားေသာ္လည္း၊ အျပစ္မလြတ္ဘူး... (မွန္ပါ့ ဘုရား)။ ဦးဘၾကည္ လြတ္ပါ့မလား ... (မလြတ္ပါဘုရား)။
ဒကာ ဒကာမေတြ ဘယ္လိုဆိုၾကမတုံး ... (မလြတ္ပါ ဘုရား)။ မသိလိုက္လို႔ ရွိရင္၊ အျပစ္လြတ္ပါ့မလား...(မလြတ္ပါဘုရား)။ မလြတ္တာ ဘာျပဳလို႔တုံးဆိုေတာ့ ပဋိစၥသမုပၸါဒ္ ေဒသနာေတာ္ဆိုတာက ဘုရားနဲ႔မဆိုင္ဘူး၊ (မွန္ပါ့)၊ ေနာက္ ကေကာ ဒကာမေတြ၊ ဘုရားနဲ႔ မဆိုင္ဘူး၊ သူ႔သေဘာအတိုင္း သူေက်းဇူးျပဳတာ...(တင္ပါ့ဘုရား)။ ဘုရားက မျပနဲ႔ဆိုလို႔လဲ မရဘူး၊ ျပဳပါဆိုၿပီး ေတာင္းပန္လို႔လဲမရဘူး၊ သူ႔သေဘာနဲ႔ ဓမၼနိယာမ သေဘာျဖစ္ေနတာ ... (မွန္ပါ့ဘုရား)၊ ဦးဘအုန္း
ေက်နပ္ၿပီလား ... (ေက်နပ္ပါတယ္ဘုရား)။ သင္ ဘယ္သေဘာပါလိမ့္... (ဓမၼနိယာမပါဘုရား)။ ဓမၼနိယာမသေဘာဆိုေတာ့ အဲဒီဓမၼနိယာမကို ဘုရားပြင့္လာက တည္းက ဖ်က္တယ္၊ ရွင္းၿပီလား... (မွန္ပါ့ဘုရား)။
အဲဒီေတာ့ ဓမၼနိယာမ ဖ်က္တယ္ဆိုေတာ့ ပဋိစၥသမုပၸါဒ္ ဆိုတဲ့ ဥစၥာက ဝိုင္းတတ္တယ္၊ လည္တတ္တယ္ ဆိုတဲ့တရားကို ငါဘုရားပြင့္တဲ့အခါက်ေတာ့ မင္းတို႔သည္ အလည္ရပ္ေအာင္ ငါႀကိဳးစားေပးပါ့မယ္ ဆိုၿပီးသကာလ ဝိပႆနာဉာဏ္ကိုေဟာ တယ္၊ ရွင္းၾကၿပီလား ... (ရွင္းပါၿပီဘုရား)။
ဘာလုပ္ရမလဲ ... (ဝိပႆနာဉာဏ္ပါဘုရား) ဝိပႆနာဉာဏ္လုပ္ေတာ့ မရွိတာကဘာတုံး၊ အနိစၥ၊ မရွိမွန္ သိတာက - မဂၢ။ မဂၢဆိုေတာ့ကို ... ပဋိစၥသမုပၸါဒ္ ျပတ္ထြက္သြားၿပီ၊ ျပတ္ကဲ့လား ... ဦးဘအုန္း ... (ျပတ္ပါ တယ္ဘုရား)။
ဘယ္ေနရာက စျပတ္သြားပါလိမ့္၊ တဏွာနိေရာေဓာ တဏွာမလာဘဲနဲ႔ ျပတ္တယ္၊ မဂ္ကျဖတ္လိုက္တာ၊ ဒကာ ဒကာမေတြ ဘယ္သူကျဖတ္လိုက္တယ္...(မဂ္က ျဖတ္တယ္ ဘုရား)၊ မဂ္ကျဖတ္လိုက္ေတာ့ တဏွာလာေသးရဲ႕ လား၊ (မလာ ပါဘုရား)။ တဏွာက ေက်းဇူးျပဳမွေပၚမဲ့၊ ဥပါဒါန္ဆိုတာ၊ တဏွာ မေပၚရလို႔ပဲ၊ ခ်ဳပ္ၿငိမ္းတယ္ ... (တင္ပါဘုရား)။ ဟိုဘက္ ဘဝေတြဆိုတာ လာႏိုင္ေသးရဲ႕လား ... (မလာႏိုင္ပါဘုရား)။
“ေမြးတာနဲ႔ေသတာအၾကည့္ခိုင္းတာ”
ေဝဒနာေလးေမြးလိုက္၊ ေဝဒနာေလး ေသလိုက္၊ အဲဒါ ကို ဘုန္းႀကီးက အၾကည့္ခိုင္းေနေတာ့ ဉာဏ္မ်က္လုံးထဲမွာ၊ ဪ ... ဒို႔အၾကည့္ခိုင္းတာသည္ ဘာမ်ားအၾကည့္ခိုင္းတာ တုံး...အေသရႈပ္ယွက္ခတ္ေနတာ အၾကည့္ခိုင္းတာ။
ဘာ အၾကည့္ခိုင္းတာတုံး...(အေသရႈပ္ယွက္ခတ္ေနတာပါဘုရား) ရိပ္မိၾကပလား ... (ရိပ္မိပါၿပီဘုရား)။
ဝိပႆနာရႈဆိုတာ၊ ဒကာ ဒကာမတို႔ အေသရႈပ္ယွက္ ခတ္ေနတာ အထပ္ထပ္ အေသေတြရႈပ္ယွက္ခတ္ေနတာကို၊ အရႈခိုင္းတာ၊ ရွင္းၿပီလား ... (ရွင္းပါၿပီဘုရား)၊ ၾကည့္ျဖစ္
ေအာင္ၾကည့္စမ္းပါ။
ဒီကေန႔တရားမွာ ခင္ဗ်ားတို႔ ဝိေဝကေ႒ာေဟာဖို႔ရာ ဝိေဝက႒ကို ဒီကစၿပီး မေဟာလို႔ရွိရင္ ဆိတ္ၿငိမ္တာကို မျပႏိုင္မွာ ေၾကာင့္ မဆိတ္ၿငိမ္တာကိုအရင္ျပရတယ္...(တင္ပါ့ဘုရား)။ မေန႔ကတရားနဲ႔တျခားစီေနာ္...(မွန္ပါ့ဘုရား)၊ မဆိတ္ၿငိမ္တာ ျပေနတယ္... (တင္ပါ့ဘုရား)၊ မဆိတ္ၿငိမ္တာဆိုေတာ့ သုခ ေဝဒနာ ၾကည့္လိုက္ျပန္ေရာ ရႈပ္ယွက္ခတ္ေသေနတာပဲ။ ဒုကၡ ေဝဒနာေလးေပၚလို႔ ၾကည့္လိုက္ျပန္ေရာ ရႈပ္ယွက္ခတ္ေသေန တာပဲ။
ဒုကၡေဝဒနာလဲ တစ္ခုတည္းေသတာမဟုတ္ဘူး၊ သူနဲ႔ သဟဇာတ ေတြပါေရာေသၾကတာ... (မွန္ပါ့ဘုရား)၊ ရႈပ္ယွက္ ခတ္မေနဘူးလား ... (တင္ပါ့ဘုရား)၊ ေကာင္းၿပီ၊ ဥေပကၡာ ေဝဒနာ ၾကည့္လိုက္စမ္းပါ၊ ဦးဘၾကည္ရာ၊ ဘယ္လိုေနတုံး... (ရႈပ္ယွက္ခတ္ေနတာပါဘုရား)။

ယထာဘူတဉာဏ္၊ နိဗၺႏၵဉာဏ္

ဪ ... ရႈပ္ယွက္ခတ္ ေသျပန္တဲ့အခါက်ေတာ့၊ ေသတာေတြျမင္၊ ေမြးတာေတြျမင္၊ ဒါေတြခ်ည္းျမင္ေနေတာ့ ခင္ဗ်ားတို႔ ဉာဏ္သည္ပင္လွ်င္ ေျပာင္းေနတယ္ မေျပာင္းေပ ဘူးလား ...(ေျပာင္းပါတယ္ဘုရား)။
ဒီရႈပ္ယွက္ခတ္တာခ်ည္း ၾကည့္ေနရတာျဖင့္ကြာ ၾကည့္ ကိုမၾကည့္ခ်င္ဘူးလို႔ ေျပာင္းမလား၊ မေျပာင္းဘူးလား (ေျပာင္း မွာပါဘုရား) ၾကည့္ကိုမၾကည့္ခ်င္ေတာ့ဘူးဆိုေတာ့၊ သူတို႔ရွိ လ်က္သားနဲ႔ကို၊ မၾကည့္ခ်င္ပဲ မေနရပဲနဲ႔ ၾကည့္ေနရေတာ့ မၾကည့္ ခ်င္ျမင္လ်က္သားဆိုတဲ့အတိုင္း မုန္းလ်က္နဲ႔ ေပၾကည့္ေနရတယ္။ သေဘာၾကၿပီလား ...(က်ပါၿပီဘုရား)။
အဲဒီေတာ့ ခုနက ရႈပ္ယွက္ခတ္ျမင္တာက ယထာဘူတ ဉာဏ္ ရႈပ္ယွက္ခတ္တာေတြ မၾကည့္ခ်င္ပဲနဲ႔ ေပၾကည့္ေနရတာ ကေတာ့ ဘာတုံး၊ နိဗၺိႏၵဉာဏ္၊ ရွင္းၿပီလား ... (ရွင္းပါတယ္ ဘုရား)။
ရႈပ္ယွက္ခတ္တာေတြ၊ ရႈပ္ယွက္ခတ္တယ္လို႔ သိေနတဲ့ ဉာဏ္က၊ ဘာဉာဏ္တုံး ...(ယထာဘူတဉာဏ္)၊ ယထာဘူတ ဉာဏ္က မဂၢင္ငါးပါး၊ ရႈပ္ယွက္ခတ္တာကို ၾကည့္ေနၾက ျဖစ္ေန ေတာ့၊ တစ္ကိုယ္လုံး ဉာဏ္နဲ႔ စိုက္ၾကည့္လိုက္ေတာ့ ျဖစ္ပ်က္နဲ႔ ဉာဏ္ဟာ ခြဲလို႔ မရေတာ့ဘူး။
ထိုကဲ့သို႔ ျဖစ္ပ်က္နဲ႔ ဉာဏ္နဲ႔ ခြဲလို႔မရေတာ့၊ ဒကာ ဒကာမေတြက ဪ ... ဒီဝဋ္ဘယ္ေတာ့ ကြၽတ္ပါ့မတုံး ဆို တာေတြဟာ လာမလား၊ မလာဘူးလား ... (လာပါတယ္ ဘုရား)။ ဒါ - ဝိပႆနာအလုပ္သမားမွလာမယ္ေနာ္ ... (မွန္ပါ့ဘုရား)။ ဒါစာေျပာရွိပါေသးတယ္ ... (မွန္ပါ့ဘုရား)။
ဦးခ်စ္ခ ရႈပ္ယွက္ခတ္တာလဲျမင္ရၿပီ၊ ရႈပ္ယွက္ခတ္တာ ေတြက မ်က္စိဝိညာဏ္ေအာက္ကိုပဲ ေရာက္ေနေတာ့ ဦးဘၾကည္ တို႔ ကိုထြန္းဦးတို႔ လြဲလို႔ကိုမရဘူး ... (မွန္ပါ့ဘုရား)၊ ရေသးရဲ႕ လား ... (မရပါဘုရား)၊ လြဲလို႔မရတဲ့ဉာဏ္၊ ဉာဏ္ေခၚၾက မတုံး ... (နိဗၺိႏၵဉာဏ္)။
ကိုင္း ... ဒါျဖင့္ ရႈပ္ယွက္ခတ္တာေတြကို မၾကည့္ ခ်င္ပဲနဲ႔ ၾကည့္ေနရေတာ့ ႐ြံမုန္း လ်က္နဲ႔ ေပၾကည့္ေနရတယ္၊ သေဘာက်ၿပီလား ... (မွန္ပါ့ဘုရား)။ ႐ြံ႕မုန္းလ်က္နဲ႔ ေပၾကည့္ ေနရတာလဲ မိမိ နဂိုကမိမိခႏၶာေပါ့ဗ်ာ ... (မွန္ပါ့ ဘုရား) အခုေတာ့ျဖင့္ မိမိခႏၶာဘာဆိုရတယ္၊ ရႈပ္ယွက္ခတ္ေန တာရယ္၊ မုန္းစရာႀကီးရယ္က မိမိခႏၶာလို႔ မိမိတို႔က ထင္ေတာ့ ထင္ေနတာ၊ ထင္သာထင္ရတယ္၊ မုန္းစရာႀကီးပါလားဆိုတာ၊ ဉာဏ္ေျပာင္း မသြားဘူးလား၊ သြားသလား ... (ေျပာင္းသြားပါတယ္ ဘုရား)။
အဲဒီလိုေျပာင္းသြားေတာ့ နိဗၺႏၵဉာဏ္ထိုးတက္သြား တယ္၊ နိဗၺႏၵဉာဏ္ ထိုးတက္ သြားတဲ့အခါ က်ေတာ့ ဒကာ ဒကာမေတြ ေဝဒနာသုံးပါးကို ၿငီးေငြ႕ေပမယ့္ ဘယ္ေလာက္ပဲၿငီးေငြ႕၊ ၿငီးေငြ႕၊ ၿငီးေငြ႕တာေတြ သန္ေလေလ၊ ေကာင္းေလပဲကြ...လို႔ ဘုရားကေဟာတယ္ ... (မွန္လွပါဘုရား)။
ၿငီးေငြ႕တာ သန္ေလေလ၊ ေကာင္းေလပဲ၊ ၿငီးေငြ႕တာ သန္ရင္ မလိုခ်င္တာျမင္မွာပဲကြ၊ လာမလား၊ မလာဘူး လား... (လာမွာပါဘုရား)၊ ဒီၿငီးေငြ႕တာသန္ရင္ ဘာလာမယ္ထင္ သတုံး... (မလိုခ်င္တာလာမယ္ဘုရား)၊
မလိုခ်င္ တာျမင္မွ။

ဒါျဖင့္ ၿငီးေငြ႕ေပမယ့္လဲ၊ ေပစိုက္ၿပီး ဦးခင္ေမာင္တို႔ ရႈပါ (တင္ပါ့ဘုရား)၊ ဒကာ ဒကာမေတြ ၿငီးေငြ႕ၿပီးေတာ့ ဘာလုပ္ရ မတုံး ... (ေပရႈရမွာပါဘုရား)။ ၿငီးေငြ႕ရင္းနဲ႔ ေပစိုက္ၿပီး သကာလ ရႈၿပီဆိုမွျဖင့္ မိမိခႏၶာလို႔ နဂိုက အထိမ္းအမွတ္ထားတဲ့ ေဝဒနာကၡႏၶာႀကီး၊ ဒကာ ဒကာမေတြက ေၾသာ္...ဒါႀကီးျဖင့္ ကံမေကာင္း၊ အေၾကာင္းမသင့္လို႔ ဘဝသံသရာက မိုက္မႈ၊ မဲမႈ ေတြ အျပစ္သင့္ေနတဲ့ခႏၶာႀကီးလို႔ ဆိုတာ၊ ကိုယ့္ဟာကိုယ္ မလာေပဘူးလား ... (လာပါတယ္ ဘုရား)။

မဂ္ဉာဏ္

ဘဝသံသရာမွာ အျပစ္ႀကီး သင့္ၿပီးသကာလ၊ ဝဋ္ပါေန တဲ့ ဝိပါက ဒုကၡသစၥာပဲ၊ (တင္ပါ့ဘုရား)၊ ဝိပါက အက်ိဳးေပးတယ္၊ (မွန္ပါ့)၊ ခဏခဏ ေမြး၊ ခဏခဏေသေပါ့ဗ်ာ၊ ဒါဘာသစၥာျဖစ္ သြားသတုံး ... (ဝိပါကဒုကၡသစၥာပါဘုရား)။
အင္း ဝိပါက ဒုကၡသစၥာပဲလို႔ သိလိုက္တဲ့အခါက်လို႔ရွိ ရင္ျဖင့္ ဒုကၡသစၥာဟာ၊ ဘယ္ဟာ သုခပါေသးလဲ လို႔ျပန္ေတြး၊ ဘယ္ဟာမွ သုခမပါေတာ့ဘူး၊ ဒုကၡအစစ္ပဲလို႔ ဆုံးျဖတ္ခ်က္ခ် တဲ့အခ်ိန္မွာ ဖ်ပ္ဆို သူခ်ဳပ္သြားတယ္၊ ရွင္းၾကၿပီလား ... (ရွင္းပါၿပီဘုရား)။
ဒုကၡအစစ္ပဲလို႔ ဆုံးျဖတ္ခ်က္ခ်ေတာ့ ေရွးကျဖစ္ပ်က္ ေတြ ေတြ႕ေသးရဲ႕ လား ..(မေတြ႕ပါဘုရား)၊ မေတြ႕ေတာ့ ဒီမွာ ျဖစ္ပ်က္မရွိတာဘဲ က်န္ရစ္ေတာ့တယ္၊ ဘာက်န္ရစ္တုံး... (ျဖစ္ပ်က္မရွိတာက်န္ရစ္တယ္ဘုရား)၊ ျဖစ္ပ်က္မရွိတာ၊ ခုနက ၾကည့္တာ ရႈပ္ယွက္ခတ္ေသတာေတြ၊ အခုေတာ့ ရႈပ္ယွက္ခတ္ ေသတာမရွိေတာ့ ေသပြဲကင္းတာ ဒီေနရာကိုးလို႔ လာမလား၊ မလာဘူးလား ...(လာပါတယ္ဘုရား)။
ကိုင္း... ဒကာ ဒကာမတို႔ ခုနက ရႈပ္ယွက္ခတ္တာ ေတြကို၊ ဒုကၡအစစ္ပဲလို႔ သုခ-နဲနဲမွမပါ၊ ပါဘူးလို႔၊ ကိစၥဉာဏ္နဲ႔ ပိုင္းျဖတ္လိုက္ပါ...(မွန္ပါ့ဘုရား)၊ ပိုင္းျဖတ္လိုက္သည္ႏွင့္ တစ္ၿပိဳင္နက္၊ ပိုင္းျခားတဲ့ဉာဏ္နဲ႔ဆိုရင္၊ မဂၢင္ရွစ္ပါးျပည့္တယ္ ... (မွန္ပါ့)။ ဒကာဒကာမတို႔ မဂ္ရတာအမွန္ပဲ ... (မွန္ပါ့) ဘုရား)။ .
ပိုင္းျခားသည္ႏွင့္တစ္ၿပိဳင္နက္ သူက ေဘးေရာက္ၿပီး သကာလ၊ နိဗၺာန္က အတည့္လာျဖစ္တယ္၊ ရွင္းၿပီလား.. (မွန္ပါ့ဘုရား)၊ ဒီဉာဏ္နဲ႔ နိဗၺာန္နဲ႔က အတည့္၊ သူက ေဘးထြက္ တယ္၊ သေဘာက်ပလား... (တင္ပါဘုရား) ဒုကၡသစၥာက ေဘးထြက္တယ္ေနာ္... နိဗၺာန္ကဘာတုံး... (တည့္ပါတယ္ ဘုရား)။
နိဗၺာန္နဲ႔တည့္ေတာ့ တည့္တဲ့ေနရာ ခင္ဗ်ားတို႔က စိုက္ ၾကည့္။ တည့္တဲ့ေနရာ စိုက္ၾကည့္ေတာ့ အရင္လို ရႈပ္ယွက္ခတ္ ေသးရဲ႕လား၊ ရွင္းၿပီးလား၊ (ရွင္းပါတယ္ဘုရား)။ ေနာက္က ဒကာ ဒကာမေတြေကာ... (ရွင္းပါတယ္ဘုရား)။
ဒါ..ခင္ဗ်ားတို႔ အားထုတ္ၾကည့္ပါ။ ဘုန္းႀကီးေျပာတဲ့ အတိုင္း ေပၚ ရမယ္။ ဒါဘုရား၏ အားထုတ္စဥ္၊ အရိယာအားလုံး ၏ အားထုတ္စဥ္ (မွန္ပါ့ဘုရား)၊

ဒါနိဗၺာန္

ဒကာဒကာမတို႔-ခုနက ရႈပ္ယွက္ခတ္တာေတြ ဖ်တ္ခနဲ ေပ်ာက္သြားတာ၊ ဪ... မရွိေတာ့ဘူးလို႔၊ ဒီမဂ္ဉာဏ္က မေျပာေပဘူးလား... (ေျပာပါတယ္ဘုရား)၊ ရႈပ္ယွက္ခတ္တာ
ေတြမရွိေတာ့ဘူးလို႔ ေျပာတာက ဘာတုံး... (မဂ္ဉာဏ္ပါ ဘုရား)။
ကိုယ့္မဂ္ဉာဏ္က ကိုယ္ရႈလို႔ ခုနက ရႈပ္ယွက္ခတ္တာ ေတြဟာ နဂိုတုံးက ရွိလာခဲ့တာကို မဂၢင္သုံးပါး၊ ငါးပါးနဲ႔ ၾကည့္ လိုက္ေတာ့ ရႈပ္ယွက္ခတ္တာေတြဟာ ဒုကၡအစစ္ပဲ လိုခ်င္စရာ တစ္ကြက္မွ မရွိဘူးဆိုေတာ့ သူတို႔က ဖယ္တယ္၊ ေပ်ာက္ကြယ္ သြားတယ္၊ သူတို႔ေနရာမွာ ဘယ္သူကမွ လာၿပီးအစားမထိုးပဲနဲ႔ ကြက္လပ္ႀကီးက်န္ေနတယ္... (မွန္ပါဘုရား)၊ ဒကာဒကာမတို႔၊ ဘာက်န္ေနသလဲ... (ကြက္လပ္ႀကီး က်န္ေနပါတယ္ဘုရား)။ . . ဪ ... နိဗၺာန္ဆိုတာ ေႏွာင့္ယွက္ျခင္းမွ ဆိတ္ကင္း တဲ့သေဘာ၊ ဝိေဝကေ႒ာ - ေႏွာင့္ယွက္ျခင္းမွ ဆိတ္သုဥ္းတယ္၊ ကိေလသာ ေႏွာင့္ယွက္ျခင္းမွ ဆိတ္ကင္းတယ္၊ ဒီျဖစ္ပ်က္ေတြ က ခင္ဗ်ားတို႔ ကိေလသာ မကုန္လို႔ရွိရင္ ေပၚၾကအုံးမွာဘဲ... (မွန္ပါ့ဘုရား)။
ျဖစ္ပ်က္ဟာ ဘယ္လိုေၾကာင့္ေပၚေပၚေနတာတုံး ... (ကိေလသာမကုန္လို႔ပါဘုရား)၊ ကိေလသာမကုန္တဲ့ ပုဂၢိဳလ္မွာ ကိေလသာက အေၾကာင္း၊ သူကအက်ိဳး ... (မွန္ပါ့ဘုရား)။
ကိေလသာ ကထြက္ တဲ့ ကိေလသာ႐ုပ္ေတြကို အာသေဝါ၏ အာ႐ုံေတြလို႔မဆိုႏိုင္ဘူးလား (ဆိုႏိုင္ပါတယ္ ဘုရား)၊ ေသေသခ်ာခ်ာ နားေထာင္ေနာ္ ... ဒကာ ဒကာမတို႔ ဒီကေန႔ေတာ့ အထူးတလည္ ရွင္းလင္းေအာင္ကို ေဟာေနတာ အရႈပ္နဲ႔အရွင္းကိုေဟာေနတာ၊ မေန႔ကေတာ့ ဝဋ္ကြၽတ္ဖို႔ေဟာတာ။
ဒီကေန႔ေတာ့ ေႏွာင့္ယွက္ျခင္းမွ ဆိတ္ကင္းဟာကို ေဟာတာ... (မွန္ပါ့ဘုရား)။ ကိုင္း ... ဒါျဖင့္ ေရွးကျဖစ္ပ်က္ေတြ ဟာ ခင္ဗ်ားတို႔စိတ္ထဲမွာ အေႏွာင့္အယွက္ေပးေနတဲ့တရားေတြ ပဲ၊ သေဘာက်ပလား ... (က်ပါၿပီဘုရား)၊ ျဖစ္ပ်က္ေတြဟာ နဂိုရႈေနတုံးက ဘာေပးေနတာတုံး ... (အေႏွာင့္အယွက္ေပး ေနတာဘုရား)၊ အေႏွာင့္အယွက္ေပးေနေတာ့ ဪ ... ဒါေတြၾကည့္ေနရတာ ဒုကၡပဲ၊ ဒုကၡအၾကည့္ခိုင္းတာပဲ။
ဒီခႏၶာႀကီးဟာ အႀကီးအက်ယ္ဒုကၡပဲ၊ လိုခ်င္စရာ ရခ်င္စရာ၊ တစ္ကြက္မွမရွိပါကလား၊ အားလုံးကုန္ဒုကၡခ်ည္းပဲ လို႔ဆိုလိုက္ပါေရာ။ ခ်ဳပ္ေပ်ာက္သြားတယ္၊ အဘယ့္ေၾကာင့္ ေပ်ာက္ သတုံးလို႔ ေမးေတာ့၊ ကိေလသာေပ်ာက္လို႔ သူေပ်ာက္ တယ္၊ (မွန္လွပါဘုရား) ဟုတ္လား ... (မွန္ပါဘုရား)။
တဏွာနိေရာဓာ၊ ဒုကၡနိေရာဓါ ... (မွန္ပါဘုရား)၊ တဏွာေကာ မခ်ဳပ္ဘူးလား ... (ခ်ဳပ္ပါတယ္ဘုရား)၊ ဒုကၡေကာ (ခ်ဳပ္ပါတယ္ဘုရား)၊ ခ်ဳပ္သြားေတာ့၊ တဏွာနိေရာဓါ၊ ဒုကၡနိေရာဓါ .. ဆိုသျဖင့္၊ ဒကာ ဒကာမတို႔၊ မဂ္ကေနၿပီး ခြာလိုက္ေတာ့၊ တဏွာက ခ်ဳပ္တယ္၊ တဏွာအေၾကာင္းခ်ဳပ္
ေတာ့၊ ဒုကၡအက်ိဳးကလဲ က်န္ရစ္ဖို႔ အေၾကာင္းမရွိဘူး၊ ရွိေသး သလား...(မရွိပါဘုရား)၊ မရွိဘူးေနာ္။
ဒကာ ဒကာမတို႔ ေသေသခ်ာခ်ာ နားေထာင္၊ ဒါျဖင့္ စာအုပ္ထဲ သြားၾကည့္လို႔ ေတြ႕မွာမဟုတ္ဘူး ... (တင္ပါ့ဘုရား) ဘယ္နည္းနဲ႔မွ မေတြ႕ဘူး၊ ဒီဥစၥာက အလုပ္စဥ္မွ ရမွာ .. (မွန္လွပါဘုရား)။ အလုပ္စဥ္ေဟာတဲ့တရားမွာ ဒကာ ဒကာမ ေတြ ဒီဥစၥာေတြ ေတြ႕ႀကဳံႏိုင္တယ္၊ ျမင္ႏိုင္တယ္။
အဲဒီေတာ့ အခု-မဂၢင္ရွစ္ပါး၊ ေပၚေတာ့မွ ရႈပ္ယွက္တာ နဲ႔ ရႈပ္ယွက္ခတ္တာေတြဟာ မရွိေတာ့ဘူး... (မွန္ပါဘုရား)၊ ဘယ္သူက ျမင္ေနတာတုံး ... (မဂ္ကျမင္ေနတယ္ဘုရား)၊ မဂၢင္ကျမင္ေနတဲ့အခါက်လို႔ရွိရင္ျဖင့္ နဂိုက ရႈပ္ထားတာ ဘယ္သူက ရႈပ္ထားတာတုံး၊ ျဖစ္ပ်က္ကို ကိေလသာက ရႈပ္ထားတာလို႔။
ကိေလသာက အေၾကာင္း၊ ရႈပ္ယွက္ခတ္တာက အက်ိဳး၊ သေဘာက်ပလား ... (တင္ပါဘုရား)။ ကိေလသာက ဘာပါ လိမ့္ ... (အေၾကာင္းပါဘုရား)၊ ျဖစ္ပ်က္ရႈပ္ယွက္ခတ္ေနတာ က ... (အက်ိဳးပါဘုရား)။
ေကာင္းၿပီ၊ အဲဒီကိေလသာ ျဖတ္လိုက္သည္ႏွင့္ တစ္ၿပိဳက္ နက္ အေၾကာင္း “ယထာဘူေတ၊ ႏုပႆေဝဓမၼ” ဆိုတဲ့အတိုင္း ခိုင္ၿမဲတဲ့အေၾကာင္း အျမစ္ႀကီးကို ျဖတ္လိုက္တဲ့အခါက်ေတာ့ ပင္မနဲ႔ တူတဲ့ ရႈပ္ယွက္ခတ္တာႀကီးဟာ ေပ်ာက္ထြက္သြားတယ္၊ သေဘာက်ၿပီလား...(တင္ပါဘုရား)။
(ဆက္ရန္)
