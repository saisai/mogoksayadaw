မွန္းေျခေပါက္အလုပ္ အပိုင္း(၂)
(၁၀-၃-၆၁)

#ဒိ႒ိ အရင္ျဖဳတ္ပါ အပိုင္း(၂)
(၁၄-၁၁-၆၀)

ဤတရားသည္ ဦးသံဒိုင္တို႔အားေနာက္ရက္ဆက္ေဟာေသာ တရားေတာ္ျဖစ္သည္။

အသံဖိုင္ေခါင္းစဥ္ = ရန္ကုန္မွဧည့္သည္မ်ားအား အထူးေဟာၾကားဆံုးမေတာ္မူအပ္ေသာ ဒိ႒ိဝိစိကိစၧာပယ္ထုတ္ပံု ေန႔အလုပ္ေပးတရားေတာ္
စာအုပ္ေခါင္းစဥ္ = ဒိ႒ိ အရင္ျဖဳတ္ပါ
~~~~~~~~~~~~

ဒိ႒ိအပင္းခံေနရင္

ဆရာသမားဆီက ဒိ႒ိမကြာဘဲနဲ႔ ..၊ ဉာတပရိညာနဲ႔ မကြာဘဲနဲ႔၊ တီရဏပရိညာနဲ႔ အားထုတ္ၿပီးေတာ့ ျဖစ္ပ်က္ေတြ ျမင္ေစကာမူ၊ ဒိ႒ိအပင္းခံေနလို႔ ဒိ႒ိဝိစိကိစၧာတည္းဟူေသာ ကိေလသာေရာဂါေဝဒနာ ေပ်ာက္မွာမဟုတ္ဘူး။ ရွင္းၿပီလား၊ တင္းတင္း ေျပာေနတာလို႔ မေအာက္ေမ့နဲ႔၊ အမွန္ေျပာေနတာ ေအာက္ေမ့ .. (မညႇာပါနဲ႔ ဘုရား)။
ကိုင္း ... ဒါျဖင့္ ပဋိစၥသမုပၸါဒ္နားလည္ေအာင္ လုပ္ၾကစို႔။ ပဋိစၥသမုပၸါဒ္က အတိတ္ ပဋိစၥသမုပၸါဒ္ ရွိတယ္။ အနာဂတ္ ပဋိစၥသမုပၸာဒ္ ရွိတယ္။ ဒါ.. က်ဳပ္တို႔နဲ႔ မဆိုင္ဘူး၊ သိေအာင္သာ လုပ္ထားရမယ္၊ က်ဳပ္တို႔ အလုပ္ခြင္မွာ မဝင္လာဘူး ဦးထြန္းရင္ရဲ႕။

အလုပ္ခြင္ဝင္ရမယ့္ ပဋိစၥသမုပၸါဒ္

က်ဳပ္တို႔ အလုပ္ခြင္ဝင္လာမည့္ ပဋိစၥသမုပၸါဒ္က ပစၥဳပၸန္ ပဋိစၥသမုပၸာဒ္၊ ဒီပစၥဳပၸန္ ပဋိစၥသမုပၸါဒ္သည္ ယေန႔ တစ္ေန႔လုံးကို ဆိုသည္မဟုတ္ဘူး၊ ယခုျမင္တဲ့အခိုက္၊ ယခုၾကားတဲ့ အခိုက္ေပၚတဲ့ ပဋိစၥသမုပၸါဒ္။ မေန႔က အဲဒီေရာက္တယ္၊ မေရာက္ဘူးလား ... (တင္ပါ့ဘုရား)။
မွတ္ခ်က္(မေန႔ကေဟာၾကားသည္ကိုရည္ညႊန္းသည္။)
ေရာက္ေတာ့ ဒါကေလး ကေန႔မွ ေရွ႕ဆက္ရေအာင္လို႔ ဒါကေလး ကေန႔မွ ေရွ႕ဆက္ေတာ့ ဒါက အဆင္း႐ူပါ႐ံု၊ အဆင္း ဆိုေတာ့ အဆင္းမ်ိဳးစုံေပါ့ .. (တင္ပါ့)၊ ဒါက ကံက လုပ္လိုက္တဲ့ မ်က္လုံးပသာဒ အၾကည္႐ုပ္။

နာမကၡႏၶာေလးပါးပါေပၚမွာ

ဒီအၾကည္႐ုပ္သည္ ဒီဟာနဲ႔ဒါ မွန္နဲ႔ လူနဲ႔သာတည့္ပါ။ အရိပ္မေပၚဘူးလား ... ေပၚသလား ... (ေပၚပါတယ္ဘုရား)၊ ေပၚရမယ္။ မေပၚပါနဲ႔ ဆိုရင္လည္း မရဘူး၊ မေပၚပါနဲ႔ဆိုလို႔ မရေတာ့ ေပၚတယ္။ ပါဠိလိုသုံးေတာ့ “စကၡံဳစ ပဋိစၥ ႐ူေပစ ဥပၸဇၨတိ စကၡဳဝိညာဏံ” ေပၚမွာပဲ .. (တင္ပါ့)၊ စကၡဳဝိညာဏ္ တစ္ဝိညာဏ္တည္းသာ ေပၚသလား၊ သမၸယုတၱဓမၼပါ ေပၚသလား .... (သမၸယုတၱဓမၼပါ ေပၚပါတယ္ ဘုရား)။
ဒါျဖင့္ နာမကၡႏၶာ ေလးပါးေပၚတာ က်ဳပ္တို႔ ေက်နပ္ၿပီ မဟုတ္ဘူးလား ... (တင္ပါ့)။
ဒါျဖင့္ ခႏၶာဖြဲ႕ၾကစို႔။ ဒါက ပဋိစၥသမုပၸါဒ္ ..။ ဒါက ပဋိစၥသမုပၸႏၷလို႔ ခြဲမွတ္လိုက္ၾကပါဦး။ သူကျဖစ္ေၾကာင္း ႏွစ္ခု၊ ျဖစ္က်ိဳး ေလးခု။ ျဖစ္ေၾကာင္းက ႏွစ္ခုေပါင္းမွ ျဖစ္က်ိဳးေလးခုျဖစ္တယ္။ ႏွစ္ခုက အေၾကာင္း၊ ဒီေလးခုက အက်ိဳး။ သေဘာက်ရဲ႕လား ... (တင့္ပါ)၊ ႏွစ္ခုကအေၾကာင္း .... (ေလးခုက အက်ိဳး)၊ ဒါေသေသခ်ာခ်ာမွတ္ပါ။
မွတ္ခ်က္။ ။(ႏွစ္ခု=မ်က္စိ,အဆင္း။ ေလးခု= ေဝဒနာကၡႏၶာ၊ သညာကၡႏၶာ၊ သခၤါရကၡႏၶာ၊ ဝိညာဏကၡႏၶာ။)
ဒါျဖင့္ ဦးသံဒိုင္ ဒါကေလး ၾကည့္လိုက္ပါ။ ယခုေပၚလာတဲ့ ပဋိစၥသမုပၸါဒ္။ အိမ္ကပါလာတာ မဟုတ္ဘူး၊ အိမ္ကပါလာတာက ဒီကို ဘယ္ပါလာႏိုင္ပါ့မတုန္း။ မဟုတ္ဘူးလား။ ေလွကားထစ္က ဆင္းလိုက္ကတည္းက ရွိမွမရွိေတာ့ဘဲ၊ ရွင္းၿပီလား။
ေကာင္းၿပီ ...။ ဒါဟာ ယခုေရာက္ေနဆဲ ပဋိစၥသမုပၸါဒ္ ဆိုတာ ခင္ဗ်ားတို႔ ေက်နပ္ၿပီလားလို႔ ေမးလိုပါတယ္။ ေက်နပ္ၿပီလား၊ ေရာက္ဆဲ ပဋိစၥသမုပၸါဒ္ေလ။ ေရာက္ဆဲ ပဋိစၥသမုပၸါဒ္ဆိုေတာ့ ႐ုပ္ႏွစ္ခု၊ နာမ္ေလးခု ေပါင္းလိုက္ေတာ့ ႐ုပ္ႏွစ္ခုဟာ ႐ူပကၡႏၶာ။ နာမ္ေလးခုဟာ နာမကၡႏၶာေလးပါး။ ေပါင္းလိုက္ေတာ့ ခႏၶာငါးပါး။
ဒါဟာ ခင္ဗ်ားတို႔ ခုျဖစ္ေနဆဲ ခႏၶာငါးပါး။ အိမ္ကပါလာတဲ့ ခႏၶာ ငါးပါးလား၊ အေမေပးတဲ့ ခႏၶာငါးပါးလား၊ ထမင္း စစားတုန္းက ခႏၶာငါးပါးလား ေမးလိမ့္မယ္။ “မဟုတ္ပါ၊ အခုအသစ္ပါ ဘုရား ... ျဖစ္ဆဲအသစ္ပါ” ဆိုႏိုင္မလား ... (ဆိုႏိုင္ပါတယ္ ဘုရား)။
ျဖစ္ဆဲအသစ္။ ဒါကို က်ဳပ္တို႔က ဂ႐ုစိုက္ရမယ္။ သူမ်ား ေျပာတာကို နည္းနည္းမွ သြားမယုံနဲ႔၊ သူမ်ားေျပာတာကို သြားယုံ ေနလို႔ရွိရင္ ခင္ဗ်ားတို႔ မရွိတာခ်ည္း ရႈမိလ်က္သား ႀကဳံေနလိမ့္ မယ္။ မေရာက္ေသးတာကို ရႈမိလ်က္သား ႀကဳံေနလိမ့္မယ္။
စာကေတာ့ ေရးတာပဲ၊ “႐ူပံ အတီတံ အနာဂတံ ပစၥဳပၸႏၷ”၊ အဲဒါက သမၼသနဉာဏ္ ေဟာေနတာကြ...။ ဥဒယဗၺယဉာဏ္ ေဟာတာ မဟုတ္ဘူး။ ဒါက ပစၥဳပၸန္ ဥဒယဗၺယ ေဟာေနတာ။ သမၼသနက လူၿပိန္းကို ေဟာတာ .... လူၿပိန္းကို ေဟာတာ။

တိုက္ဆိုင္လို႔ေပၚလာတဲ့ ခႏၶာငါးပါး၊ အရင္း က်က်သိသြားၿပီ

ကဲ .. ဒါျဖင့္ ခႏၶာငါးပါးျပည့္ၿပီလား .. (ျပည့္ပါၿပီ ဘုရား)။ ဒါဟာ အိမ္ကပါလာတဲ့ ခႏၶာ ငါးပါးလား .... အေမေမြး ကတည္းက ခႏၶာငါးပါးလား ... ယခုမွ တိုက္ဆိုင္ေပၚလာတဲ့ ခႏၶာငါးပါးလား (ယခုမွ တိုက္ဆိုင္ ေပၚလာပါတယ္ ဘုရား)။
ရွင္းၿပီလား ... ေကာင္းၿပီ၊ ဒါျဖင့္ ဒီခႏၶာငါးပါး သိသြားၿပီ ပစၥဳပၸန္ခႏၶာငါးပါး၊ ေရာက္ဆဲခႏၶာငါးပါး၊ ျဖစ္ဆဲ ခႏၶာငါးပါးသိတာကို ဘုန္းႀကီးက ငါ့တရားဟာ ဘုရားေဟာေတာ္မူတဲ့ တရားအရင္းေတာ့ က်သြားၿပီေဟ့ .. ။ ဒီဒကာ ႏွစ္ေယာက္ အရင္းေတာ္ေတာ္က်သြားၿပီ ဆိုႏိုင္တယ္၊ အရင္းက်က် မိသြားတယ္။ မဂ္ဖိုလ္တည္ဖို႔ နည္းပဲက်န္ေတာ့တယ္၊ အရင္းက်က်သိသြားၿပီ။ ။
ႏို႔မဟုတ္လို႔ရွိရင္ ခင္ဗ်ားတို႔မွာ သႆတဒိ႒ိက ခံေနမယ္ “က်ဳပ္ မေသေသးဘူးဗ်၊ အသက္ (၅၀)ေက်ာ္လာၿပီ၊ အရင္အတိုင္းပဲ က်ဳပ္”၊ သႆတဒိ႒ိ၊ အဲဒါ ျဖဳတ္ေနတာ ခင္ဗ်ားတို႔က မသိလိုက္ လို႔၊ ခု ... ဒိ႒ိတစ္ခု ျဖဳတ္လိုက္တာ။

သႆတဒိ႒ိနဲ႔ လာခဲ့ၾကတာမို႔ ဒိ႒ိျဖဳတ္ေပးေနတာ

ဦးသံဒိုင္ အသက္ဘယ္ေလာက္ေရာက္ၿပီတုန္း၊ ဟာ ... ။ ငါးဆယ္ေက်ာ္ၿပီ။ ဪ ... ငယ္ငယ္တုန္းကလည္း ဒီလိုပဲ၊ ခုလည္း ဒီလိုပဲ၊ ဒီကို လာခဲ့တာပါပဲ ဘုရားဆိုေတာ့ ဘာဒိ႒ိျဖစ္ေနသလဲ ... (သႆတဒိ႒ိပါ ဘုရား)၊ သႆတဒိ႒ိ ျဖစ္ေနတယ္၊ ကိုထြန္းရင္လည္း ဒီလိုပဲ သႆတဒိ႒ိနဲ႔ လာခဲ့တာဗ်... ယခု လာခဲ့တာ ... (မွန္ပါ့)။
အဲဒီ သႆတဒိ႒ိဟာက အခုျဖစ္ဆဲ ခႏၶာငါးပါးကို က်က်နန သေဘာမက်လို႔ သူရွိေနတာဗ် .. မဆိုႏိုင္ဘူးလား။ ျဖစ္ဆဲခႏၶာ ငါးပါးကို ယခုျဖစ္ၿပီး ယခုေပၚလာတာကို သေဘာက်မယ္ ဆိုရင္ ဟိုဟာေတြမရွိလို႔ ဒါ... ေပၚတာကိုး ဆိုတာကို သိၾကမယ္။
ဒါျဖင့္ ဒီဥစၥာ ဘာေဟာေနတာတုန္းဆိုေတာ့ “ေၾသာ္ ... ဆရာဘုန္းႀကီးက သႆတ ျဖဳတ္ေနတာ ပါကလား” ဆိုတာ ေပၚလာ မယ္။ သႆတ ဘာနဲ႔ျဖဳတ္လိုက္တုန္းဆိုေတာ့ ေဟာဒီ အေၾကာင္းႏွစ္ခုေၾကာင့္ အက်ိဳးေလးခုျဖစ္တယ္။ ခုမွ အသစ္ကြ၊ အသစ္ဆိုသျဖင့္ တစ္တိုတစ္စမွ် ေနာက္က မပါခဲ့ဘူး ဆိုတာ မေသခ်ာဘူးလား ... (ေသခ်ာပါတယ္ဘုရား)။
ေသခ်ာေတာ့ ေနာက္ကဟာေတြနဲ႔ ဘာမွ က်ဳပ္သည္ကား လို႔ဆိုလို႔ရွိရင္ျဖင့္ အဆက္ အသြယ္ မရွိဘူးလို႔ ဒီလိုလည္း မယူလိုက္ပါ နဲ႔တဲ့။ အဆက္အသြယ္ နည္းနည္းရွိတယ္၊ အဆက္အသြယ္ မရွိဘူး ဆိုရင္ ဥေစၧဒဘက္ ခင္ဗ်ားတို႔ ေျပးေတာ့မယ္။ မေျပးေပဘူးလား ... ေျပးသြားမယ္။
အခု သႆတ စင္ေအာင္လုပ္ေတာ့ ဥေစၧဒ ခင္ဗ်ားတို႔ သြားကပ္မယ္ ... ။ ရွင္းၿပီလား၊ သႆတေတာ့ စင္မသြားဘူးလား၊ ဟိုက ပါလာတာ ဟုတ္ေသးရဲ႕ လား .. (ဟိုက ပါလာတာ မဟုတ္ပါ ဘုရား)။
အဲဒီေတာ့ ဒါအသစ္လို႔ မဆိုႏိုင္ဘူးလား ... အသစ္ခႏၶာ ငါးပါးဆိုကတည္းက သႆတ ခိုင္ၿမဲတာခ်ည္းပါေသးရဲ႕ လား . . (မပါ, ပါဘုရား)။
အဲ ... သႆတကေတာ့ စင္သြားၿပီ၊ ဘုန္းႀကီးေဟာတဲ့ အထဲမွာ ခင္ဗ်ားက ရယ္စရာ ေျပာေနတာ ေအာက္ေမ့လို႔လား.. သႆတ ႏွင္ထုတ္တယ္။ ေပၚၿပီလား .. အေမေမြးလာတာ ဒီအထဲမွာ ပါေသးရဲ႕လား ... (မပါ ပါဘုရား)၊ ပါရဲ႕လား ... (မပါ, ပါ)၊ ပါလာတယ္ဆိုရင္ ဘာဒိ႒ိ ျဖစ္မလဲ .... (သႆတဒိ႒ိ ျဖစ္မယ္)။
အဲဒါ စင္သြားၿပီ .... စင္သြားၿပီ၊ သႆတဒိ႒ိစင္သြား ၿပီ ...တဲ့။ သေဘာပါရဲ႕လား .... မပါရင္ ဒီအတိုင္း ေကာက္ေမးတာေပါ့။
စင္ရဲ႕လား ဦးသံဒိုင္၊ အေမေမြးလာတာ ဒီအထဲမွာ တစ္တို တစ္စ ပါေသးရဲ႕ လားတဲ့ ... (မပါ, ပါဘုရား)၊ အခုမွ အသစ္ေပၚတဲ့ ခႏၶာငါးပါးလား ... (အခုမွ အသစ္ေပၚတာပါဘုရား)။
ဒါျဖင့္ နဂိုထင္ေနတာေတြက “က်ဳပ္ႀကီးလာၿပီ၊ ငယ္ရာက ႀကီးလာတယ္”ဆိုတာေတြ ဟုတ္ေသးရဲ႕လား ... (မဟုတ္ပါဘုရား)။

ေရာက္ဆဲခႏၶာငါးပါးသီေတာ့ သႆတဒိ႒ိစင္

ငယ္ရာက ႀကီးလာတယ္ဆိုရင္ သႆတကိုး ... ဗ်။ အဲဒီသႆတရွိေသးရဲ႕လားလို႔ ခုေမးလိုက္တယ္၊ ရွိေသးရဲ႕လား။ ဒါသိသြားလို႔ရွိရင္ ရွိေသးရဲ႕ လားလို႔၊ ယခုေရာက္ဆဲ ခႏၶာငါးပါး သိေတာ့ ... (ယခုသိေတာ့ မရွိေတာ့ပါဘုရား)။
မရွိေတာ့ဘူးဆိုေတာ့ ေၾသာ္ ... ဘုန္းႀကီးဘာေဟာေနပါ လိမ့္မတုန္းဆိုၿပီးေတာ့ ခင္ဗ်ားတို႔က လက္သည္ရွာမေနနဲ႔။ သႆတ ကို သူသတ္ေနတာ အခုဟာ။
ဒါျဖင့္ ပစၥဳပၸန္ခႏၶာငါးပါး သိရသျဖင့္၊ ခုမွေပၚတဲ့ ခႏၶာငါးပါး သိရသျဖင့္ ဘာဒိ႒ိေသသတုန္းလို႔ ဦးသံဒိုင္ ေမးလိမ့္မယ္။ ဘယ္ဒိ႒ိ ေသသြားသတုန္းလို႔ ေမးရမယ္ ... (သႆတဒိ႒ိေသပါတယ္)။ .
ဒါဟာ ျပလိုက္႐ုံနဲ႔ ေသသြားတာ၊ သႆတ ေသတယ္။ ရွင္းၿပီလား၊ သႆတ ေသပုံ ေကာင္းေကာင္းေက်နပ္ၿပီလား... (ေက်နပ္ပါၿပီဘုရား)။

ဥေစၧဒဒိ႒ိ

ဥေစၧဒ က်န္ေနေသးတယ္။ အခုမွ အသစ္ဆိုေတာ့ ဟိုဟာ ၊ ေတြနဲ႔ မဆက္သြယ္ ေတာ့ဘူး ဆိုေတာ့ ဥေစၧဒ ျဖစ္မေနဘူးလား၊ ဥေစၧဒက က်န္ေနျပန္တယ္။ ဒိ႒ိက ဟိုကပ္-ဒီကပ္ဗ်။ လူ႔လြယ္အိတ္ ျဖစ္ေနတယ္၊ လူ႔ လြယ္အိတ္ဆိုတာ ဒီဘက္က ပခုံးခ်ိတ္လိုက္ရင္ ဒီဘက္ခါးကပ္ေနတာပဲ၊ ဒီဘက္ပခုံး ခ်ိတ္လိုက္လို႔ ရွိရင္လည္း ဒီဘက္ခါးကပ္ေနျပန္တယ္။ သူက ဒိ႒ိက ကပ္ခ်ည္းေနတာပဲ။ ဒါေၾကာင့္ လူ႔လြယ္အိတ္ ျဖစ္ေနတာေျပာတာ။
ခု-သႆေတာ့ စင္သြားၿပီ ဦးသံဒိုင္ရ၊ ဥေစၧဒက ကပ္ေန တယ္။ ဒီဒိ႒ိ ႏွစ္ခု ရွိရင္လည္း မဂ္၊ ဖိုလ္ တားလိမ့္မယ္၊ မတားေပဘူး လား ... (မွန္ပါ့)၊ ဘုရားက အလယ္လမ္းသြားရမယ္ဆိုတာကိုး .. သႆတလမ္း လည္း မလိုက္နဲ႔၊ ဥေစၧဒလမ္းေကာ .... (မလိုက္နဲ႔) မလိုက္နဲ႔။ အလယ္လမ္းက လိုက္ဆိုေတာ့ အလယ္လမ္းကို ခင္ဗ်ားတို႔ႏွစ္ေယာက္ မေရာက္ဘဲ ျဖစ္ေနတယ္။ သႆတစင္ . သြားၿပီး ဥေစၧဒ သြားကပ္ေနတယ္။
ဒါေၾကာင့္ ဒီတရားမ်ိဳးေဟာရတာ က်ဳပ္ ဆန္အိတ္ပိုးခ်င္ ၊ ေသးတယ္ေျပာတာ၊ ဟိုဟာက သက္သာတယ္။
ကဲ .. ဥေစၧဒ ခြာေတာ့မယ္ေနာ္-ဟုတ္လား၊ သႆတ ရွင္းရွင္းကြာၿပီလား ... (ကြာပါတယ္ ဘုရား)၊ ျဖစ္ပ်က္ မပါဘဲနဲ႔ ကြာေနတာ အသိနဲ႔ ကြာတာလို႔ မွတ္ထားၾက။ ဘာနဲ႔ကြာတာလဲ (အသိနဲ႔၊ အသိနဲ႔ကြာတာ။ ဥေစၧဒအသိနဲ႔ ကြာေအာင္ လုပ္ေပးဦး မယ္ေနာ္။
ဒါက မ်က္လုံး အၾကည္႐ုပ္ဆိုေတာ့ စကၡဳပသာဒ႐ုပ္ေပါ့ဗ်ာ။ ဒါကို ႐ူပါ႐ုံဆိုတာလည္း ကံ၊ စိတ္၊ ဥတု၊ အာဟာရတို႔ေၾကာင့္ ျဖစ္တဲ့႐ုပ္ မဆိုႏိုင္ဘူးလား ...။ ဒါကေတာ့ အာ႐ုံဒြါရေၾကာင့္ျဖစ္တဲ့ နာမ္။ စာသံပါတယ္လို႔ မယူလိုက္ပါနဲ႔။
ဒါျဖင့္ ဒီကံတည္းဟူေသာ အေၾကာင္းကင္း၍လည္း ဒီ႐ုပ္ျဖစ္ႏိုင္ပါ့မလား ... (အေၾကာင္း ကင္း၍ မျဖစ္ႏိုင္ပါ ဘုရား)။
မျဖစ္ႏိုင္ဘူး။ ဪ ... ဒါျဖင့္ အေၾကာင္းနဲ႔ အက်ိဳးဆက္ ေသးတယ္ဆိုေတာ့ ဥေစၧဒဒိ႒ိ လြတ္မသြားဘူးလား .... (လြတ္သြား ပါတယ္ဘုရား)။

အေၾကာင္းကင္း၍ မျဖစ္ႏိုင္

ဒါနဲ႔ အထည္ထုပ္ေတြကို မေန႔ကေျပာလိုက္တယ္။ သူတို႔ လည္း ဥတုေၾကာင့္ျဖစ္တာပဲ၊ ဥတုခ်ည္းပဲ အေၾကာင္းကင္းရဲ႕လား၊ ဥတု႐ုပ္ေတြ၊ အထည္လိပ္ေတြ၊ သံထည္ေတြ မဟုတ္ဘူးလား ... (ဟုတ္ပါတယ္ ဘုရား)။
ဒါလည္း ဥတုတည္းဟူေသာ အေၾကာင္းမကင္းဘူး။ ဥတု တည္းဟူေသာ အေၾကာင္း ေၾကာင့္ ျဖစ္တဲ့ အက်ိဳးတရားေတြဆိုေတာ့ အေၾကာင္းအက်ိဳး ျပတ္ေနတဲ့ တရားလို႔ ဆိုမလား ... (မဆိုပါ ဘုရား)။
မဆိုဘူး ...။ ဒါျဖင့္ ကံ, ဥတုေၾကာင့္ ဒီက ကံ-ဒီက ဥတု၊ ကံ, ဥတု ႏွစ္ခုေပါင္းၿပီး သကာလ လုပ္လိုက္တဲ့ အက်ိဳးတရား ကေလးဆိုရင္ေရာ လြဲပါ့မလား ... (မလြဲပါဘုရား)။
မလြဲေတာ့ သူတို႔ျဖစ္လာတာလည္း ေနာက္ေၾကာင္း လုံးဝ ကင္းသလားလို႔ ေမးလိုက္ျပန္ေတာ့ ကင္းရဲ႕လား ... (မကင္းပါ ဘုရား)။
မကင္းျခင္းေၾကာင့္ ဥေစၧဒကလည္း လြတ္သြားတယ္။ အေၾကာင္းကင္းတယ္ဆိုရင္ ဥေစၧဒ ျဖစ္မွာပဲ။ အေၾကာင္းကင္းရဲ႕လားလို႔ .. (မကင္းပါဘုရား)။
မကင္းျခင္းေၾကာင့္ ဒီခႏၶာငါးပါးအေပၚမွာ ခင္ဗ်ားတို႔ သႆတေကာ။ ေနာက္က နာမ္႐ုပ္လို႔ လည္း ဆိုလို႔ရရဲ႕လား .... ေနာက္ကပါလာတဲ့ နာမ္႐ုပ္လို႔ေကာ ဆိုလို႔ရရဲ႕ လား .. မရဘူး။ ေနာက္က အေၾကာင္းကင္းသလားလို႔ ေမးျမန္ေတာ့လည္း (မကင္း ပါဘုရား)။

ဒိ႒ိေတြခံေနရင္

ခင္ဗ်ားတို႔ ေယာဂီတိုက္ေတြ သြားၿပီး ေမးၾကည့္တဲ့အခါက် ေတာ့ ဒီလိုနည္းေတြကို စုံစုံလင္လင္ မေဟာႏိုင္၊ မေျပာႏိုင္ဘူး။ ျဖစ္ပ်က္ရႈေဟ့-ဒါပဲ အၿပီးသတ္က်ေတာ့။ ဒိ႒ိက ဘယ္သူ ျဖဳတ္ေပးမွာ လဲ၊ ျဖတ္ေပးမည့္သူ ရွိေသးရဲ႕လား ... မေပၚႏိုင္ေတာ့ ဒီအေၾကာင္းေတြကလည္း၊ ဒီအေၾကာင္း ပုေရဇာတဆိုတဲ့ စကၡဳပသာဒက ကမၼပစၥေယာက လုပ္ခ်တာ။ သေဘာက်ရဲ႕လား ... ။

ဒါျဖင့္ သႆတ ဥေစၧဒႏွစ္ပါး ယခုေရာက္ဆဲ ခႏၶာငါးပါး၊ ျဖစ္ဆဲခႏၶာငါးပါးမွာ ဘယ္အခ်ိန္ ျဖစ္ျဖစ္ သႆတလည္း မလာေစနဲ႔ ေနာ္။ ဥေစၧဒေကာ .... (ဥေစၧဒလည္း မလာပါေစနဲ႔ ဘုရား)။
မလာေစနဲ႔ဆိုေတာ့ ေၾသာ္ ... ခႏၶာငါးပါးဟာ သႆတ သေဘာ၊ သႆတဒိ႒ိနဲ႔ လည္း ခင္ဗ်ားဉာဏ္ထဲမွာ မရွိေစနဲ႔....။ ဥေစၧဒဒိ႒ိလည္း မရွိေစနဲ႔ ခႏၶာငါးပါးအေပၚ၌ ရွင္းၿပီလား။ သႆတ ဒိ႒ိလည္း ... (မရွိေစနဲ႔)၊ ဥေစၧဒဒိ႒ိေကာ ... (မရွိေစနဲ႔)။
ႏို႔မို႔လို႔ ရွိရင္ သႆတ ဥေစၧဒ ခံေနလို႔ ရွိရင္ ခင္ဗ်ားတို႔ အာေပါက္ေအာင္ အားထုတ္မရႏိုင္ဘူး ... မရဘူး။ ဘာျဖစ္လို႔တုန္း ဆိုေတာ့ ဘုရားက အဂၤုတၱိဳရ္ပါဠိေတာ္မွာ ေဟာတယ္...။ ဒီထဲမွာ ဒိ႒ိတစ္ခုခု ခံေနလို႔ရွိရင္ကြာတဲ့...တဲ့၊ သစၥာႏုေလာမိက ဉာဏ္ေတာင္ မရဘူး...တဲ့။ သေဘာက် ရဲ႕လား၊ ဒိ႒ိတစ္ခုခု ခံေနရင္ သစၥာႏုေလာမိက ဉာဏ္ေတာင္မရဘူး...။ မရရင္ ေသာတပတၱိမဂ္ မရဘူး...။ မရရင္ ေသာတာပန္၊ သကဒါဂါမ္၊ အနာဂါမ္၊ ရဟႏၲာ၊ ( ဘယ္ေတာ့မွ မျဖစ္ဘူးဆိုတာ တစ္ထစ္ခ်ေဟာတာ...၊ ေက်နပ္ၿပီလား...။
ဒိ႒ိခံေနလို႔ ရွိရင္ ဘယ္လိုအားထုတ္ေပမယ့္လို႔ မရဘူး။ ဒိ႒ိမွာ ဒီဒိ႒ိႏွစ္ခုက အေရးႀကီးတယ္။
“ဒြါသ႒ိ ဒိ႒ိေယာ ဥပၸဇၨမာနာ သကၠာယဒိ႒ိ ပမုေခေနဝ ဥပၸဇၨႏၲိ”

သကၠာယဒိ႒ိက အရင္းခံပဲ

ေျခာက္ဆယ့္ႏွစ္ပါးေသာ ဒိ႒ိဟာ သကၠာယဒိ႒ိက လာတာ ကြ။ ေပၚၿပီလား ... (မွန္ပါ့)၊ သကၠာယဒိ႒ိ တစ္လုံးရွိရင္ ေျခာက္ ဆယ့္ႏွစ္ပါးေသာ ဒိ႒ိတို႔ကို ခင္ဗ်ားတို႔ ယူခ်င္တာ ယူပစ္ႏိုင္တယ္၊ မယူေပဘူးလား... (မွန္ပါ့)၊ ရွင္းၿပီေနာ္...။
ေကာင္းၿပီ ... ဒါျဖင့္ လက္ရွိ ခႏၶာငါးပါး၊ ျဖစ္ဆဲခႏၶာငါးပါး အေပၚ၌ ဦးထြန္းရင္ျဖစ္ေစ၊ ဦးသံဒိုင္ျဖစ္ေစ...၊ သႆတ ဥေစၧဒ ကင္းၿပီး သိတဲ့အသိနဲ႔ သိသလားလို႔ ေမးလိမ့္မယ္။ သႆတ, ဥေစၧဒ ကင္းၿပီလား၊ ကင္းတဲ့အသိလို႔ မဆိုႏိုင္ဘူးလား ... (ဆိုႏိုင္ ပါတယ္ဘုရား)။
ဒါျဖင့္ ကင္းတဲ့အသိဉာဏ္သည္ ခင္ဗ်ားသည္ သႆတကို လည္း ႏိုင္တဲ့ဉာဏ္နဲ႔ ခင္ဗ်ားသိတယ္။ ခုခႏၶာငါးပါးသိေနတယ္။ ဥေစၧဒကိုလည္း ႏိုင္နင္းတဲ့ဉာဏ္နဲ႔ သိေနတယ္။ ဆိုႏိုင္ၾကၿပီလား... (မွန္ပါ့)၊ သေဘာပါၾကပလား ... (မွန္ပါ့ဘုရား)။
ကဲ ... ဒီကစမယ္၊ ျဖစ္ပ်က္ မေဟာရေသးဘူး...တဲ့။ အနိစၥေဟာၿပီလား ... (မေဟာေသးပါ ဘုရား)။ မေဟာရေသးပါဘူး။
မေဟာရေသးရင္ ဘုန္းႀကီးေဟာေန တာႏွစ္ရက္ရွိၿပီ၊ တပည့္ေတာ္တို႔ ရန္ကုန္ကေတာင္ လာရတာ ဘုန္းႀကီးက ကိုယ့္ဆီလာတာ ႏို႔ .. မဟုတ္ဘူးလား။ ဒီအေျခဟာ မျဖဳတ္လို႔ရွိရင္ ငါေရွ႕ ေဟာစရာ တရား မရွိဘူး။ ေရွ႕ေဟာစရာ တရား မရွိဘူး။ ေဟာလို႔ရွိရင္ ငါလည္း အာေပါက္မွာပဲ။ မင္းတို႔က နိဗၺာန္ ေရာက္မွာ မဟုတ္ဘူး .. မေျပာထိုက္ဘူးလား။ ဘုန္းႀကီးက အာေပါက္မွာပဲ။ ခင္ဗ်ားတို႔ လည္း နိဗၺာန္ မေရာက္ဘူး။
ကိုထြန္းရင္ မႈိင္တိုင္တိုင္ လုပ္မေနနဲ႔၊ သေဘာပါရဲ႕လား။

ဒိ႒ိခံေနရင္ နိဗၺာန္ရ႐ိုးထုံးစံမရွိ

ကဲ .. သႆတ, ဥေစၧဒ တစ္ခုခုခံေနရင္ ဘယ္သူ နိဗၺာန္ရသတုန္း၊ ထုံးစံရွိရဲ႕လား ... (မရွိပါဘူး)။
ကဲ .. ဦးသံဒိုင္ ေတာ္ေတာ္ေက်နပ္ၿပီလား ... (ေက်နပ္ပါ ၿပီ)၊ ေက်နပ္ၿပီတဲ့။ ေက်နပ္လို႔ရွိရင္ ဘုန္းႀကီး ဒိ႒ိေရာ ဝိစိကိစၧာေရာ သတ္ေပးေတာ့မယ္၊ သကၠာယဒိ႒ိလည္း သတ္ေပးဦးမယ္၊ သႆတ, ဥေစၧဒ ရွင္းၿပီးၿပီတဲ့။ ရွင္းၿပီးေပမယ့္လည္း ခု ဒိ႒ိအရိပ္ အေငြ႕က်န္ေနေသးတယ္။ အရိပ္အေငြ႕ က်န္ေနေသးတယ္။

အေၾကာင္းနဲ႔အက်ိဳးပဲရွိတယ္

ဒီက စကၡဳပသာဒ၊ ဒီက ႐ူပါ႐ုံေၾကာင့္ နာမကၡႏၶာေလးပါး မျဖစ္ဘူးလား ျဖစ္သလား ... (ျဖစ္ပါတယ္ ဘုရား)။
ျဖစ္တယ္ ...။ ဒါျဖင့္ ဒီႏွစ္ခုက အေၾကာင္းလို႔ မဆိုႏိုင္ဘူး လား၊ ဒီေလးခုက ... (အက်ိဳးပါ ဘုရား)။
အက်ိဳး။ ဒါျဖင့္ ဦးသံဒိုင္ခႏၶာကိုယ္ဟာ ေယာက္်ားလား မိန္းမလား၊ အေၾကာင္းလား အက်ိဳးလားေမးရင္ ... (အေၾကာင္း အက်ိဳးပါပဲဘုရား)။
ဒီအေၾကာင္းေၾကာင့္ျဖစ္တဲ့ အက်ိဳးပဲဆိုမွာပဲ။ ေယာက္်ား လား မိန္းမလား၊ အေၾကာင္းလား အက်ိဳးလားေမးရင္ ဘယ့္ႏွယ္ ေျဖၾကမတုန္း ... (အေၾကာင္းအက်ိဳးပါပဲဘုရား)။
အေၾကာင္းေၾကာင့္ျဖစ္တဲ့ အက်ိဳး။ မကင္းေအာင္ စကား ေျပာလို႔ ရွိရင္ မဆိုႏိုင္ဘူးလား ... (ဆိုႏိုင္ပါတယ္ဘုရား)။
ဒါျဖင့္ အေၾကာင္းအက်ိဳးပဲရွိတယ္။ ဒီအေၾကာင္း မရွိျပန္လို႔ ရွိရင္ ဒီအက်ိဳးက ေပၚပါ့မလား ... (မေပၚႏိုင္ပါဘုရား)။
ဒါျဖင့္ အေၾကာင္းအက်ိဳးပဲ ရွိတယ္လို႔ က်ဳပ္တို႔ ခ်ဳံးလိုက္ ၾကစို႔ ... မခ်ဳံးႏိုင္ဘူးလား၊ အေၾကာင္းအက်ိဳး ရွိတယ္လို႔ ခ်ဳံးလိုက္ " ၾကပါ။
အေၾကာင္းအက်ိဳးသည္ ဪ .. ဘယ္ခႏၶာျဖစ္ျဖစ္ အေၾကာင္းအက်ိဳးခ်ည္းပဲ ဆိုႏိုင္သလား ... (ဆိုႏိုင္ပါတယ္ ဘုရား)၊ ကမာၻတစ္ဝန္းလုံး ျဖန႔္လိုက္ပါ၊ ကမာၻတစ္ဝန္းလုံး ျဖန႔္လိုက္၊ ေယာက္်ားေတြလား မိန္းမေတြလား၊ အေၾကာင္းအက်ိဳး ေတြလား (အေၾကာင္းအက်ိဳးေတြပါ ဘုရား)။

ဖန္ဆင္းထားတာမဟုတ္ဘူး

လူေတြ ထာဝရဘုရား ဖန္ဆင္းထားတာလည္း ဟုတ္ေသး ရဲ႕လား ... (မဟုတ္ပါ)၊ မိုဟာမက္ ဖန္ဆင္းတာေရာ ... (မဟုတ္ပါ ဘုရား)၊ ျဗဟၼာႀကီး ေမြးဖြားတာေရာ ... (မဟုတ္ပါ)၊ ဘာေတြတုန္း မဟုတ္ေနလို႔ ရွိရင္ .... (အေၾကာင္းအက်ိဳး ဒါပဲရွိပါတယ္ ဘုရား)။
ဒါျဖင့္ ခင္ဗ်ားဟာ ဘယ္က လာပါလိမ့္မတုန္း ဆိုတာ ရွိေသးရဲ႕လား .... (မရွိပါ)၊ ငါ ဘယ္က လာပါလိမ့္မလဲဆိုတဲ့ ဝိစိကိစၧာရွိေသးရဲ႕ လား၊ အဲဒီ ဝိစိကိစၧာ။ ေသၿပီ ဝိစိကိစၧာ၊ ဝိစိကိစၧာ ေသသြားၿပီ၊ အသိနဲ႔ေသသြားၿပီ။ ရွင္းပလား ... (တင္ပါ့)၊ ဝိစိကိစၧာ ဘာျဖစ္ သြားသလဲ .... (အသိနဲ႔ ေသသြား ပါတယ္။
အသိနဲ႔ေသသြားတယ္။ အပြားနဲ႔ေသတာ မဟုတ္ေသးပါ ဘူး။ အပယ္နဲ႔ ေသတာ မဟုတ္ေသး ပါဘူး။ ရွင္းၿပီလား၊ အသိနဲ႔ ေသတာရွိေသးတယ္။ မပြားနဲ႔ မေသေသးဘူး၊ အပြားနဲ႔ မေသေသး ဘူး၊ အပယ္နဲ႔ေကာ ... (မေသေသးပါဘူး)။
မေသေသးဘူး။ အသိနဲ႔ေသတယ္၊ ဒါကို ေယာင္ေတာင္ ေတာင္ဆရာသမားနဲ႔ဆိုလို႔ရွိရင္ “မင္းေသာတာပန္တည္ၿပီး ျပန္ေတာ့ကြာ”လို႔ ... ဆိုခ်င္ ဆိုလိမ့္မယ္လို႔ မေန႔ကေတာင္ ေျပာလိုက္ေသး တယ္။ မေျပာလိုက္ဘူးလား .... (ေျပာလိုက္ပါတယ္ ဘုရား)။

ဆရာမွားရင္ တစ္သံသရာလုံး ေမွာက္တယ္

အဲဒီ ဆရာသမားေတြနဲ႔ေတြ႕ရင္ တစ္သံသရာလုံး ေမွာက္ ေတာ့မွာပဲ။ ဒါေၾကာင့္ ခင္ဗ်ားတို႔ ကံေကာင္းတယ္လို႔ ေျပာတာ။
ဉာတပရိညာ၊ တီရဏပရိညာ၊ ပဟာနပရိညာ...လို႔ ဘုရားက သုံးခ်က္ေဟာလ်က္သားနဲ႔ ဒီတစ္ခ်က္တည္းနဲ႔ ေသာတာပန္ တည္တယ္လို႔ ေဟာေနတာဗ်... မလြဲဘူးလား။
ကိုထြန္းရင္တို႔လို အလြယ္ႀကိဳက္ဆိုလို႔ရွိရင္ အဲဒီဆရာထံ သြားၿပီး ဦးတိုက္လိမ့္မယ္။ ဦးတိုက္ရင္ ငါးပါးေမွာက္ၿပီ၊ မေမွာက္ ေပဘူးလား .. (တင္ပါ့ဘုရား)။

ခႏၶာငါးပါးအေၾကာင္းအက်ိဳးတရား

ကဲ ... ဒါျဖင့္ ခင္ဗ်ားတို႔ ေယာက္်ားလား၊ မိန္းမလား၊ အေၾကာင္းအက်ိဳးလားလို႔ ေမးလို႔ ရွိရင္ .... (အေၾကာင္းအက်ိဳး ျဖစ္ပါတယ္ ဘုရား)။
အေၾကာင္းအက်ိဳးပဲရွိတယ္။ ခႏၶာငါးပါးလုံးဟာ အေၾကာင္း အက်ိဳးခ်ည္းပဲရွိတယ္။ သေဘာက်ရဲ႕ လား .. (တင္ပါ့ဘုရား)။
႐ူပကၡႏၶာလည္း ကမၼအေၾကာင္းရွိတယ္။ မရွိဘူးလား ... (ရွိပါတယ္)၊ ဒီကဥစၥာလည္း ဥပနိႆယအေၾကာင္း မရွိဘူးလား .. (ရွိပါတယ္)၊ ဒါေၾကာင့္ အေၾကာင္းအက်ိဳးေတြေပါ့။ ပုဂၢိဳလ္သတၱဝါ ေတြ႕သလား .... (မေတြ႕ပါဘုရား)၊ ဘာေတြ႕ေနသလဲ .... (အေၾကာင္းအက်ိဳးေတြ ေတြ႕ေနပါတယ္ဘုရား)။
အေၾကာင္းအက်ိဳးပဲ ေတြ႕မယ္။ ဘယ္ကမ်ား လာပါလိမ့္ မတုန္းဆိုေတာ့၊ ငါ ဒီအေၾကာင္း ေၾကာင့္ ဒီအက်ိဳး ျဖစ္တာခ်ည္းပဲ။ ဘယ္ကမွ မလာဘူး၊ လာရဲ႕လား ... (မလာပါဘုရား)။
ဘယ္ျဗဟၼာႀကီးကမ်ား ဖန္ဆင္းလႊတ္လိုက္တာ ဟုတ္ေသး ရဲ႕ လား ... (မဟုတ္ပါဘုရား)။
ထာဝရဖန္ဆင္းလႊတ္လိုက္တာမ်ား ဟုတ္ေသးရဲ႕လား... (မဟုတ္ပါဘုရား)။
သူ႔အေၾကာင္းနဲ႔ သူ အက်ိဳးျဖစ္ေနတာဆိုေတာ့ ဝိစိကိစၧာ ေသ၊ မေသစဥ္းစားစမ္းပါ. (ေသပါတယ္ ဘုရား)။
ေသၿပီေနာ္ ... ေသၿပီလား .... (တင္ပါ့)၊ ေသၿပီ။ ဒါဟာ အသိနဲ႔ ေသၿပီ၊ အသိနဲ႔ေသပါၿပီ ...တဲ့။

႐ုပ္နာမ္ထဲမွာ ငါမပါ

ကိုင္း ... ဒါျဖင့္ ဦးသံဒိုင္ ေမးရဦးမယ္။ အေၾကာင္းထဲမွာ လည္း ေဟာဒီအေၾကာင္းက အာ႐ုံ ဆိုေသာေၾကာင့္ အာ႐ုံဆိုတာ သိၿပီးသား ျဖစ္ေနတယ္။ ႐ူပကၡႏၶာ ႐ုပ္တရား။ ဒီအေၾကာင္းကလည္း ႐ုပ္တရား။ ဒါက နာမ္တရား။ ငါဘယ္ထဲ ဝင္သတုန္း၊ ႐ုပ္ထဲမွာ ငါပါေသးသလား ... (မပါ,ပါ)၊ နာမကၡႏၶာေလးပါးထဲမွာေကာ... (မပါ,ပါ)၊ အင္း ... ဒီအေၾကာင္း ျဖစ္တဲ့ ႐ူပကၡႏၶာထဲမွာ ... (မပါ,ပါ)၊ ဒါဟာ ဒိ႒ိစင္ၿပီ။ ငါမပါဘူးလို႔ ေသေသခ်ာခ်ာသိလို႔ ... ။
ခႏၶာငါးပါးထဲ ငါပါေသးသလား ... (မပါ, ပါဘုရား)၊ မပါ တာက ဘာစင္သြားသတုန္း ... (ဒိ႒ိစင္သြားပါတယ္)၊ ဒိ႒ိစင္ သြားတာ ရွင္းၿပီလား။ ငါမပါတာက ဒိ႒ိစင္တာ။ ဘယ္က လာပါလိမ့္ မတုန္းလို႔ သံသယရွိတာက ဝိစိကိစၧာရွိတာ၊ ခုေတာ့ ဘယ္ကမွ မလာဘူး၊ အေၾကာင္းနဲ႔ အက်ိဳးနဲ႔ ေပၚေနတယ္ဆိုေတာ့ ဒိ႒ိဝိစိကိစၧာ ေသၿပီ လား၊ ႏွစ္ခ်က္ ေသၿပီလား၊ ဒိ႒ိေရာ ေသၿပီလား ... (တဒဂၤေတာ့ ေသပါၿပီဘုရား)။
တဒဂၤေသၿပီ ...၊ ဝိစိကိစၧာေရာ တဒဂၤေသၿပီလား၊ တဒဂၤ ေသမွာပဲ ဉာတရွိေသးတာ...၊ တီရဏေတာင္ တဒဂၤရွိေသးတယ္ ပဟာနက်မွ အကုန္ေသမွာကိုးဗ်။
အဲ ... တီရဏ က်ေအာင္ေတာ့ က်ဳပ္လမ္းျပမယ္ေလ၊ ပဟာနက်ေတာ့ ကိုယ့္ဟာကိုယ္ ပြားယူ၊ မဟုတ္ဘူးလား...။
