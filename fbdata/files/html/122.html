မွန္းေျခေပါက္အလုပ္ အပိုင္း(၂)
(၁၀-၃-၆၁)

#ကထိန္ေရစက္ခ်တရားေတာ္ အပိုင္း(၂)
(၂၂-၁၁-၆၁)

ဦးသန္းေမာင္ သိပ္အဖိုးတန္တယ္.. (အဖိုးတန္ပါတယ္ ဘုရား)

အားလုံး တကာတကာမေတြက ဝမ္းေျမာက္ၾကနဲ႔ေနာ္.. (မွန္ပါ့ဘုရား) တစ္သက္မွ တစ္ခါလႉရတဲ့ အသဒိသ ဒါနအလႉနဲ႔ အတူတူပဲ ... (မွန္လွပါဘုရား)။
ကိုင္း ... ဒါျဖင့္ ဘုန္းႀကီးတို႔ တကာတကာမေတြကို လမ္းျပေကာင္းနဲ႔ ႀကဳံျပန္ေတာ့လဲ ဒကာသစ္ေရ .. ေနာက္လိုက္ေကာင္းတယ္ ... (မွန္လွပါဘုရား) လမ္းျပ ေကာင္း ခြၽတ္ယြင္းခ်က္ ရွိေနျပန္ေတာ့လဲ ေနာက္လိုက္ ေခ်ာ္ၾကတယ္ .. (မွန္ပါ့ဘုရား) လဲၾက, ကြဲၾကေပါ့ဗ်ာ ... (မွန္ပါ)။
အဲ ... ယခုအခ်ိန္မွာျဖင့္ အလြန္အဖိုးတန္ေသာ လမ္းျပေကာင္းနဲ႔လဲ ေတြျပန္၊ ေနာက္လိုက္ေတြကလဲ ေခ်ာ္မက် ဘဲနဲ႔ ေျဖာင့္ေျဖာင့္ လိုက္ျပန္ေသာေၾကာင့္ ငါတို႔သည္ ဝ႗္ဒုကၡ ကြၽတ္တဲ့ ဝိဝ႗သံဃိက ဒါနအလႉႀကီးျဖင့္ အထေျမာက္ ၿပီေပါ့.. ဆိုၿပီးသကာလ ဒီဥစၥာျဖင့္ သမထ ဝိပႆနာ ၿခံရံတဲ့ အလႉႀကီး ျဖစ္ေသာေၾကာင့္လဲ ဝိဝ႗အစစ္ ျဖစ္ပါတယ္ ... (မွန္လွပါဘုရား)။
အဂၤုတၱိဳရ္ပါဠိေတာ္ႀကီးမွာ ဒီအတိုင္းလာေတာ့ ေလးေလး စားစားနဲ႔ ေၾသာ္ .. ငါးမူး တစ္က်ပ္ထည့္ႏိုင္တဲ့ ပုဂၢိဳလ္ေတာင္မွ လဲပစၥည္းက မနည္းဘူး အက်ိဳးေပးနိဗၺာန္တိုင္တိုင္ တစ္ခါတည္း ဉာဏ္အျမင္နဲ႔ ေရာက္ေအာင္ ဝ႗္ႀကီး ႐ြံမုန္းၿပီး လႉတဲ့အလႉျဖစ္ ေသာေၾကာင့္ ဝိဝ႗ ျဖစ္ေလ ေသာေၾကာင့္လဲ တကာတကာမတို႔ ပစၥည္းလိုရင္း မဟုတ္ဘူး၊ စိတ္ထား မြန္ျမတ္ဖို႔ လိုရင္းပါပဲ .. (မွန္ပါဘုရား) ရွင္းၾကပလား .. (ရွင္းပါၿပီဘုရား)။
အင္း ... တကာတကာမေတြက ခႏၶာကိုယ္ႀကီး ေရွ႕ဘယ္စခန္းနဲ႔ ဘယ္လမ္းမ်ား ျမန္းၾကဦးမယ္ ဆိုတာလဲ ခႏၶာက သြားလ်က္ကိုးဗ် ... (မွန္လွပါဘုရား) အင္း ... ခႏၶာႀကီးက ယခုအခါ အိုလမ္း ကေနၿပီး နာလမ္းကိုျဖင့္ အေရာက္ေျပးေနၾက ၿပီ.. (မွန္လွပါဘုရား)။ ။
တကာတကာမတို႔ အခု အိုလမ္းကေနၿပီး ဘယ္လမ္းကို သြားေနၾကသတုံး ... (နာလမ္း သြားေနပါတယ္ဘုရား) တားပါလားဗ်..(မရပါဘုရား) ဘာရမတုံး.. အဝိဇၨာပစၥယာ ပုညာဘိသခၤါရ လုပ္ခဲ့တာကိုး .. (မွန္လွပါဘုရား) အဝိဇၨာ ပစၥယာ ... (ပုညာဘိသခၤါရ လုပ္ခဲ့ပါတယ္ဘုရား)။
အဲဒီေတာ့ ပုညာဘိသခၤါရာ အထက္နားက အုပ္ခ်ဳပ္ ေနတာက အဝိဇၨာပစၥယာ.. (မွန္လွပါ) ေၾသာ္ ... မသိလႉ လႉခဲ့တယ္ .. (မွန္လွပါဘုရား) ဘယ့္ႏွယ္ဆိုပါ့မလဲ ... (မသိလႉ လႉခဲ့ပါတယ္ဘုရား)။
မသိတာက အဝိဇၨာ၊ လႉတာက သခၤါရဆိုေတာ့ မသိတာ အုပ္ခ်ဳပ္ၿပီး လႉလိုက္တဲ့အတြက္ .. တဲ့၊ တကာတကာမေတြကမွာ ယခု တပည့္ေတာ္တို႔ အိုတဲ့အထဲမွာ နာလမ္း ေျပးရေတာ့ ကိုယ္က်ိဳးျဖင့္ လွလွႀကီး နည္းေပါ့ဘုရား ... (မွန္လွပါဘုရား)။
အိုတဲ့ ခႏၶာကိုယ္ႀကီးဟာ ဘယ္ေျပးေနရသလဲ ... (နာလမ္း ေျပးေနရပါတယ္ ဘုရား) နာလမ္းကို ေျပးေနရျပန္ေတာ့ ဘုန္းႀကီးတို႔ တကာတကာမေတြက အစ, ကလဲ မေကာင္း, အလယ္မွလဲ မေကာင္းဘဲနဲ႔ ကိုယ္က်ိဳးနည္းေနၾကတယ္ ... (မွန္လွပါဘုရား)။ ။
ဘယ္ႏွယ့္ေၾကာင့္ ကိုယ္က်ိဳးနည္းရသလဲ၊ ကံမေကာင္း အေၾကာင္းမသင့္လို႔ နည္းရတယ္လို႔ သူမ်ားက ဆိုလို႔ရွိရင္ မယုံၾကပါနဲ႔ .. (မွန္လွပါ) အဝိဇၨာပစၥယာ ပုညာဘိသခၤါရာ၏ ဒဏ္ခ်က္ေဟ့.. (မွန္လွပါ ဘုရား)။
ဘယ့္ႏွယ္မွတ္ၾကမယ္ ... (အဝိဇၨာပစၥယာ ပုညာဘိ သခၤါရာ၏ ဒဏ္ခ်က္ပါဘုရား) အဝိဇၨာပစၥယာ ပုညာဘိသခၤါရာ ၏ ဒဏ္ခ်က္ေၾကာင့္ ယခုျဖင့္ အိုေဘးႀကီး ထမ္းၿပီးသကာလ နာေဘးရွိရာ ေျပးရတယ္ .. (မွန္လွပါဘုရား) အိုေဘးႀကီး ထမ္းၿပီး .. (နာေဘးရွိရာ ေျပးရပါတယ္ ဘုရား) ေျပးခ်က္ ဆိုးလွခ်ည္လား ... (ဆိုးပါတယ္ဘုရား) ထမ္းရတာ ဘာေဘး တဲ့လဲ... (အိုေဘးပါ ဘုရား)။
အိုေဘး ခႏၶာႀကီးေနာ္ .. (မွန္ပါ) ေျပးလို႔ ေရာက္မည့္ ေနရာက ဘယ္ေနရာလဲ. (နာေဘးရွိရာပါ ဘုရား) နာေဘးစုံ ေနတဲ့ေနရာ .. (မွန္ပါ့) အမယ္ေလး ... တစ္ခ်က္မွလဲ မေကာင္းပါလား.. (မေကာင္းပါဘုရား) ေပၚၾကပလား .. (ေပၚပါၿပီဘုရား) ဒါျဖင့္ ဒီနာေဘးႀကီးရွိရာျဖင့္ တကာ တကာမေတြ ဘုန္းႀကီးလဲ မကယ္ႏိုင္ဘူး...(မွန္လွပါ) ဘာ့ေၾကာင့္တုံး ဆိုေတာ့ အဝိဇၨာပစၥယာ ပုညာဘိသခၤါရာရဲ. ဒဏ္ခ်က္ သင့္ေနတယ္ ... (မွန္လွပါဘုရား) ရွင္းပလား .. (ရွင္းပါၿပီ ဘုရား)။
ဘယ္သူ႔ ဒဏ္ခ်က္ သင့္ပါလိမ့္ .. (အဝိဇၨာပစၥယာ ပုညာဘိ သခၤါရာ၏ ဒဏ္ခ်က္ သင့္ပါတယ္ ဘုရား) ေၾသာ္ ..ေနာက္ထပ္ အသင့္ျဖင့္ မခံၾကပါနဲ႔၊ လိမၼာၾကပါေတာ့ဆိုတဲ့ အဓိပၸာယ္ကို ဆရာဘုန္းႀကီးက သတိေပးလိုက္တယ္ .. (မွန္ပါဘုရား) လိမၼာေတာ့မလား .. ဒါျဖင့္ .. (လိမၼာ ပါေတာ့မယ္ ဘုရား)။
လိမၼာရမယ္ .. (မွန္ပါ့) အခု အိုေဘးထမ္းၿပီး နာေဘး ရွိရာ ေျပးရေတာ့မယ္ဆိုေတာ့ ရပ္လို႔လဲမရ၊ ဆီးလို႔လဲ မရ .. ခနာ့ထုံးစံအတိုင္း ျဖစ္ေနတယ္.. (မွန္ပါ့ဘုရား)။
ဒါျဖင့္ တကာတကာမတို႔သည္ အိုေဘးထမ္းၿပီး နာေဘး ရွိရာ ေျပးရေတာ့ အင္း.. ဒီမီးပုံက ေသးတာနဲ႔ ဟိုမီးပုံႀကီးထဲ ေျပးလိုက္ဦးမယ္ဆိုတဲ့ အဓိပၸာယ္ ေရာက္ပါတယ္.. (ေရာက္ပါ တယ္ဘုရား) မေရာက္ဘူးလား .. (ေရာက္ပါတယ္ဘုရား)။
ေၾသာ္ .. ဉာဏ္နဲ႔ ေတြးၾက, ဉာဏ္နဲ႔ေတြးၾက တကာ တကာမတို႔ ခႏၶာလမ္းစဥ္က ဤလမ္းစဥ္မွတစ္ပါး ဘယ္မွ မေ႐ြ႕ ဘူး..(မွန္ပါ့ဘုရား) ေ႐ြ႕ၾကရဲ႕လား..(မေ႐ြ႕ၾကပါဘုရား)။
အခု ဘယ္လမ္းသြားေနၾကသလဲ .. (နာလမ္းသြားေန ပါတယ္ဘုရား) ဘာေတြ ထမ္းသြားၾကသလဲ.. (အိုေဘးထမ္း သြားပါတယ္) အိုေဘးထမ္းၿပီး နာေဘးရွိရာ ေျပးတယ္ ... (မွန္လွပါ) လြန္လွခ်ည္လား တကာတကာမတို႔ .. (မွန္ပါ့ ဘုရား)။
ကံမေကာင္း အေၾကာင္း မသင့္လို႔လား၊ အဝိဇၨာပစၥယာ ပုညာဘိသခၤါရာေၾကာင့္လား ... (အဝိဇၨာ ပစၥယာ ပုညာဘိ သခၤါရာေၾကာင့္ပါဘုရား) အ, ပုညာဘိသခၤါရကို မေဟာရဲေသး ဘူး..(မွန္လွပါ) ပုညာဘိသခၤါရာကိုပဲအေတာ္ဆိုးေနၿပီ.. (မွန္ပါ့၊ ဆိုးပါတယ္ဘုရား)။
အဝိဇၨာ အုပ္ခ်ဳပ္တဲ့ ကုသိုလ္ႀကီး ဒကာႂကြယ္တို႔က ေနာက္တုန္းက ခပ္ၿပဳံးၿပဳံးကေလး လုပ္ခဲ့တာ အခုေတာ့ မဲ့ၿပီး ခံရတယ္ ... (မွန္လွပါဘုရား) ေရွးက ဘယ္လိုလုပ္ခဲ့ပါလိမ့္ .. (ခပ္ၿပဳံးၿပဳံးကေလး လုပ္ခဲ့ပါတယ္ဘုရား)။
အဝိဇၨာပစၥယာ သခၤါရာ ငါလူခ်မ္းသာ ရေအာင္လုပ္မယ္ဟ ဆိုၿပီးသကာလ ခပ္ၿပဳံးၿပီး လုပ္ခဲ့တာ အခုေတာ့ ဒကာႂကြယ္ႀကီး သြားက်ိဳး, ဆံျဖဴ မ်က္လုံးကလဲမြဲနဲ႔ မဲ့ေနပါေပါ့ကလား ... (မွန္ပါ့ဘုရား) မမဲ့ရေသးဘူးလား .. (မွဲ႔ရပါတယ္ဘုရား)။ -
အင္း ... ဟင္ ... ဘယ့္ႏွယ္ေၾကာင့္ မဲ့ရပါလိမ့္မတုံး .. ဆိုၿပီး အေၾကာင္းရွာေတာ့ ဘာေတြပါလိမ့္.. (အဝိဇၨာ ပစၥယာ ပုညာဘိ သခၤါရာ ေတြပါတယ္ဘုရား) ေသေသခ်ာခ်ာ မွတ္ပါ၊ အဝိဇၨာ ပစၥယာ ပုညာဘိသခၤါရာဆိုတာ ဦးသန္းေမာင္ အေတာ္ဆိုးတယ္ ... (မွန္လွပါဘုရား) ရွင္းၾကပလား .. (ရွင္းပါၿပီဘုရား)။

လူေတာ့ ခင္ပါရဲ႕၊ နံလိုက္တာ လြန္ေရာ ... (မွန္ပါ ဘုရား) ေျပာၾကတယ္.. (ေျပာပါတယ္ ဘုရား) လူမမာနားမွာ တိုးတိုး တိုးတိုးေျပာတာက မရေတာ့ဘူးထင္တယ္ ေျပာတာေနာ္ ..(မွန္လွပါ ဘုရား) ရိပ္မိၾကပလား .. (ရိပ္မိပါၿပီဘုရား)။
လူမမာနားမွာ တိုးတိုး, တိုးတိုးေျပာတာ ဘာထင္သတုံး (မရေတာ့ဘူး ထင္တယ္ ေျပာတာပါ ဘုရား) သူ႔ေရွ႕မို႔ သာ ေကာင္းေအာင္ ေျပာလိုက္ရတယ္၊ က်ဳပ္မထင္ဘူး .. (မွန္လွပါဘုရား) ဒီအသံေတြေကာ က်က္သေရရွိတဲ့ အသံလား, က်က္သေရမရွိတဲ့ အသံလား .. (က်က္သေရမရွိတဲ့ အသံပါ ဘုရား)။
ဒါက တစ္ေယာက္တည္းလား၊ မိတ္ေဆြမ်ား, မ်ား သေလာက္ လူသိခံရတာလား .. (မိတ္ေဆြမ်ား သေလာက္ လူသိခံရတာပါဘုရား) ဒါျဖင့္ အရွက္တကြဲ အက်ိဳးနည္းပဲ ဆိုရင္ေကာ .. (ဆိုႏိုင္ပါတယ္ ဘုရား) သေဘာပါပလား ... (ပါ, ပါၿပီဘုရား) နာပြဲဆိုတာ အရွက္တကြဲ အက်ိဳးနည္းပြဲ ... (မွန္လွပါ ဘုရား)။
အဲဒါ ခင္ဗ်ားတို႔ လြတ္ေအာင္ ေျပးႏိုင္ပါ့မလား၊ ဒီဘဝမွာ .. (မေျပးႏိုင္ပါဘုရား) ေၾသာ္ .. ဒါက သူမ်ားေပးလို႔ ရတာလား၊ ကိုယ့္ကိုယ္တိုင္ လုပ္ယူတာလား၊ အကဲခတ္ၾကစမ္းပါဦး.. (ကိုယ့္ကိုယ္တိုင္ လုပ္ယူတာပါဘုရား)။
ကဲ.. ပါဠိ႐ြတ္ပါ..(အဝိဇၨာပစၥယာ ပုညာဘိသခၤါရာ ပါဘုရား) ဟာ ... ေၾကာက္စရာ သိပ္ေကာင္းပါကလား .. ခင္ဗ်ားတို႔ဥစၥာ ... (မွန္ပါဘုရား)။
“ အဝိဇၨာ နိေရာဓာ သခၤါရ နိေရာေဓာ " ရွိပါလ်က္ သားနဲ႔ တဒဂၤ နိေရာေဓာလဲရွိတယ္၊ ဝိကၡမၻနနိေရာေဓာ ရွိတယ္၊ သမုေစၦဒ နိေရာေဓာလဲ ရွိတယ္၊ တဒဂၤနိေရာေဓာေတာင္ မလုပ္ခဲ့တဲ့ အတြက္ တဒဂၤကေလး အဝိဇၨာခ်ဳပ္ေအာင္ မလုပ္ခဲ့ တဲ့အတြက္ ဒီပြဲႀကီးျဖင့္ ဦးသန္းေမာင္ လွလွႀကီး ႏႊဲေပေတာ့ ... (မွန္လွပါဘုရား) မႏႊဲရေပဘူးလား ... (ႏႊဲရပါတယ္ဘုရား) ရွင္းၿပီေနာ္ ... (ရွင္းပါၿပီ ဘုရား)။
ကဲ ... နာပြဲႀကီးကေနၿပီး ဒီခႏၶာႀကီးက အိပ္ရင္းသြား လိမ့္မယ္ေနာ္ .. (မွန္ပါဘုရား) အိပ္ရင္း ဘယ္သြားမတုံးဆို က်ဳပ္ေတာ့ျဖင့္ ေသပြဲသြားလိုက္ဦးမယ္ .. (မွန္ပါဘုရား) ပက္လက္သြားတာ၊ ေရထဲ ပက္လက္ကူးသလို .. (မွန္ပါ) ေရထဲပက္လက္ကူးေတာ့ပက္လက္ပဲေရစုန္မွာ ေမ်ာရသလို... (ေမ်ာရမွာပါ ဘုရား)။
ဒီမွာလဲ တကာတကာမတို႔ ဒီဗ်ာဓိ ခႏၶာကိုယ္ႀကီးဟာ မရဏဘက္ ပက္လက္ ေမ်ာတယ္.. (မွန္ပါ့ဘုရား) ေကြးေနတဲ့ ပုဂၢိဳလ္ဟာ ေကြးရင္း ေမ်ာသြားတယ္ ..(မွန္ပါ) ဘယ္ဆီေမ်ာ သြားသတုံး ဆိုေတာ့ မရဏေရထဲ ေမ်ာပါတယ္.. (မွန္ပါဘုရား) ရွင္းပလား .. (ရွင္းပါၿပီဘုရား)။ ။
တကာတကာမေတြက ဘယ္ေရထဲ ေမ်ာၾကမယ္ ထင္သ တုံး ... (မရဏေရထဲ ေမ်ာပါမယ္ ဘုရား) အင္း .. တကာ တကာမတို႔ နဂိုက နာပြဲထက္ ေသပြဲတိုးေတာ့မယ္ .. (မွန္ပါ့ဘုရား) နာပြဲထက္ .. (ပြဲတိုးပါေတာ့မယ္ ဘုရား)။
ဒီေသပြဲႀကီးကေတာ့ သားေတြ သမီးေတြနဲ႔ကြဲ, ပစၥည္းေတြ နဲ႔ကြဲ, ရွာထားတာေတြနဲ႔ကြဲ၊ ခ်စ္မႈ, ခင္မႈ, ၾကင္နာမႈေတြနဲ႔ - အလုံးစုံ အကုန္ သပိတ္ေမွာက္ၿပီး ကြဲၾကတယ္..(မွန္ပါ့ဘုရား) ဉာဏ္ကလဲ မပါေတာ့ မ်က္ရည္စက္လက္နဲ႔ပဲ ကူးတယ္ .. (မွန္ပါ့ဘုရား)။
ေနျခင္းဆိုး ေနခဲ့လို႔ ေသျခင္းဆိုး ေသရၿပီဆိုတဲ့ ကံ ကမၼနိမိတ္ ဂတိနိမိတ္ထင္လာလို႔ မ်က္ရည္စက္လက္နဲ႔ ပြဲကလဲ ေတြ႕ရဦးမယ္..(မွန္ပါ့, ေတြ႕ရပါဦးမယ္) မဆိုး႐ြားဘူးလား.. (ဆိုး႐ြား ပါတယ္ဘုရား)။
အဲဒါေတြ ဉာဏ္နဲ႔ ရွင္းၾကည့္လိုက္တဲ့အခါက်ေတာ့မွ အင္း ... ဒီနာပြဲႀကီး မ်က္ရည္စက္လက္ ကိုယ္ကိုယ္တိုင္က်ၿပီ ကံ ကမၼနိမိတ္ ဂတိနိမိတ္ေတြထင္လို႔ ေခြးနက္ႀကီးတို႔၊ ငရဲမီးတို႔က ျမင္လာေတာ့ ဦးသန္းေမာင္ေရ ငါ ေနျခင္းဆိုး ေနခဲ့တဲ့အတြက္ ေသျခင္းဆိုးဟာလဲ ငါပဲဟ ဆိုၿပီး မ်က္ရည္က်တယ္ (မွန္လွပါဘုရား) ဘယ္လိုပါလိမ့္ .. (ေနျခင္းဆိုးေနခဲ့လို႔ ေသျခင္းဆိုးဟာ ငါပဲဆိုၿပီး မ်က္ရည္ က်ပါတယ္ ဘုရား)။
ဒကာႂကြယ္ ေနျခင္းဆိုးေနခဲ့လို႔ ေသျခင္းဆိုးေသရတာ က်ဳပ္ပါပဲဆိုၿပီး ေခါင္းအုံးေပၚ မ်က္ရည္ႏွစ္ဖက္ စီးက်တယ္.. (မွန္ပါဘုရား) ကံ ကမၼနိမိတ္ ဂတိနိမိတ္ ထင္သကိုးဗ်.. (မွန္ပါဘုရား) ေခြးနက္ႀကီးတို႔ ေတာင္ႀကီးတို႔ ေခ်ာက္ႀကီးေတြ, က်င္းႀကီးေတြ, ငရဲမီးႀကီးေတြ ထင္လာတယ္၊ မ်က္ရည္ေတြ မက်ေပဘူးလား ... (က်ပါတယ္ဘုရား)။
အဲဒီက်ေတာ့မွ သူ႔ဟာသူ ေတြးလိုက္တယ္၊ ေၾသာ္ ... ေနျခင္းဆိုးေနခဲ့လို႔ ေသျခင္းဆိုးျဖင့္ ငါကိုယ္တိုင္ ႏႊဲရပါေပါ့လား ဆိုၿပီး မ်က္ရည္က်တယ္ .. (မွန္ပါဘုရား) မဆိုး႐ြားဘူးလား .. (ဆိုး႐ြားပါတယ္ ဘုရား)။
အလ်င္ေတာ့ သူတစ္ပါးက တံေတြးေထြး႐ုံပဲ၊ အခုေတာ့ ကိုယ့္မ်က္ရည္ပြဲနဲ႔ကိုယ္ ႏႊဲၿပီးသကာလ ေနရပါၿပီ .. (မွန္ပါ ဘုရား) ေကာင္းၾကေသးရဲ႕လား.. (မေကာင္းပါဘုရား)။
ဘယ့္ႏွယ္ေၾကာင့္ ဒီ မေကာင္းတာႀကီး ကံမေကာင္း အေၾကာင္းမသင့္လို႔ ေတြ႔ရတာလား တကာတကာမတို႔၊ ကိုယ္ကိုယ္တိုင္ အရယူတာလား .. (ကိုယ္ကိုယ္တိုင္ အရယူတာပါ ဘုရား)။
ေၾသာ္ .. ဒါျဖင့္ ပါဠိေတာ္႐ြတ္, ပါဠိေတာ္႐ြတ္ .. (အဝိဇၨာပစၥယာ ပုညာဘိ သခၤါရာပါဘုရား) မေမ့ဘူး, မေမ့ဘူး၊ ဒီကထိန္ပြဲမွာ ဒီတစ္လုံးကေတာ့ျဖင့္ မေမ့ေတာ့ဘူး ခင္ဗ်ားတို႔ ... (မွန္ပါ့ဘုရား)။
ဒါလုပ္ခဲ့တဲ့အတြက္ ဤကဲ့သို႔ ေသပြဲႀကီးကို မ်က္ရည္ စက္လက္နဲ႔ ႏႊဲရျခင္းသည္ ဦးသန္းေမာင္ သိပ္အ႐ုပ္ဆိုးပါကလား ..(ဆိုးပါတယ္ ဘုရား) သေဘာက်ပလား ..(မွန္ပါဘုရား)။
ကိုင္း.. လိုက္ဆိုၾက တကာတကာမတို႔..
“ တပည့္ေတာ္ တပည့္ေတာ္မတို႔သည္ ေသပြဲႀကီးကို ကိုယ္ကိုယ္တိုင္ ႏႊဲရမည္ကို မရဏဒုကၡဟု အမွန္သိ, တကယ္သိသည္ ျဖစ္ပါ၍ ဤဒုကၡတို႔၏ လြတ္ရာ အမတ, ဆိုေသာ မေသရာမွန္ ျပည္နိဗၺာန္ ကိုသာ ေရာက္ျခင္း ရျခင္း, ဆႏၵ ျပင္းျပသည္ ျဖစ္ပါ၍ ဤကထိန္လ်ာ သကၤန္းကို အၿခံအရံႏွင့္တကြ သံဃာေတာ္ျမတ္တို႔အား လႉဒါန္းပါ၏ အရွင္ဘုရား.. ။”
