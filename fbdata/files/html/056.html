#သႏၲာပေ႒ာ အပိုင္း(၃)
တရားနာရင္း ကြၽတ္တမ္းဝင္နည္း

ဒုကၡသစၥာ၏ အနက္ (၃)သႏၲာပေ႒ာ
ေဟာၾကားသည့္ေန႔ (၉-၁၂-၅၇)

ေက်းဇူးေတာ္ရွင္အဂၢမဟာပ႑ိတ
မိုးကုတ္ဆရာေတာ္ဘုရားႀကီး မႏၲေလးၿမိဳ႕၌ ေဟာၾကားေတာ္မူေသာ တရားေတာ္

ေနာက္ျပန္တက္လာတယ္ဆိုတာက ဟိုေနာက္ဘုရားေပါင္းဘယ္ ေလာက္ၾကာမွ ျပန္တက္မယ္လို႔ က်ဳပ္မေျပာတတ္ဘူးေပါ့ဗ်ာ၊ အခုျဖင့္ ေနာက္လာစရာ မျမင္ေသးဘူး၊ အေတာ္ခဲယဥ္းပါတယ္၊ အေတာ္လည္းခဲယဥ္း ရပါတယ္။

လက္ရွိအခ်ိန္ကေလး မဆုံးရႈံးေစနဲ႔

အဲဒီေတာ့ အခုလက္ထဲေရာက္ေနတဲ့ အခ်ိန္ကေလး မဆုံးရႈံးေစခ်င္ ဘူး၊ သစၥာတရားနာမႈနဲ႔ သစၥာတရားပြားမႈကို မစြန႔္ပါနဲ႔၊ စြန႔္လို႔ရွိရင္ျဖင့္ ခင္ဗ်ား တို႔ကိုယ္က်ိဳးမကပါဘူး၊ ခင္ဗ်ားတို႔ အကုန္ ဆုံးမယ္ဆိုတာ ဦးဘအုန္း ဆုံးျဖတ္ ခ်က္ခ်ပါ၊ မဆိုထိုက္ဘူးလား ... (ဆိုထိုက္ပါတယ္ဘုရား)။ အဲဒီေတာ့ ခင္ဗ်ားတို႔ ဒါပဲအားကိုးစရာရွိတယ္။
ေ႐ႊေတြ၊ ေငြေတြ၊ စိန္ေတြ၊ ေက်ာက္ေတြ၊ ျမေတြဆိုတာက ခင္ဗ်ားတို႔ အေရးႀကီးတဲ့အခါ ေဝဒနာတစ္ခုသက္သာေအာင္ မတတ္ႏိုင္ပါဘူး၊ အိုမင္း ရင့္ေရာ္သြားတာေလးနည္းနည္းမွ မတတ္ႏိုင္ ပါဘူး၊ နာတာေလးေကာ (မတတ္ႏိုင္ပါဘုရား)။
ေသခန္းက်ေတာ့ ဒါေတြက အကူအညီေတြရေသးသလား (မရ ပါဘုရား) မရတဲ့အျပင္ ထိုးခ်လိုက္တယ္၊ မထိုးခ်ဘူးလား ... (ထိုးခ်ပါ တယ္ဘုရား)။

မိမိအားထုတ္တဲ့တရားသာ၊ အားကိုးပါ

အဲဒီေတာ့ အားကိုးရာအစစ္က “အတၱာဟိ အတၱေနာ နာေထာ” ဆိုတဲ့အတိုင္း မိမိ အားထုတ္တဲ့ တရားကိုသာလ်င္ မိမိအားကိုးရေတာ့မွာပါ လားဆိုတာ ယေန႔ဆုံးျဖတ္ခ်က္ခ်၊ အားလုံး ဒကာ ဒကာမေတြ၊ ဘာမွ အားကိုးစရာမရွိဘူး၊ ဘုန္းႀကီးဆီနာထားတဲ့တရားရယ္၊ ခင္ဗ်ားတို႔ကိုယ္တိုင္ ပြားတာေလးရယ္၊ ဒါပဲအားကိုးစရာရွိတယ္၊ က်န္တာကေတာ့ ... (အားကိုးစရာမရွိပါဘုရား)။
အားကိုးစရာမရွိဘူးဆိုသျဖင့္၊ ဒါအပါယ္ေလးပါးလည္း တံခါးပိတ္ တယ္၊ အားကိုးစရာ အစစ္လည္းျဖစ္တယ္ဆိုေတာ့ ခင္ဗ်ားတို႔ ဒါကို ႀကိဳးစား ပါဆိုတာ အထူးတိုက္တြန္းေနတာ အေတာ္ ၾကာသြားၿပီဗ်။ ဒီလိုတိုက္တြန္းရ တာ၊ အေၾကာင္းေတြျပရတာကတစ္မ်ိဳး၊ ခင္ဗ်ားတို႔ အျပစ္ေတြကိုေလ ေျပာျပရတာ ကတစ္မ်ိဳး (မွန္လွပါဘုရား)။
လုံေလာက္ေအာင္ေျပာရတာကတစ္မ်ိဳး၊ ေတာ္ၾကာအားကိုးမွားေန မွာစိုးရတာက တစ္မ်ိဳး လို႔ဆိုေတာ့၊ အခုေတာ့ျဖင့္ အကြက္လည္သြားၿပီ၊ ၾကည့္ ပါလား၊ မလည္ေသးဘူးလား ... (လည္ပါတယ္ ဘုရား)။ ။
ဘာအားကိုးရမွာတုံး ... (သစၥာဓမၼ အားကိုးရမွာပါ ဘုရား)၊ သစၥာ ဓမၼပြားမ်ားဖို႔အလုပ္၊ ကိုယ့္အားကိုယ္ကိုးဖို႔အလုပ္ လုပ္ပါ။

ဘယ္လိုေၾကာင့္ ဘုရားျဖစ္သတုံး

ဘုရားသည္ ဘယ္လိုေၾကာင့္ ဘုရားျဖစ္သတုံး၊ သစၥာေလးပါးသိမွ ငါဘုရားလို႔ တာဝန္ခံတယ္၊ မသိခင္တုန္းက ... (တာဝန္မခံပါဘုရား) တာဝန္မခံဘူး။
အဲဒီေတာ့ကြာ ငါဥပမာျပမယ္တဲ့ သစၥာမသိဘဲနဲ႔ ငါေသာတာပန္ ငါ သကဒါဂါမ္၊ ငါ-အနာဂါမ္ျဖစ္လာတယ္လို႔ဆိုလို႔ရွိရင္ ဒီလိုသာမွတ္ေပေတာ့တဲ့၊ ငါဟာအိမ္ေဆာက္တယ္ေဟ့ အျခင္ေတြ၊ ထုပ္ေလ်ာက္ေတြ၊ အရင္တင္တာ၊ တိုင္တစ္လုံးမွမပါဘူးလို႔ေျပာတဲ့ ပုဂၢိဳလ္နဲ႔အတူတူပဲ (မွန္ပါ့ ဘုရား)။
အျခင္ေတြအရင္တင္တယ္၊ ဒိုင္းေတြအရင္တင္တယ္ေပါ့ဗ်ာ၊ အခု ေခတ္အသုံးျဖင့္ ဒိုင္းေတြ အရင္တင္တယ္၊ ၿပီးမွ ငါတိုင္ေတြစိုက္တယ္ကြ၊ အဲဒီလိုေျပာေတာ့ ခင္ဗ်ားတို႔က ယုံၾကမွာလား ... (မယုံပါဘုရား)။

သစၥာမသိရင္ေသာတာပန္ မတည္ႏိုင္

အဲဒီအတိုင္းပဲ၊ ငါ-သစၥာမသိဘဲနဲ႔ ေသာတာပန္တည္ခဲ့တယ္ဆိုရင္ အျခင္ အရင္တင္တယ္ လို႔ေျပာတာ အ႐ူးေျပာတာနဲ႔ အတူတူပဲကြ၊ သစၥာမပါ ဘဲနဲ႔ျဖင့္ ဘယ္သူမွ မရဘူး၊ ဆုံးျဖတ္ခ်က္ခ် ပလား (ခ်ပါၿပီဘုရား)။
အင္း-ခင္ဗ်ားတို႔ကေတာ္ေတာ္ၾကာ ဘာေလးအားကိုး၊ ညာေလး အားကိုးတာနဲ႔ နိဗၺာန္ ေရာက္လိမ့္ မယ္လို႔ သြားၿပီးသကာလ၊ အထင္ႀကီးနဲ႔မ်ား အစြဲအလန္းဥပါဒါန္ႀကီးနဲ႔ လုပ္မေနနဲ႔၊ သာမညအားကိုးသာရမယ္ (မွန္လွပါ ဘုရား) ခဏနားတာပဲရမယ္၊ ျပန္က်မွာက လြတ္ပါ့မလား ... (မလြတ္ပါ ဘုရား)။
ဪ ... ဒီႏွစ္ခုသာလ်င္ ခိုကိုးရာ အားထားရာရွိေတာ့တယ္၊ သစၥာနာမႈနဲ႔ သစၥာပြားမႈ သည္ သာလ်င္ တို႔၏ ခိုကိုးရာ၊ အားထားရာ အစစ္ ပါလားဆိုတာသာ ေသေသခ်ာခ်ာမွတ္ပါ ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။
ဒါျဖင့္ သစၥာနာမႈကိုေရွးဦးစြာ ဘုန္းႀကီးေဟာမယ္၊ ၿပီးေတာ့မွ သစၥာ ပြားမႈအလုပ္ကို ဉာဏ္စဥ္နဲ႔ တက္ေပးမယ္၊ ရွင္းပလား ဒကာ ဒကာမတို႔ ... (ရွင္းပါၿပီဘုရား)။

သစၥာနာမႈကိုအရင္ေဟာမယ္

ကိုင္း ဘာမွ မပူနဲ႔၊ သစၥာဆိုတဲ့တရားက သာမညသတၱိရွိတဲ့တရား မဟုတ္ပါဘူးတဲ့၊ သူ႔ကိုမ်ား မနာရေသးဘူးဆိုလို႔ရွိရင္ျဖင့္ ငါး.. ဘုရားသခင္ ကိုယ္ေတာ္ျမတ္ ဉာဏ္အျမင္နဲ႔ မင္းတို႔ကို ဥပမာျပမယ္တဲ့ ... ။
ေအာက္မွာ (၁၃) မိုင္အနက္ထု၊ (၁၃) မိုင္ပတ္လည္ရွိတဲ့ေက်ာက္ တိုင္ႀကီးေတြစိုက္ပါ။ ဦးဘၾကည္ ... (မွန္လွပါဘုရား) အႏွစ္တစ္ရာ ၾကာမွ ကတၱီပါေလးနဲ႔ တစ္ခ်က္သာပြတ္ပါ၊ ဒီေက်ာက္တိုင္ႀကီး ဘယ္ေတာ့ ကုန္မွာ တုံးလို႔ေမးၾကည့္ရင္၊ ဘယ့္ႏွယ္ေျဖၾကမယ္ ... (မကုန္ပါ ဘုရား)။

ေက်ာက္တိုင္ႀကီးသာေပ်ာက္စရာရွိေသးတယ္

အႏွစ္တစ္ရာၾကာမွ၊ ကတၱီပါနဲ႔ တစ္ခါသာပြတ္ရမွာကိုးဗ်။ အင္မတန္ ႏူးညံ့တဲ့ကတၱီပါ၊ အဲဒါသာကုန္ရင္ ကုန္လိမ့္မယ္၊ သစၥာနားမလည္ေသးလို႔ ရွိရင္ မင္းတို႔ ဒုကၡဘယ္ေတာ့မွ မကုန္ဘူး၊ ေက်ာက္တိုင္ႀကီး ေပ်ာက္စရာရွိ ေသးတယ္၊ ကုန္စရာရွိေသးတယ္၊ မင္းတို႔ဒုကၡမကုန္ဘူးတဲ့။
သစၥာမနာရလို႔၊ သစၥာအားမထုတ္ရလို႔ရွိရင္၊ ဒီေလာက္ထိေအာင္ ဘုရားက ေဟာလို႔ရွိရင္ ဒကာ ဒကာမေတြ အေတာ္ယုံဖို႔ေကာင္းပါၿပီ၊ မယုံ ေသးဘူးလား ... (ယုံပါတယ္ဘုရား)၊ ဒါက သစၥသံယုတ္မွာ ဒီအတိုင္း လာပါတယ္ ... ကိုထြန္းဦး (မွန္လွပါဘုရား)။
ဒါ... ခင္ဗ်ားတို႔ကအေတာ္ေဟာထားတာကိုးလို႔၊ ေအာက္ေမ့မေန နဲ႔ ျဖစ္စဥ္ ကိုက္ေဟာ ထားတာ လို႔ ဆုံးျဖတ္ခ်က္ခ်ပါ၊ အေတာ္ႀကီးႀကီး က်ယ္က်ယ္ ဒို႔ကိုေျခာက္တာကိုးလို႔ မေအာက္ေမ့နဲ႔ဦး (မေအာက္ေမ့ပါ ဘုရား)။

ပီဠနေ႒ာ

အဲဒါျဖင့္ ဒကာ ဒကာမတို႔ သစၥာနာမႈသည္ အေရးအႀကီးဆုံးအလုပ္ ပဲဆိုတာေကာ ယေန႔ ေပၚပလား ... (ေပၚပါၿပီဘုရား) ေပၚလို႔ရွိရင္၊ ဒါကို ပြားမ်ားၾကစို႔လားဆိုေတာ့ ပထမေန႔တုန္းက ဦးဘၾကည္ တို႔ကိုေဟာခဲ့တယ္။
ခႏၶာငါးပါးသည္ ပီဠနေ႒ာ လို႔ေဟာခဲ့တယ္၊ အက်ိဳးနဲ႔အကန္းက ႏွိပ္ စက္တယ္၊ မေျပာ ခဲ့ဘူးလား ... (ေျပာခဲ့ပါတယ္) အက်ိဳးနဲ႔အကန္းက ခင္ဗ်ားတို႔ကိုႏွိပ္စက္ေနတယ္ဆိုေတာ့၊ ခႏၶာငါးပါးသည္ ႏွိပ္စက္တတ္တဲ့ တရား၊ ၿပီးၿပီအဲဒါမထည့္ေတာ့ဘူး။

သခၤတေ႒ာ

မေန႔က ေဟာလိုက္ေတာ့ ခႏၶာငါးပါးသည္ ဘယ္ေဘး၊ ဘယ္ဒဏ္၊ ဘယ္ရန္ မဆို သူခြဲ သြားတယ္ လို႔မရွိဘူး၊ လက္ခံတတ္တဲ့တရား၊ ဟုတ္ဘူးလား ၊ (ဟုတ္ပါတယ္ဘုရား) လက္ခံတာ အႏွိပ္စက္ခံ တဲ့တရား၊ ဒီလိုသိေတာ့ ေသာ္ ႏွိပ္စက္တတ္တဲ့တရားလည္း သူပဲ၊ အႏွိပ္စက္ ခံရတဲ့တရား ေကာ ... (သူပါပဲဘုရား)။
အင္း... ဒါျဖင့္ ပုဂၢိဳလ္သတၱဝါရယ္လို႔ျဖစ္လာလို႔ရွိရင္ ႏွိပ္စက္ဖို႔ ရယ္၊ ႏွိပ္စက္ခံ ဖို႔ရယ္ျဖစ္လာတာကိုး ... ဒုကၡသစၥာအစစ္ပါလား၊ ဒုကၡ ေရာက္ဖို႔ျဖစ္လာတာပဲ၊ ခႏၶာငါးပါးရတဲ့ ပုဂၢိဳလ္က ဘာတဲ့ (ဒုကၡေရာက္ဖို႔ပါ ဘုရား)၊ ဒါျဖင့္ ပီဠနေ႒ာနဲ႔ သခၤတေ႒ာ ေက်နပ္ေရာေပါ့ဗ်ာ ... (မွန္လွ ပါဘုရား)။
ဒုကၡသစၥာလို႔သိေစခ်င္လို႔

ဒီေန႔ေဟာမွာက သႏၲာပေ႒ာ ကိုေဟာမယ္၊ ဒီတဆယ့္ေျခာက္ခ်က္ ကေတာ့ လုပ္ရမည့္ကိစၥ (မွန္ပါ့ဘုရား) စာမွာဒီအတိုင္းလာတယ္၊ ဘုရား ေဟာတာ သေဘာက်ပလား ... (က်ပါၿပီဘုရား) ဒီတစ္ဆယ့္ေျခာက္ခ်က္ လည္း သိရမည့္ကိစၥ၊ ပြားရမည့္ကိစၥ။
ဒါျဖင့္ ဒကာ ဒကာမတို႔ ဒီတရားေလးကို ပြားမ်ားရမယ့္ကိစၥဟာ ဒုကၡသစၥာကို ဒုကၡသစၥာ လို႔သိေစခ်င္တဲ့ အက်ိဳးငွာ၊ ဘုန္းႀကီးတို႔ ဒကာ ဒကာမ ေတြကို ဘုရားသခင္ ကိုယ္ေတာ္ျမတ္ႀကီး သည္ သစၥာအနက္ (၁၆)ခ်က္ကို ေဟာတာ၊ မေဟာဘူးလား ... (ေဟာပါတယ္ ဘုရား)။

ဒုကၡသစၥာ၏အနက္ သႏၲာပေ႒ာ

ဒီေန႔ “သႏၲာပ” ဆိုတာကို ေဟာလိမ့္မယ္၊ ပါဠိလိုေတာ့ “သႏၲာပေ႒ာ” ျမန္မာလိုေတာ့၊ ခင္ဗ်ားတို႔ခႏၶာကိုယ္ႀကီး မီးေလာင္ေနတာ၊ မီးေလာင္စာႀကီးရထားတာ၊ ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)၊ ဘာရထားပါလိမ့္ (မီးေလာင္စာႀကီး ရထားပါတယ္ ဘုရား)။ ။
မီးေလာင္စာႀကီးရထားတယ္လို႔ ဒကာ ဒကာမတို႔ မွတ္စမ္းပါ၊ ဘာရ ထားတုံး ... (မီးေလာင္စာ ႀကီး ပါဘုရား)၊ ေနာက္က ဒကာ ဒကာမေတြ ဘာရထား... (မီးေလာင္စာႀကီး ရထားပါတယ္ဘုရား) မီးေလာင္စာႀကီး ရထားတယ္။
ဒီမီးက သာမညမီးမဟုတ္ဘူးတဲ့ ဒီအထဲမွာ ေထာင့္ငါးရာ ကိေလသာမီးေတြေအာင္းေနတယ္၊ ေထာင့္ငါးရာကိေလသာမီးေတြ၊ မဂ္နဲ႔ မပယ္သ၍ ဘယ့္ႏွယ္ေနမတုန္း ... (ေအာင္းေနပါတယ္ဘုရား)။

႐ုပ္နာမ္ကမီးစာ

ေအာင္းေနေတာ့ က်န္တဲ့႐ုပ္နာမ္ေတြက မီးစာေတြ၊ ဒါျဖင့္ မီးေလာင္ စာမွ ဟုတ္ရဲ႕လား ... (ဟုတ္ပါတယ္ဘုရား) ရွင္းပလား (ရွင္းပါၿပီဘုရား) ခႏၶာႀကီးက ဘာပါလိမ့္ ... (မီးေလာင္စာ ပါဘုရား)။
တစ္ေထာင့္ငါးရာကိေလသာေတြက မီး... ဒါျဖင့္ မီးနဲ႔ေလာင္စာ တြဲေနတဲ့ဥစၥာ၊ မီးက သူေတာ္ေကာင္း လို႔ဆိုမလား ... (မဆိုႏိုင္ပါဘုရား) မီးက သူေတာ္ေကာင္းဆိုရင္ ဘယ္သူ႔မွ မေလာင္ဘူး ေပါ့ဗ်ာ၊ ရိပ္မိပလား (ရိပ္မိပါၿပီဘုရား)။ ။
မီးကိုသူေတာ္ေကာင္းလို႔ဆိုၾကမလား ... (မဆိုပါဘုရား) ဘယ့္ႏွယ္ဆိုမယ္ (ေလာင္တတ္တဲ့ မီးပါဘုရား)၊ ေလာင္တတ္တဲ့မီးလို႔သာ ဆုံးျဖတ္ခ်က္ခ်ပါ၊ ဒကာ ဒကာမေတြဒါက ဘယ္မွာ ေနတုံးလို႔ ေမးခြန္းထုတ္ ျပန္ေတာ့၊ ဘယ့္ႏွယ္ဆိုၾကမယ္ ... (ခႏၶာထဲမွာပါဘုရား) ခႏၶာထဲမွာ ရွိတယ္။

ကိေလသာမီးေလာင္ေနတယ္

ဘယ္မွာရွိလဲ ... (ခႏၶာထဲမွာပါဘုရား) ခႏၶာထဲမွာရွိတယ္၊ ခႏၶာ ထဲမွာ ရွိလို႔ခင္ဗ်ားတို႔ကိုယ္တိုင္ အခုမီးေလာင္လို႔၊ ကိုယ့္အိမ္ ကိုယ့္ယာ ကိုယ့္တိုက္တာေတြ တည္ႏိုင္ၾကတဲ့ ပုဂၢိဳလ္လည္း တည္ၾက ဟုတ္လား၊ အမ်ိဳးမ်ိဳး အဖုံဖုံ၊ အၿခံအရံေတြနဲ႔ ေနၾကထိုင္ၾကတယ္။ ။
အဲဒီကိုယ့္အိမ္ကိုယ့္ရာကေနၿပီး၊ ဟိုသြားၿပီးေငြရွာရ၊ ဒီသြားၿပီးေငြ ရွာရ၊ ဟိုသြားၿပီး မိတ္ေဆြ အေပါင္းအသင္းဖြဲ႕ရ၊ ဒီသြားၿပီး မိတ္ေတြအေပါင္း အသင္းဖြဲ႕ရဆိုတာ၊ ကိေလသာ မီးေလာင္လို႔ အိမ္ကကိုထြက္ေျပးေနရတာ၊ ရိပ္မိပလား ... (ရိပ္မိပါၿပီဘုရား) ဟိုေဈးစုံစမ္းေရးထြက္ရ၊ မထြက္ရေပ ဘူးလား (ထြက္ရပါတယ္ဘုရား)။

ေလာဘမီး

ဟိုမွာ ရစရာရွိလို႔ဟိုသြားလုပ္ရမွာဗ်၊ ကိုယ့္အိမ္မွာမေနရဘူး၊ ဟိုသြားမထြက္ရဘူးလား (ထြက္ရပါတယ္ဘုရား) အဲဒါခင္ဗ်ားတို႔ မီးေလာင္ လို႔ေျပးတာ၊ ဒကာ ဒကာမတို႔ ဘာျပဳလို႔ေျပးတာတုံး (မီးေလာင္လို႔ပါဘုရား) ေလာဘမီးေလာင္တာ မေလာင္ဘူးလား၊ ေလာင္သလား ... (ေလာင္ ပါတယ္ဘုရား)။
အဲဒီေတာ့ ဒီခႏၶာႀကီးဟာ ေလာင္သာေနတယ္၊ လမ္းမွာလည္း ေလာင္ရင္းသြားတာပဲ မဆိုႏိုင္ဘူးလား (ဆိုႏိုင္ပါတယ္) ဒီခႏၶာကိုယ္ႀကီးကို ဘယ္သူက ဘာနဲ႔ႀကဳံေတြ႕လို႔ဘာနဲ႔တိုက္မိသတုံး၊ ဘာနဲ႔ခိုက္မိသတုံး၊ ကားနဲ႔ တိုက္မိမလား၊ စက္ဘီးနဲ႔တိုက္မိမလား၊ ဒါေတြေၾကာင့္ၾကတဲ့ ေဒါသမီးက ေရာ (ေလာင္လ်က္ပါဘုရား)။

ေဒါသမီး

ေလာင္လ်က္နဲ႔ အိမ္ကထြက္တုန္းက ေလာဘမီး၊ လမ္းက်ေတာ့ အႏၲရာယ္ေတြ႕ေတာ့ ေဒါသမီးနဲ႔ဟုတ္လား၊ အဲဒီေတာ့ ေလာဘမီး၊ ေဒါသမီး ဟာ ေလာင္ၿပီးသကာလ လာေတာ့၊ ကိုယ့္အလုပ္ခြင္ ကိုယ့္ရပ္႐ြာရွိတဲ့ဆီ ေရာက္ၿပီးသကာလလာၾကတာ၊ အိမ္ေဆာက္ၿပီး မေနရတာ ဘာျပဳလို႔ မေနရ တာတုံး၊ ဦးဘၾကည္ေမးၾကည့္ ... (မီးေလာင္လို႔မေနရတာပါ) မီးေလာင္ လို႔ ထြက္ေျပးရတာ။
ဒကာ ဒကာမတို႔ အိမ္ေဆာက္ၿပီး အိမ္မွာေနရတဲ့ ပုဂၢိဳလ္အေတာ္ ရွားပါတယ္ မရွားဘူးလား ... (ရွားပါတယ္ဘုရား) ဒါက ညေလးအပန္း ေျဖဖို႔၊ ဒါကေန႔အပန္းေျဖဖို႔၊ ရိပ္သာေလးတစ္ခုေတာ့ ေနဖို႔ေတာ့မဟုတ္ပါ ဘူး၊ ေန႔လည္က်ေတာ့ ေနေကာ ေနၾကရဲ႕လား ... (မေနရပါဘုရား)။

ကိေလသာမီး ေလာင္လြန္းလို႔အျမန္ေျပးရ

မျဖစ္ပါဘူး၊ ေျခလ်င္သြားရင္ ေႏွးမွာစိုးလို႔ စက္ဘီးနဲ႔သြားတယ္၊ တစ္ခါတည္း ေႏွးမွာစိုးလို႔ ဦးဘၾကည္ ကားနဲ႔မသြားၾကရဘူးလား (သြားရပါ တယ္ဘုရား) ကိေလသာမီးကေလာင္လြန္းလို႔ အျမန္ေျပးၾကရတာ၊ အျမန္ ေျပးရတယ္ (မွန္လွပါဘုရား)။
ေႏွးေႏွးေျပးရင္ ကိေလသာမီးက ကိုယ္အၿမဲေလာင္ေနေတာ့၊ ေလယာဥ္ပ်ံျမန္လွၿပီ ေအာက္ေမ့ေတာ၊ ကိေလသာမီးက သူ႔ထက္အရင္ ေရာက္ခ်င္တယ္၊ ရႈိ႕လိုက္တဲ့ျဖစ္ျခင္း၊ မရႈိ႕ဘူးလား (ရႈိ႕ပါတယ္ဘုရား) ရႈိ႕ လိုက္ေတာ့ ဒကာ ဒကာမေတြ အိမ္ေဆာက္ၿပီး အိမ္မေနရတာ ဘာမီးပါ လိမ့္ ... (ကိေလသာမီးပါ ဘုရား)။ ။
ခင္ဗ်ားတို႔က ဟိုအိမ္ကမီးနီးလို႔၊ ဟိုအိမ္ကလူေတြထြက္ကုန္ၿပီလို႔ ေအာက္ေမ့မေနနဲ႔၊ အိမ္တိုင္းက ထြက္ေနတယ္၊ ေန႔တိုင္းမီးေလာင္ေနတာ၊ ဟိုအိမ္သြားၾကည့္စမ္း၊ ဒီအခ်ိန္ သူ႔ကို ေတြ႕မလားလို႔ လူလႊတ္ၾကည့္ရေသး တယ္၊ ရွိမွ ရွိပါ့မလား၊ မီးေလာင္လို႔ ေျပးမ်ားေျပးေနၿပီလားလို႔၊ မေျပးၾက ဘူးလား ... (ေျပးၾကပါတယ္ဘုရား)။
အဲဒီလို ကိေလသာမီး ေလာင္ေတာ့ ဘယ္သူ႔ေလာင္သတုံးဆိုေတာ့ ဇရာမီးေလာင္တယ္၊ ဒိျပင္ဟာေတြ ေ႐ြ႕ေလာင္သလား ... (မေလာင္ပါ ဘူးဘုရား)။
ဦးဘအုန္းႀကီး ဘယ္သူ႔ေလာင္သတုံး ... (ခႏၶာငါးပါးေလာင္ပါ တယ္ဘုရား)။ ခႏၶာငါးပါး သာေလာင္ခ်တယ္၊ အဲေတာ့ ခႏၶာငါးပါးေလာင္ခ် ၿပီးသကာလေနေတာ့ ဒီခႏၶာႀကီးသည္ကားလို႔ ဆိုလို႔ရွိရင္ျဖင့္ အိုခ်ိန္မေရာက္ ဘဲနဲ႔ အိုဖို႔၊ နာခ်ိန္မေရာက္ဘဲနဲ႔ ... (နာဖို႔ပါဘုရား)။ ေသခ်ိန္ မေရာက္ဘဲနဲ႔ ... (ေသဖို႔ပါဘုရား)။

ကိုယ့္ကိုယ္ကိုယ္သတ္ေသတဲ့မီး

ဒါ ခင္ဗ်ားတို႔ ဘယ့္ႏွယ္ေၾကာင့္ အခ်ိန္ေတြ ခုႏွစ္ဆယ့္ငါးႏွစ္တန္းမွာ ေနသင့္ပါလ်က္သားနဲ႔၊ တခ်ိဳ႕ခုႏွစ္ဆယ့္ငါးႏွစ္မွ မျပည့္ခင္ အသက္သုံးဆယ္၊ ေလးဆယ္၊ ငါးဆယ္က ေသၾကတယ္ ဆိုလို႔ရွိရင္၊ ဘာမီးတုံးလို႔ ေမးလို႔ရွိရင္ျဖင့္ အျခားမီးမဟုတ္ဘူးေဟ့၊ မင္းတို႔ဟာမင္းတို႔ ကိုယ့္ကိုယ္ကိုယ္ သတ္ေသတဲ့မီး (မွန္ပါ့)။ ။
မဆိုထိုက္ဘူးလား ... (ဆိုထိုက္ပါတယ္ဘုရား)၊ ဘာမီးပါလိမ့္... (မရဏမီးပါဘုရား)၊ ေလာဘမီး၊ မရဏမီးက မပူေသးပါဘူး၊ ေလာဘမီးက ေလာင္တုံးရွိေသးတယ္၊ တခ်ိဳ႕ေလာဘ မီးေလာင္တာနဲ႔ပဲ တစ္ခါတည္း ကိုယ္ခင္တဲ့ပုဂၢိဳလ္၊ ကိုယ္ၾကင္နာတဲ့ပုဂၢိဳလ္နဲ႔ အတူတူမေနရလို႔ ေရထဲ
ေသတဲ့ပုဂၢိဳလ္နဲ႔၊ မီးထဲခုန္ဆင္းတဲ့ ပုဂၢိဳလ္နဲ႔ ဒါဘယ္မီးေလာင္တာပါ လိမ့္ ... (ေလာဘမီးပါဘုရား)။
ေလာဘမီးေလာင္တယ္၊ ဟုတ္လား၊ မခံခ်င္တဲ့စိတ္မ်ားေတာ့ ေဒါသ မီးနဲ႔ ေသလိုက္တာ ေအးပါေသးတယ္ဆိုေတာ့ ဒါဘာမီးေတြေလာင္တာပါ လိမ့္ ... (မရဏမီးပါဘုရား)၊ မရဏမီးကို မလာေသးပါဘူး... (မွန္ပါ့) မရဏမီးက သက္တန္းေစ့မွ လာမွာကိုးဗ် ... (မွန္ပါဘုရား)။
အဲဒီအခ်ိန္ထိမေစာင့္ဘူး၊ ေစာေစာသတ္မယ္ဆိုတဲ့မီး၊ ရိပ္မိၿပီလား ... (ရိပ္မိပါတယ္ဘုရား)၊ ေစာေစာသတ္တဲ့မီးက ဘယ္မီးပါလိမ့္မတုံး (ေလာဘမီး၊ ေဒါသမီးပါဘုရား)၊ ေလာဘမီး၊ ေဒါသမီး၊ ေမာဟမီးဆိုတာ ေက်နပ္ၿပီလား ... (ေက်နပ္ပါတယ္ဘုရား)။ ။
ဒါျဖင့္ ဒကာ ဒကာမတို႔ ခင္ဗ်ားတို႔မွာ ရင္ထဲမွာ တစ္ခါတည္း ပူလိုက္၊ အိုက္လိုက္၊ စိတ္ပူကိုယ္ပူဆိုတာေတြဟာက စိတ္ခ်လက္ခ် ေအးေအး ခ်မ္းခ်မ္း ေနရတဲ့အခ်ိန္ ဘယ္အခ်ိန္လဲ လို႔ ေမးလို႔ရွိရင္ ဘယ္အခ်ိန္ မွ မရွိဘူးလို႔ ဆုံးျဖတ္ခ်က္ခ်... (မွန္ပါဘုရား)။
ဟုတ္ဖူးလား၊ သားပူ ပူလည္း ဒီထဲက ေလာဘထေတာက္တာပဲ၊ သမီးပူ၊ ေဆြပူ၊ မ်ိဳးပူ၊ မင္းပူ၊ စိုးပူေတြေကာ အကုန္မေလာင္ဘူးလား ... (ေလာင္ပါတယ္ဘုရား)။ ။

အိပ္ယာထဲမွာ မ်က္ရည္သုတ္ရတယ္

ေလာင္တဲ့အျပင္ ေသာက၊ ပရိေဒဝေတြေကာ ... (ေလာင္ပါ တယ္ဘုရား)၊ တစ္ခါတေလ အိပ္ယာထဲမ်ား ကိုယ့္ဟာကိုယ္မ်က္ရည္ သုတ္ ေနရတဲ့ဘဝေတြေကာ မေရာက္ဘူးလား ... (ေရာက္ပါတယ္ ဘုရား)။
အံမေလး ! အတြင္းမ်ား ပိတ္ၿပီးေလာင္ေနတာ အခန္းပိတ္ေလာင္ ေနတာ ... (မွန္ပါဘုရား)။ ရိပ္မိၿပီလား ဒကာ ဒကာမတို႔၊ ဘယ္ေလာက္ မ်ားဆိုးသလဲဆိုတာေပၚၿပီလား ... (ေပၚပါၿပီဘုရား)။ ။
အဲဒီေတာ့ ဒါ ... မရဏမီးလို႔ဆိုမလား၊ ကိေလသာမီးလို႔ ဆိုမလား ... (ကိေလသာမီးပါဘုရား)၊ ဪ ... ဒီကိေလသာမီး အေလာင္ခံဖို႔ ခင္ဗ်ားတို႔ ဆုေတာင္းထားတာကိုး ဒီခႏၶာႀကီးဟာ ... (မွန္လွ ပါဘုရား)။
ကိေလသာမီး အေလာင္ခံၿပီး ေသျခင္းဆိုးေသရပါလို၏တဲ့၊ ဒုကၡ ေရာက္ၿပီး ေသရပါလို၏ ... (မွန္လွပါ)၊ ဒီခႏၶာႀကီးဟာ အေလာင္ခံရတဲ့ ခႏၶာႀကီးမို႔ ခင္ဗ်ားတို႔သည္ မီးေလာင္ခံရတဲ့သူကို သုခလို႔ဆိုမလား၊ ဒုကၡလို႔ ဆိုမလား ... (ဒုကၡပါဘုရား)။
ဒါျဖင့္ ဒုကၡသစၥာေပၚၿပီလား ... (ေပၚပါၿပီဘုရား) ရိပ္မိၿပီလား (ရိပ္မိပါၿပီဘုရား)။

သႏၲာပေ႒ာ

သႏၲာပေ႒ာ ေလ ... (မွန္ပါဘုရား)၊ ဆင္းရဲမီးျဖင့္ သီးသီးေတာက္ ေျပာင္၊ အၿမဲေလာင္ကြၽမ္း ေနေသာ အနက္သေဘာသည္လည္းေကာင္း၊ သူက သႏၲာပ႒သတၱိရွိတယ္ ... (မွန္ပါဘုရား)။ ။
ဆင္းရဲမီး အေလာင္ခံဖို႔ သတၱိရွိတယ္ ... (မွန္ပါဘုရား)၊ ဒကာ ဒကာမတို႔ ရိပ္မိၿပီလား ... (ရိပ္မိပါၿပီဘုရား)။
ကံေကာင္းလို႔ လူျဖစ္လာတာလား၊ ေလာင္စာဆုေတာင္းလို႔လူျဖစ္ လာတာလား၊ ေလာင္စာဆုေတာင္းလာတာပါ ... (ေလာင္စာဆုေတာင္း လာတာပါဘုရား)။
အဲဒါ ဘဝသံသရာမွာ ခင္ဗ်ားတို႔ အမိုက္ႀကီး မိုက္လာတာ၊ ဒီေလာင္ စာကို ဆုေတာင္းတဲ့ ပုဂၢိဳလ္ တစ္ဦးတစ္ေယာက္ သည္ကားလို႔ ဆိုလို႔ရွိရင္ျဖင့္ ေလာင္စာသိမ္း၍ ၿငိမ္းရပါလို၏ ဆိုရင္ ဘယ္ေလာက္ေကာင္းမလဲ ... (ေကာင္းပါတယ္ ဘုရား)။

ေလာင္စာသိမ္း၍ ၿငိမ္းရပါလို၏

ဒါက ေလာင္စာ ... (မွန္ပါဘုရား) ၿငိမ္းရပါလို၏ဆိုတာ အတြင္းကမီး ... (မွန္ပါဘုရား)၊ ေလာင္စာသိမ္း၍ ၿငိမ္းရပါလို၏ဆိုတာ သာလွ်င္ ခင္ဗ်ားတို႔ ကိုယ့္ဖို႔အစစ္ ... (မွန္ပါဘုရား)။
က်န္တာေတြ အဲဒီဆုေတြေတာ့ ဘယ္သူမွ မေတာင္းနဲ႔ ... ( မေတာင္းပါဘုရား)၊ ေလာင္စာ ႀကီးႀကီးက်ယ္က်ယ္ျဖစ္ရပါလို၏ နတ္ေလာင္စာ၊ ျဗဟၼာေလာင္စာ၊ စၾကဝေတး မႏၶာတ္ ေလာင္စာ၊ ေလာင္စာႀကီး ၍ မီးႀကီးရပါလို၏။ ဒါသာဆုေတာင္းေလ့ရွိတယ္ ဒကာ ဒကာမတို႔ မေတာင္း ၾကေပဘူးလား ... (ေတာင္းပါတယ္ဘုရား)။
ဒါျဖင့္ အဲဒါသစၥာသိတဲ့ ပုဂၢိဳလ္လား၊ သစၥာမသိကဲ့ပုဂၢိဳလ္လား ...(သစၥာမသိတဲ့ ပုဂၢိဳလ္ပါ ဘုရား)။ ဘယ္ေတာ့ နိဗၺာန္ရမတုံး ... နိဗၺာန္ဆို တာ ေလာင္စာနဲ႔ မီးၿငိမ္းရမယ္ ... (မွန္ပါ)။
ဦးဘၾကည္ ဒါက ေလာင္စာမဟုတ္လားဗ်ာ ... (မွန္ပါဘုရား)။ ကိေလသာက ... (မီးပါဘုရား)၊ ေလာင္စာနဲ႔မီးၿငိမ္း၍ သိမ္းတာမွ နိဗၺာန္ ကိုးဗ် ... (မွန္လွပါဘုရား)။ ဒုကၡနဲ႔သမုဒယ ခ်ဳပ္မွကိုးဗ်... (မွန္လွပါ ဘုရား)၊ ရွင္းၿပီလား ... (ရွင္းပါၿပီဘုရား)။
အဲဒါ ခင္ဗ်ားတို႔က ေလာင္စာနဲ႔ မီးတြဲလ်က္ႀကီးျဖစ္ရပါလို၏။ အံမေလး! ေၾကာက္စရာ ေကာင္းတဲ့ ဒကာ ဒကာမေတြ ... ဘယ့္ႏွယ္မ်ား ဆုေတာင္းေလ့ရွိတုံး ... (ေလာင္စာနဲ႔မီးတြဲလ်က္ႀကီး ျဖစ္ရပါလို၏)။
ျဖစ္မွျဖစ္ရေလဗ်ာ၊ ျဖစ္မွျဖစ္ရေလ ဒကာ ဒကာမတို႔၊ ခင္ဗ်ားတို႔ ေတာင္းထားတဲ့ဆုဟာ အခုေတာ့ အက်ိဳးေပးပါေပါ့လား ... (မွန္ပါ ေရွ႕ လည္းလာဦးမွာပါဘုရား) လာဦးမယ္၊ ရိပ္မိၿပီလား ဒကာ ဒကာမတို႔ ... (ရိပ္မိပါၿပီဘုရား)။
ခင္ဗ်ားတို႔ ေတာင္းထားတဲ့ဆုဟာ ေရွ႕ကလည္း ေတာင္းလို႔မရဘူး၊ ဘယ္သူက ဘယ္လိုျဖစ္ ေနလို႔၊ ဘယ္သူ႔ဆီရစရာကလည္းမရဘူး၊ ကိုယ့္မွာ လည္း အထုပ္အထည္မရွိေတာ့ဘူး၊ အိုခက္ကုန္ၿပီ၊ ေလာင္ကုန္ၿပီေကာဗ် ... (မွန္လွပါဘုရား)။
မေလာင္ေသးဘူးလား ... (ေလာင္ပါတယ္ဘုရား)၊ အဲဒါသည္ ခင္ဗ်ားတို႔ ကံမေကာင္း အေၾကာင္း မသင့္လို႔ ေတြ႕ရတာလား၊ ဆုေတာင္းျပည့္ တာလားသာေမး ... (ဆုေတာင္းျပည့္တာပါ ဘုရား)။ ။
ေတာင္းတဲ့ဆုျပည့္ပါေစသတည္းဆိုတာဒါပဲ၊ အဲဒါ ဘယ္မွာမဆို ခင္ဗ်ားတို႔က ပေစၥကဗုဒၶါဆီ ဆုေတာင္းလည္း ဒါပါတာပဲ၊ ဘုရားဆီ ဆုေတာင္းျပန္လည္း သစၥာမသိရင္ ဒါပါတာပဲ ... (မွန္ပါ)။ မပါဘူးလား (ပါပါတယ္ဘုရား)။
ဒါျဖင့္ ခင္ဗ်ားတို႔ ေတာင္းတဲ့ဆုျပည့္ေတာ့ကို ခင္ဗ်ားတို႔ အၿငိမ္ေနလို႔ ရေသးရဲ႕ လား ... (မရပါဘူးဘုရား)၊ မရေတာ့ဘူး။

ေလာင္စာနဲ႔မီးၿငိမ္းမွသာလ်င္နိဗၺာန္

မအိုခ်ိန္တန္ အို၊ မနာခ်ိန္တန္ နာ၊ ေသမဲ့လမ္းဘက္တိုးသြား၊ ဒီလို မေနရေပဘူးလား ... (ေနရပါတယ္ ဘုရား)၊ ေနရေတာ့ကိုးတဲ့ ဒီေလာင္စာမီးသည္ကားလို႔ဆိုရင္ ဒကာ ဒကာမတို႔ ေလာင္စာႏွင့္ မီးၿငိမ္းမွ သာလွ်င္ နိဗၺာန္ ... (မွန္ပါဘုရား)။
ဒါျဖင့္ ဒုကၡသစၥာသိတဲ့ပုဂၢိဳလ္မွ၊ ဒုကၡသစၥာက ခႏၶာငါးပါးက ဒုကၡသစၥာ၊ ျဖစ္ပ်က္ ဒုကၡသစၥာေပါ့ဗ်ာ ... (မွန္ပါဘုရား)၊ သိတာက မဂၢသစၥာ ... (မွန္ပါဘုရား)။
ဒုကၡသစၥာကို မဂၢသစၥာနဲ႔သိတဲ့အခ်ိန္က်ေတာ့မွ သမုဒယေလာင္စာ မီးက အရင္သိမ္းတယ္ ... (မွန္လွပါဘုရား)၊ ၿပီးေတာ့မွ ထင္းက အကုန္ သိမ္းတယ္ ... (မွန္လွပါဘုရား)၊ သေဘာက်ၿပီလား ... (မွန္ပါ)။
သဥပါဒိေသသ၊ အႏုပါဒိေသသ ႏွစ္ခ်က္ခြဲတယ္ ... (မွန္ပါ ဘုရား)၊ ေရွးဦးစြာ မီးအရင္သိမ္း လိုက္တယ္ ... (မွန္ပါ့)။ ၿပီးေတာ့မွ ေလာင္စာ သိမ္းတယ္၊ ရွင္းၿပီလား ... (မွန္ပါ)။ ။
သဥပါဒိေသသ နိဗၺာန္ဆိုတာ ဘာအရင္သိမ္းသတုံး ... (မီးအရင္ သိမ္းပါတယ္ဘုရား)၊ အဲဒါ ကိေလသာ သိမ္းတာကစတာ၊ သေဘာက်ၿပီလား (မွန္ပါ)၊ ဒါျဖင့္ မီးအရင္သိမ္းတယ္၊ သေဘာက်ၿပီလား ... (မွန္ပါ)။
ၿပီးေတာ့မွ ဘာတုံး ... (ေလာင္စာသိမ္းပါတယ္ဘုရား)၊ ေလာင္စာ သိမ္းတယ္၊ သေဘာက် ၿပီလား ... (မွန္ပါ)၊ အဲဒီေတာ့ကိုး ဒါ မဂ္လာေပ လို႔ေနာ္ ... (မွန္ပါ)၊ သူ႔ကို သစၥာမွန္းသိလို႔ ... (မွန္လွပါ) ဒီမီးၿငိမ္းသြားတာ ... (မွန္လွပါ)။
မီးၿငိမ္းသြားေတာ့ သစၥာမွန္းသိေနေတာ့ ခင္ဗ်ားတို႔ ဆုေတာင္းျပည့္ တဲ့ဥစၥာက ထင္းကေလး ကေတာ့ က်န္ရဦးမွာပဲ ... (က်န္မွာပါဘုရား)၊ မက်န္ဘူးလား ... (က်န္ပါတယ္ဘုရား)။

ဘုရားျဖစ္ေတာ့မီးေတာ့သိမ္းတယ္

ဘုရား ေဗာဓိပင္ႏွင့္ ေ႐ႊပလႅင္မွာတဲ့ မီးေတာ့သိမ္းတယ္ ... (မွန္ပါ)။ ေလာင္စာမသိမ္းႏိုင္ဘူး၊ သိမ္းႏိုင္ရဲ႕လား ... (မသိမ္းႏိုင္ပါဘုရား) ကိုယ္ေတာ္ႀကီးက်န္ေနတယ္ ... (မွန္ပါ)။ ေပၚၾကၿပီလား ဒကာ ဒကာမတို႔ (ေပၚပါၿပီဘုရား)။
အင္း ... ဒါျဖင့္ ကိုယ္ေတာ္ျမတ္ႀကီးက ဝိပါကဝဋ္ ... (မွန္ပါ)၊ ဆုေတာင္းျပည့္ထားၿပီး ... မျပည့္ဘူးလား ... (ျပည့္ပါတယ္ဘုရား)။
ငါဘု ရားျဖင့္ ႏွစ္ရွစ္ဆယ္ေတာ့ ေနရပါလို၏ကြာဆိုေတာ့ ႏွစ္ရွစ္ဆယ္ ထင္းျဖစ္ရပါလို၏ ဆိုတာ ... (ပါေနၿပီ) ပါလ်က္ပဲဆိုတာ ရိပ္မိၾကၿပီလား ... (ရိပ္မိပါတယ္ဘုရား)။
အံမေလး! ဒကာ ဒကာမတို႔ ခင္ဗ်ားတို႔ ေတာင္းထားတဲ့ အႀကိမ္ႀကိမ္ ဆိုရင္ေတာ့ သြားပါၿပီ ... (မွန္ပါဘုရား)၊ မသြားေသးဘူးလား ... (သြားပါတယ္ဘုရား)၊ အႀကိမ္ႀကိမ္ ဆိုလို႔ရွိရင္ျဖင့္ ထင္း အႀကိမ္ႀကိမ္ မီးနဲ႔တြဲ ၍ အႀကိမ္ႀကိမ္၊ ဒါျဖင့္ ေသျခင္းဆိုးနဲ႔ ဆုေတာင္းတာ ... ဟုတ္လား၊ ေသျခင္းဆိုး ေသရပါလို၏။
ေသျခင္းဆိုးေသရပါလို၏ အသံကေတာ့ ဒီအသံဗ်၊ လူျဖစ္ရပါလို ၏ ဆိုေတာ့ နားေတာ့ ယဥ္တယ္ေပါ့ဗ်ာ ေနာက္လူေကာင္၊ နတ္ေကာင္ ျဖစ္ရပါလို၏ဆိုေတာ့ နားဘယ့္ႏွယ့္ေနတုံး ေထာင္လို႔ေတာ့ေကာင္း ဟုတ္လား၊ ျဖစ္စဥ္ၾကည့္လိုက္ေတာ့ မီးနဲ႔ေလာင္စာတြဲၿပီး ေသပြဲခ်ည့္ဝင္ရ ပါလို၏ ... (မွန္လွပါ)၊ ရွင္းၿပီလား ... (ရွင္းပါၿပီဘုရား)။

မီးေလာင္စာတြဲၿပီးေသပြဲဝင္ရ

မီးနဲ႔ေလာင္စာတြဲၿပီး ဘာတုံး ... (ေသပြဲဝင္ရပါလို၏ဘုရား)၊ အဲဒါ ခင္ဗ်ားတို႔ ကိုယ္ကိုယ္တိုင္ ေတာင္းထားတဲ့ဆု၊ ခု-ဘယ့္ႏွယ့္ေနသတုံးဆိုေတာ့ အတြဲႀကီးတြဲတုန္းဘုရား ဟုတ္လား။
ေရွ႕မ်ား တပည့္ေတာ္ေကာင္းစားဦးမွာလားေမးရင္ တြဲစရာ က်န္ ေသးတယ္၊ ရိပ္မိၿပီလား ... (မွန္ပါ) ေရွ႕ေကာင္းစားဦးမွာလားဆိုေတာ့ ဘယ္လို ဆုံးျဖတ္ခ်က္ခ်... (တြဲစရာက်န္ပါတယ္ဘုရား)၊ က်န္ေသးတယ္၊ အိုတုန္းလည္း အေလာင္ခံရဦးမွာ၊ နာတုန္းေကာ ... (အေလာင္ခံရမွာပါ ဘုရား)။
နာတုန္းလည္း ဟိုစိတ္မခ်၊ ဒီစိတ္မခ်၊ ဟိုအေမြေပးခ်င္၊ ဒီအေမြေပး ခ်င္ဆိုေတာ့ ကိေလသာမီးကလည္းလာေသးတာဗ် ... (မွန္ပါ)။
နာတာကတစ္ဖက္၊ ေလာင္တာကတစ္ဖက္ကိုးဗ် ... (မွန္လွပါ) ရိပ္မိၿပီလား ... (ရိပ္မိပါတယ္ ဘုရား)။
နာမႈ ႏွိပ္စက္တာကတစ္ဖက္၊ ေပးစရာ ကမ္းစရာေတြ စိတ္မခ် လက္မခ် ေလာင္ေနတာ ကေကာ ... (တစ္ဖက္ပါဘုရား)။
