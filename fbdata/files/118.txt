<p><a class="_58cn" data-ft='{"type":104,"tn":"*N"}' href="/hashtag/လႉနည္းသင္?source=feed_text&amp;epa=HASHTAG"><span class="_5afx"><span aria-label="แฮชแท็ก" class="_58cl _5afz">#</span><span class="_58cm">လႉနည္းသင္</span></span></a> (ကထိန္အႀကိဳ) အပိုင္း(၁)<br/> (၂၁-၁၁-၆၁)</p>
<p> ဒါနကသံသရာ႐ွည္တာလား။ အသိမလိုက္လို႔လား စသည္ျဖင့္လႉနည္းသင္ေပးေသာတရားျဖစ္သည္။</p>
<p> အသံဖိုင္ေခါင္းစဥ္ = ပဋိစၥသမုပၸာဒ္ ႏွင့္လႉနည္းသင္တရားေတာ္<br/> စာအုပ္ေခါင္းစဥ္ = ဒါနခန္း (ကထိန္အႀကိဳ)</p>
<p> ေက်းဇူးေတာ္ရွင္ အဂၢမဟာပ႑ိတ<br/> မိုးကုတ္ဆရာေတာ္ဘုရားႀကီး အမရပူရၿမိဳ႕ - ဓမၼာ႐ုံ၌ <br/> ေဟာၾကား ျပသ ဆုံးမေတာ္မူအပ္ေသာ<br/> ပဋိစၥသမုပၸါဒ္ အလုပ္ေပးတရားေတာ္(၄)<br/> ~~~~~~~~~~~~</p>
<p>       တကာတကာမတို႔ စာလိုေတာ့ ပဋိစၥသမုပၸါဒ္၊ ျမန္မာ လိုေတာ့ ခႏၶာ၏ လမ္းစဥ္လို႔ မွတ္ပါ.. (မွန္လွပါ) ျမန္မာလို ဘယ္လို မွတ္ၾကမယ္ ...... (ခႏၶာ၏ လမ္းစဥ္လို႔ မွတ္ရပါမယ္ ဘုရား)။<br/>       ခႏၶာ၏ လမ္းစဥ္၊ ခႏၶာ ဒီအစဥ္အတိုင္း သြားေနတယ္ ဒီအေၾကာင္း အက်ိဳးအတိုင္း ဆက္ေနတယ္ ဆိုတာကို အားလုံ တကာ တကာမေတြ မွတ္ၾကရမယ္ .. (မွန္လွပါဘုရား)။<br/>       အဲဒီေတာ့ တကာတကာမေတြ သိတဲ့အတိုင္း အတိတ္ အေၾကာင္း ငါးပါးထဲမွာ အဝိဇၨာဆိုတာ ပါ, ပါတယ္ .... (ပါ, ပါတယ္ဘုရား)။<br/>       တကာတကာမေတြ သိထားတာက အဝိဇၨာပစၥယာ သခၤါရာ ...... (မွန္လွပါ) ေၾသာ္ ...... ဒါျဖင့္ အဝိဇၨာ ပစၥယာ သခၤါရာလို႔ ဘုရားသခင္ကိုယ္ေတာ္ျမတ္ႀကီးကမင္းတို႔ကြာ.... လူခႏၶာေတြ၊ နတ္ခႏၶာေတြ ဆိုတဲ့ဥစၥာ အဝိဇၨာမူတည္တာပဲလို႔ေျပာလိုက္တယ္ ... (မွန္လွပါဘုရား)။<br/>       လူခႏၶာ, နတ္ခႏၶာေတြ ျဖစ္ေၾကာင္းမွာ ဘယ္ဟာမူတည္ ပါလိမ့္..(အဝိဇၨာ မူတည္ပါတယ္ ဘုရား) အဝိဇၨာ မူတည္တယ္ လို႔တကာတကာမေတြမွတ္ထားၾကပါ....(မွန္ပါ့) အဝိဇၨာ မူတည္ တယ္ ဆိုေတာ့ အဝိဇၨာဆိုတာက ဒကာႂကြယ္ ဘာမသိတာတဲ့တုံး .....(သစၥာေလးပါး မသိတာပါဘုရား)။<br/>       သစၥာေလးပါး မသိတာ ဘာေခၚၾကမယ္ ..... (အဝိဇၨာ ေခၚပါတယ္) ေၾသာ္ ..... ဒါျဖင့္ သစၥာေလးပါး မသိတာ အဝိဇၨာ လို႔ဆိုတာ၊ ေၾသာ္ ........ ငါတို႔မွာ အတိတ္က အဝိဇၨာရွိခဲ့တယ္ ဆိုတာမွတ္ပါ.. (မွန္လွပါဘုရား)။<br/>       အတိတ္က ဘာေတြနဲ႔ေနခဲ့, ထိုင္ခဲ့ၾကရသလဲ..(အဝိဇၨာ နဲ႔ေနခဲ့ ထိုင္ခဲ့ၾကရပါတယ္ဘုရား) ဘာမသိတာနဲ႔ ေနခဲ့ၾကပါလိမ့္ (သစၥာေလးပါး မသိတာနဲ႔ ေနခဲ့ၾကပါတယ္ဘုရား) သစၥာေလးပါး မသိတာနဲ႔ ေနခဲ့ၾကရေတာ့ကို .. တဲ့၊ တကာ တကာမေတြက ကုသိုလ္လဲ ျပဳၾကတယ္ .. (မွန္ပါဘုရား) ဒါ သခၤါရဆိုတာ ကုသိုလ္ပါပဲ..... (မွန္ပါ့)။<br/>       ကုသိုလ္ပင္ ျပဳျငားေသာ္လဲ ဒီဘက္မွာ လာစပ္တယ္၊ ဝိညာဏ္, နာမ္႐ုပ္, သဠာယတန, ဖႆ, ေဝဒနာဆိုတဲ့ ခႏၶာငါးပါးပဲ ျပန္ရတယ္ .. (မွန္လွပါ) ေသာ္ တကာ တကာမေတြ သစၥာေလးပါး မသိတဲ့ အဝိဇၨာနဲ႔ ျပဳလုပ္လိုက္တဲ့ ကုသိုလ္ဟာ ခႏၶာငါးပါး ဒုကၡသစၥာတရား ရတယ္လို႔ ဦးသန္းေမာင္ မွတ္စမ္းပါ..... (မွန္လွပါဘုရား)။<br/>       ဒါျဖင့္ ကုသိုလ္ေတာ့ျပဳတာပဲ၊ ဘာေတြရသတုံး ... လို႔ ေမးေတာ့ ခႏၶာငါးပါး ဒုကၡသစၥာတရား ရတယ္ ....... (မွန္လွပါ) ကုသိုလ္ျပဳလို႔ .. (ခႏၶာငါးပါး ဒုကၡသစၥာတရား ရပါတယ္ဘုရား)။<br/>       ဘယ့္ႏွယ္ေၾကာင့္ ရပါလိမ့္မတုံးလို႔ ေမးေတာ့ တကာ တကာမေတြ အဝိဇၨာက သစၥာမသိဘူး ... (မွန္လွပါ) အဝိဇၨာက သစၥာမသိေတာ့ သူခိုင္းတာလုပ္တဲ့ ကုသိုလ္ဟာ ဒုကၡသစၥာ ရတယ္ ... (မွန္လွပါ) ဦးသန္းေမာင္ ေသေသခ်ာခ်ာ မွတ္စမ္းပါ၊ ဒီဟာ ၾကားရ၊ နာရခဲတယ္ဆိုတာ ဒကာ ဦးလွဘူး၊ ဒကာႂကြယ္ အေရးႀကီးတယ္ေနာ္ ... (အေရးႀကီး ပါတယ္ဘုရား)။<br/>       အဲဒါက ဘယ္သူ႔ ေဟာေနပါလိမ့္မလဲလို႔ ေမးေတာ့၊ ဘုန္းႀကီးနဲ႔တကြ ဘုန္းႀကီးတို႔ တကာတကာမေတြဟာ အခု ခႏၶာငါးပါး ဒုကၡသစၥာတရားႀကီးနဲ႔ ခြဲကို မခြဲရေသးဘူး ..... (မွန္လွပါ ဘုရား)။ <br/>       ဒီလိုေနၾကတာဟာ ... တဲ့၊ ဘယ္လိုေၾကာင့္ တို႔ ဒီလို ေနရပါလိမ့္မတုံးဆိုေတာ့ အတိတ္ကို ျပန္စဥ္းစားပါ၊ သစၥာေလးပါး မသိခဲ့လို႔ က်ဳပ္တို႔ ကုသိုလ္ သခၤါရလုပ္ခဲ့တယ္ ...... (မွန္ပါ့) မလုပ္ခဲ့ဘူးလား....(လုပ္ခဲ့ပါတယ္ဘုရား) ဒီၾကည့္ပါ၊ သစၥာ ေလးပါးမသိေတာ့ ကုသိုလ္သခၤါရ လုပ္ခဲ့တယ္ ....) (မွန္လွပါ)။<br/>       အတိတ္ဘဝက ဘာေတြလုပ္ခဲ့ပါလိမ့္ ... (ကုသိုလ္ သခၤါရ လုပ္ခဲ့ပါတယ္ဘုရား) သိၿပီးလုပ္တာလား၊ မသိဘဲနဲ႔ လုပ္တာလား .. (မသိဘဲနဲ႔လုပ္တာပါဘုရား)။<br/>       ေၾသာ္ .. ဘာမသိဘဲနဲ႔ လုပ္ပါလိမ့္မတုံး ဒီသခၤါရေတြ ဆိုေတာ့ ေဟာဒီ ဒုကၡသစၥာဆိုတဲ့ ခႏၶာငါးပါးႀကီး ရမႈကို မသိဘဲနဲ႔ လုပ္ခဲ့တယ္..... (မွန္ပါဘုရား)။<br/>       ဒါျဖင့္ ဒီခႏၶာငါးပါး ဒုကၡသစၥာတရားႀကီးဟာ ..... တကာ တကာမတို႔ အိုမႈ, နာ, ေသမႈ ကင္းပါ့မလား .. (မကင္းပါ ဘုရား)။<br/>       မကင္းတဲ့ ဒုကၡသစၥာႀကီး ရေအာင္ က်ဳပ္တို႔သည္ ဘယ့္ႏွယ္ေၾကာင့္ လုပ္ပါလိမ့္မတုံး ဆိုလို႔ရွိရင္ျဖင့္တဲ့၊ မသိတဲ့ အဝိဇၨာနဲ႔ ျပဳလုပ္တဲ့ ကုသိုလ္သခၤါရ..... (မွန္လွပါဘုရား)။<br/>       ဒကာႂကြယ္ရိပ္မိပလား......(ရိပ္မိပါၿပီ) မသိတဲ့အဝိဇၨာနဲ႔ ... (ျပဳလုပ္တဲ့ သခၤါရပါဘုရား) ျပဳလုပ္တဲ့ သခၤါရေၾကာင့္ သုံးတန္းကိုၾကည့္ .. ၁, ၂, ၃၊ ဒီအတန္းကို ဒီေန႔ ေဟာလိမ့္ မယ္ေနာ္ ... (မွန္ပါဘုရား)။<br/>       မသိတာက အဝိဇၨာ၊ မသိတဲ့ပုဂၢိဳလ္ ျပဳလုပ္တဲ့ကုသိုလ္က သခၤါရ၊ ဘာသစၥာတုံး .. (ဒုကၡနဲ႔ သမုဒယသစၥာပါဘုရား) သမုဒယသစၥာလုပ္ခဲ့ၾကတယ္..... (မွန္ပါ) ကိုယ့္စာ႐ြက္ထဲလဲ ကိုယ္ၾကည့္ပါ၊ ဘာသစၥာ လုပ္ခဲ့ၾကသလဲ ..... (သမုဒယသစၥာ လုပ္ခဲ့ပါတယ္ဘုရား)။<br/>       ဒကာႂကြယ္......ခင္ဗ်ားကေတာ့ အေကာင္းထင္ေနတယ္ ... (ထင္ခဲ့ပါတယ္ဘုရား) သစၥာနဲ႔ ၾကည့္လိုက္ေတာ့ ဘာသစၥာလုပ္ခဲ့သလဲ .. (သမုဒယသစၥာလုပ္ခဲ့ပါတယ္ ဘုရား)။<br/>       စာ႐ြက္ထဲမွာလဲ ေထာက္ၾကည့္ပါ တကာတကာမတို႔၊ အတိတ္အေၾကာင္းက သမုဒယသစၥာပဲ ပါ, ပါလိမ့္မယ္ ဦးသန္းေမာင္..(ပါ, ပါတယ္ဘုရား)ဒကာသစ္မေတြ႕႕ဘူးလား (ေတ႔ြပါတယ္ဘုရား)။<br/>       ေနာက္က တကာတကာမေတြ ... ခင္ဗ်ားတို႔သည္ မသိတဲ့ အဝိဇၨာအုပ္ခ်ဳပ္ၿပီး သကာလတဲ့ ၊ လႉခဲ့ တန္းခဲ့တဲ့ ကုသိုလ္သခၤါရလုပ္ပါတယ္ ..(မွန္လွပါဘုရား) အဝိဇၨာ ပစၥယာသခၤါရာ ..... (မွန္ပါ့) သစၥာေလးပါး မသိတာနဲ႔..... တဲ့ လူဘဝ, နတ္ဘဝေရာက္ေၾကာင္း သခၤါရလုပ္ပါတယ္ .... (မွန္လွပါ)။<br/>       ဒါျဖင့္ ကုသိုလ္လုပ္ခဲ့တယ္ဆိုျငားေသာ္လဲဒီကုသိုလ္ဟာ ဘာသစၥာတုံး ... (သမုဒယသစၥာပါ ဘုရား) ေကာင္းေကာင္း ရိပ္မိၿပီ..... (ရိပ္မိပါၿပီဘုရား) ကုသိုလ္လဲ လုပ္ခဲ့တာပါပဲ ..... (မွန္ပါ့ဘုရား) ဒီကုသိုလ္ ဘာသစၥာပါလိမ့္..(သမုဒယသစၥာ ပါဘုရား)။<br/>       ကိုင္း ... ဒါျဖင့္ ဒကာႂကြယ္တို႔၊ ဒကာသစ္တို႔ ၊ ဦးသန္းေမာင္တို႔ သမုဒယသစၥာ လုပ္ခဲ့လို႔ ရွိရင္ေတာ့ ဒုကၡသစၥာ ကိုယ္တိုင္ရေတာ့မွာပဲ...... (ေငြကုန္ၿပီး လူပင္ပန္းပါတယ္ဘုရား)။<br/>       ေငြကုန္ၿပီးသကာလ လူ ဒုကၡသစၥာ ျဖစ္ရျပန္ခ်ည္ေသး တယ္..(မွန္လွပါ) ဝိညာဏ္, နာမ္႐ုပ္, သဠာယတန၊ ဖႆ, ေဝဒနာ လူခႏၶာပဲ...... (မွန္ပါ, လူခႏၶာပါဘုရား) သူ ဘာသစၥာရသလဲ (ဒုကၡသစၥာ ရပါတယ္ ဘုရား)။<br/>       အဲဒါ ဘယ့္ႏွယ္ေၾကာင့္ ရပါလိမ့္မလဲလို႔ ဦးလွဘူးတို႔ ဒကာႂကြယ္တို႔ ေမးၿပီ ...... (သမုဒယ သစၥာ ေၾကာင့္ပါ ဘုရား) မသိဘဲနဲ႔ လႉတဲ့ သမုဒယသစၥာလုပ္ခဲ့လို႔၊ ရွင္းပလား ... (ရွင္းပါၿပီ)။<br/>       မသိဘဲနဲ႔ လႉတဲ့ သမုဒယသစၥာလုပ္ခဲ့လို႔ ယခု ဘာသစၥာ ရသလဲ .... (ဒုကၡသစၥာ ရပါတယ္ ဘုရား)။<br/>       ဒါျဖင့္ ဒုကၡသစၥာ ရမွာျဖင့္ ဦးသန္းေမာင္ ဘုန္းႀကီးလဲ မလႉခ်င္ဘူး၊ ခင္ဗ်ားလဲမလႉခ်င္ဘူး .....(မွန္လွပါဘုရား) သုခသစၥာရမယ္ဆို လႉခ်င္တယ္ က်ဳပ္တို႔ ..... (မွန္ပါ) သေဘာက် ပလား .. (က်ပါၿပီဘုရား)။<br/>       အဲဒီေတာ့ တကာတကာမေတြကို လမ္းေကာင္းၫႊန္ျပတဲ့ ဆရာသမားမွန္က ဒီဥစၥာ ျပရလိမ့္မယ္ ... (မွန္ပါ) မျပရ ဘူးလား .. (ျပရပါမယ္ဘုရား)။<br/>       ဘုန္းႀကီးက ျပတာလား၊ ဘုရားက ေဟာတာလားဆိုတာ “အဝိဇၨာပစၥယာ သခၤါရာ၊ သခၤါရပစၥယာ ဝိညာဏံ ” ဘုရားကေဟာတာ .. (မွန္ပါ၊ ဘုရားက ေဟာတာပါ) ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။<br/>       ဒါျဖင့္ မသိတဲ့ ပုဂၢိဳလ္မ်ား လႉတာ ဘာသစၥာရသလဲ ...... (ဒုကၡသစၥာရပါတယ္) ရတာက ဒုကၡသစၥာ၊ မသိလို႔လႉတာက (အဝိဇၨာပါဘုရား) ဒကာႂကြယ္..... ေတာ္ေသးတယ္၊ ဒကာႂကြယ္ တို႔ မေသႏွင့္လို႔ ဒါကေလးကို သိလိုက္ရေသးတယ္ ဟင္ .... (မွန္လွပါဘုရား)။ ။<br/>       ႏို႔မို႔လို႔ ရွိရင္ျဖင့္ကြာ ပိုလာပေဟ့ ... လာပေဟ့၊ ဒီဘဝတြင္ စားလို႔ေတာ့ မေတာ္ဘူးကြ၊ ေနာက္ဘဝလဲ ဒီ အထုပ္ ကေလး ယူသြားဦးမယ္..(မွန္ပါ) ဘဝမပါဘူးလား ပါသလား .... (ပါ, ပါတယ္ဘုရား) ေနာက္ဘဝ ဆိုကတည္းက ခႏၶာငါးပါး လို႔ မဆိုႏိုင္ဘူးလား .. (ဆိုႏိုင္ပါတယ္ဘုရား) သစၥာဖြဲ႕လိုက္ (ဒုကၡသစၥာပါဘုရား)။<br/>       ကိုင္း ... မသိလို႔ လႉတာမ်ား ဒုကၡသစၥာရတယ္ ..... (မွန္လွပါဘုရား) ရွင္းပလား .... (ရွင္းပါၿပီ) ဟို ...... ဦးသန္းေမာင္တို႔က အလႉေပးမွာေနာ္၊ အင္မတန္ အေရးႀကီး ေနၿပီ၊ ကိုယ့္အတြက္မွာျဖင့္ ဆရာသမားက အျပည့္အစုံ ေပးလိုက္ၿပီဆိုတာ မွတ္ရမယ္....(မွတ္ရပါမယ္ဘုရား)။<br/>       ကဲ ... ဒါျဖင့္ ဒီဥစၥာ ျပင္ေတာ့မယ္ ဒကာႂကြယ္ေနာ္ .... (မွန္လွပါ) ဒီခႏၶာႀကီးဟာ ဘာသစၥာ ပါလိမ့္ .. (ဒုကၡ သစၥာပါ) ဒုကၡသစၥာလို႔ဆိုတာ ေသေသခ်ာခ်ာ ေပၚေနၿပီ ...... (ေပၚေနပါၿပီ ဘုရား)။ ။<br/>       ဝိညာဏ္, နာမ္႐ုပ္, သဠာယတန ဖႆ, ေဝဒနာဆိုတာ ခႏၶာငါးပါး၊ ေပါင္းလိုက္ရင္ (မွန္ပါ ဘုရား) ဘာသစၥာတုံး.... (ဒုကၡသစၥာပါဘုရား) ရွင္းပလား.....(ရွင္းပါၿပီ) ဒါဒုကၡသစၥာမွန္း ဒီကေန႔ သိေပးပါ..... (မွန္လွပါဘုရား)။<br/>       ဒါျဖင့္တကာတကာမတို႔၊ တကာတကာမေတြကအခုဘဝ သိလိုက္ၾကတယ္၊ ယခု ခႏၶာႀကီးဟာ ဘာသစၥာ ... (ဒုကၡ သစၥာပါ) ဒုကၡသစၥာ ဆိုကတည္းက ဦးသန္းေမာင္ ေနရာက်ၿပီ... (မွန္ပါ) ဝိဇၨာျဖစ္လို႔ သိတာ ... (မွန္လွပါဘုရား) အဝိဇၨာက ဘာျဖစ္သြားသလဲ ... (ဝိဇၨာျဖစ္သြားပါတယ္) ဝိဇၨာျဖစ္ သြားတယ္... (မွန္ပါဘုရား)။</p>
<p> (ဆက္လက္ေဖာ္ျပပါမည္)<br/> ~~~~~~~~~~~~</p>
