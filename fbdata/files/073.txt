<p> ေက်းဇူးေတာ္ရွင္ အဂၢမဟာပ႑ိတ<br/> မိုးကုတ္ဆရာေတာ္ဘုရားႀကီး <br/> အမရပူရၿမိဳ႕၌ ေဟာၾကားေသာ တရားေတာ္ (၁၁-၉-၆၁) <br/> ~~~~~~~~~~~~</p>
<p>       ငါ့ဥစၥာလို႔ ငါ့ဥစၥာကေလးနာေနတာ ငါ့သားကေလး နာေန တာဆိုေတာ့ ငါ့ဥစၥာနာေနတယ္ ... (မွန္ပါ့) ငါ့သားကေလး ေနေကာင္းေနတယ္ဆိုတာလဲ သုခေဝဒနာကို ငါ့သား လုပ္ထား တယ္ ... (မွန္ပါ့ဘုရား)။</p>
<p>       ကဲ ... ဒါျဖင့္ အဲဒီက်ေတာ့ တဏွာ၊ ဥပါဒါန္၊ ကံ၊ ဇာတိ၊ ဇရာ၊ မရဏ လာျပန္ၿပီ ... (မွန္ပါ့) ဒါက ငါ့ဥစၥာေၾကာင့္ လာတဲ့ ပဋိစၥသမုပၸါဒ္ ... (မွန္ပါ့) ခုနင္က ငါ့ေၾကာင့္လာတဲ့ ... (ပဋိစၥသမုပၸါဒ္ပါဘုရား) ငါ့ဥစၥာေၾကာင့္လာတဲ့ ပဋိစၥသမုပၸါဒ္ဆိုတာ ေသခ်ာၾကပလား ...(ေသခ်ာပါၿပီဘုရား)။<br/>       အဲဒါ ဒကာ ဒကာမ တို႔ ေလးေလးနက္နက္ မွတ္စမ္းပါ၊ သုညတဆိုက္ေအာင္ မၾကည့္ ႏိုင္လို႔ . (မွန္ပါ့ ဘုရား)။<br/>       ဘယ္လိုမွတ္ၾကမယ္ (သုညတဆိုက္ေအာင္ မၾကည့္ႏိုင္လို႔ပါ ဘုရား) သုညတဆိုက္ေအာင္ မၾကည့္ႏိုင္လို႔ ... (မွန္ပါ့ဘုရား)။ <br/>       ဦးမာဒင္ ဘယ္ေလာက္အေရးႀကီးသတုံး (ႀကီးပါတယ္) ႀကီး တယ္တဲ့၊ ခင္ဗ်ားတို႔ ကေတာ့ ငါနဲ႔ ငါ့ဥစၥာမွပဲ ခင္ဗ်ားတို႔မွာျဖင့္ ကိုယ့္အေရးႀကီးတဲ့ အခ်က္မွတ္ေနတယ္ (မွန္ပါ့) ငါက ဒိ႒ိ ငါ့ဥစၥာက တဏွာ... (မွန္ပါ့) သေဘာက်ပလား (က်ပါၿပီဘုရား)။ း ငါက...(ဒိ႒ိ) ငါ့ဥစၥာက ... (တဏွာပါ) ကဲ- ငါ့ေၾကာင့္ လဲ ပဋိစၥသမုပၸါဒ္ တစ္ခ်က္သြားၿပီ ...(မွန္ပါ့)" ငါ့ဥစၥာေၾကာင့္ ေကာ (ပဋိစၥသမုပၸါဒ္ တစ္ခ်က္သြားပါတယ္ဘုရား)။<br/>       ကိုင္း ... ဒါဟာ ဒီပဋိစၥသမုပၸါဒ္ ႏွစ္သံသရာ ခရီးလမ္းႀကီး ႏွစ္ခုေပၚလာတာဟာ ဦးမာဒင္၊ ဦးလွဘူးတို႔ စဥ္းစားပါတဲ့ သုညတ မျမင္လို႔ ... (မွန္ပါ့) ဘယ္လိုဆိုၾကပါ့မယ္ ... (သုညတ မျမင္လို႔ ပါဘုရား)။<br/>       အားလုံး ဒကာ ဒကာမေတြ ဒီပဋိစၥသမုပၸါဒ္ ေပၚလာတယ္ ဆိုကတည္းကိုက ခင္ဗ်ားတို႔ သံသရာခရီးလမ္းႀကီးကျဖင့္ ဒါလဲ မိမိသြားတာပဲ ... (မွန္ပါ့) ဒီဟာေကာ ... (မိမိသြားတာပါ) ဒါေကာ ... (မိမိသြားတာပါ) ဒါလဲ မိမိေရာက္တာပဲ (မွန္ပါ့ ဘုရား)။<br/>       ကဲ ... ဒကာ ဒကာမတို႔ ဒီဥစၥာ သူမ်ားသြားေနတာလား မိမိသြားေနတာလား ... (မိမိသြားေနတာပါ) ေျသာ္ ... ဒီပဋိစၥသမုပၸါဒ္ဟာ မိမိတည္ေထာင္တဲ့ ပဋိစၥသမုပၸါဒ္ (မွန္ပါ့) ရွင္း ၾကပလား ... (ရွင္းပါၿပီဘုရား)။ ( သူမ်ားတည္ေထာင္တာလား ... မိမိတည္ေထာင္တာလား၊ (မိမိတည္ေထာင္တာပါဘုရား)။ . ဪ ... ဒါျဖင့္ ဘုန္းႀကီးတို႔ ဒကာဒကာမေတြက ဘယ့္ ႏွယ္ေၾကာင့္ ဒီပဋိစၥသမုပၸါဒ္ႏွစ္ခုကို ကိုယ္ဆင္းရဲေၾကာင္း ပဋိစၥသမုပၸါဒ္ ႏွစ္ခုကို ကိုယ္ကိုယ္တိုင္ ပေယာဂႀကီးနဲ႔ လုပ္ပါလိမ့္မလဲ ေမးဖို႔ အေၾကာင္း ႀကဳံလာတယ္ ... (ႀကဳံလာပါတယ္ဘုရား)။<br/>       ထိုကဲ့သို႔ ႀကဳံလာတာႀကဳံခ်င္လို႔ ႀကဳံရတာမဟုတ္ဘူး၊ ခင္ဗ်ား တို႔ သုညတဆိုက္ေအာင္ မၾကည့္ႏိုင္လို႔ ... (မွန္ပါ့) ေပၚၾက ပလား ... (ေပၚပါၿပီဘုရား)။ ။<br/>       ဘယ္လိုမွတ္ၾကမယ္ ... (သုညတဆိုက္ေအာင္ မၾကည့္ႏိုင္ လို႔ ပါဘုရား)။<br/>       ေၾသာ္ ... ဒကာသစ္ေရ ဒါျဖင့္ ဦးမာဒင္ ဆရာေကာင္း သမားေကာင္း ... သိပ္လိုတယ္ ... (လိုပါတယ္) လိုၿပီ- လိုၿပီ ဦးလွဘူးေရ ... (လိုပါတယ္ဘုရား)။ ။<br/>       ကဲ ... ဒကာဒကာမတို႔ ဒါ အခု ပဋိစၥသမုပၸါဒ္ ဘယ္ႏွစ္မ်ိဳး ၿပီးသြားၿပီလဲ ... (ႏွစ္မ်ိဳးပါ) ႏွစ္မ်ိဳးၿပီးသြားၿပီ၊ ဒိ႒ိေၾကာင့္ ျဖစ္တဲ့ ပဋိစၥသမုပၸါဒ္တစ္မ်ိဳး၊ ငါ့ေၾကာင့္ျဖစ္တဲ့ ပဋိစၥသမုပၸါဒ္ (တစ္မ်ိဳးပါ ဘုရား)၊ ငါ့ဥစၥာေၾကာင့္ျဖစ္တဲ့ ပဋိစၥသမုပၸါဒ္ (တစ္မ်ိဳးပါဘုရား)၊ ပဋိစၥသမုပၸါဒ္တစ္မ်ိဳးလို႔ ဆိုတာ ဒကာ ဒကာမေတြ သိထားျပန္ေတာ့ ေၾသာ္ .... ငါ့ေၾကာင့္လဲ အပါယ္သြားတယ္ ... (မွန္ပါ့) ငါ့ဥစၥာေၾကာင့္လဲ ... (အပါယ္သြားပါတယ္ဘုရား)။<br/>       အင္း ... ခင္ဗ်ားတို႔ အိမ္မွာေနတဲ့အခါက်ေတာ့ ငါမရွိရင္ ျဖင့္ခက္ေတာ့တာပဲ ... (မွန္ပါ့) အင္း ... ငါမရွိလို႔ ရွိရင္ ခက္ တာမဟုတ္ဘူး၊ ငါမရွိရင္ နိဗၺာန္ေရာက္တယ္ ... (မွန္ပါ့ဘုရား)။<br/>       သို႔ေသာ္ ... ခင္ဗ်ားတို႔ ကေတာ့ ဘာတဲ့ ... (ငါမရွိရင္ ခက္ပါသတဲ့) သုညတ နားမလည္ေတာ့ ဒီဥစၥာ တကယ္အေရး တႀကီးသုံးပါတယ္ ... (သုံးပါတယ္ဘုရား)။<br/>       ဒကာ ဒကာမေတြ ဒီစကားေလး တစ္လုံးက နားေထာင္စမ္း ပါ... (မွန္ပါ့) ဒီစကားေလးတစ္လုံး နားေထာင္စမ္းပါ ဦးလွဘူးေရ ... (မွန္လွပါဘုရား)။ | ခင္ဗ်ားတို႔ ဒီကေန ျပန္သြားတဲ့အခါ တစ္ခုခု ခ်ိဳ႕ယြင္းေနတဲ့ အခါက်လို႔ရွိရင္ ငါမရွိရင္ ဒီလိုခ်ည့္ပဲ (ေျပာပါတယ္ဘုရား)။ ။<br/>       ဒါက ဒိ႒ိစလိုက္တာ ... (မွန္ပါ့) ဒိ႒ိစလိုက္ေတာ့ ကိုယ္က လဲ သုညတနားမလည္တဲ့ ပုဂၢိဳလ္ျဖစ္ေနေတာ့ အားလုံး ဒကာ ဒကာမတို႔ ပဋိစၥသမုပၸါဒ္ဆက္သြားၿပီ ... (မွန္ပါ့) မသြားပါနဲ႔ ဆိုလို႔ ... (မရပါဘုရား) မသြားပါနဲ႔ဆိုလို႔ မရေတာ့ဘူးဆိုတာ ေသခ်ာၾကပလား ... (ေသခ်ာပါၿပီဘုရား)။<br/>       အင္း - ငါမရွိေတာ့ ဘာျဖစ္သတုံး၊ ဟို -ငါ့ဥစၥာေတြေပ်ာက္ ကုန္တာေပါ့ ... (မွန္ပါ့) ငါ့ဥစၥာေတြ ပ်က္စီးကုန္တာေပါ့ ... (မွန္ပါ့ဘုရား)။<br/>       အင္း ... ငါ့ဥစၥာေတြတဲ့၊ ဒကာ ဒကာမတို႔ တဏွာပဋိစၥ သမုပၸါဒ္ ဖြင့္ျပန္ၿပီ ... (ဖြင့္ပါတယ္ဘုရား)။<br/>       ခုႏွစ္တုန္းက ငါ့-ပဋိစၥသမုပၸါဒ္ (မွန္ပါ့) ငါ- ပဋိစၥသမုပၸါဒ္ ဆိုေတာ့ ဒိဠိပဋိစၥသမုပၸါဒ္ ... (မွန္ပါ့) ရွင္းပလား ... (ရွင္း ပါၿပီဘုရား)။<br/>       ေနာက္က်ေတာ့ ... ငါမရွိလို႔ရွိရင္ ငါ့ပစၥည္းေတြဟာ ကစင့္ ကရဲျဖစ္ကုန္တာပဲ၊ ဟာကုန္တာပဲ ... ငါ့ဥစၥာေတြ ဟာကုန္ၿပီ (မွန္ပါ့) ငါ့ဥစၥာေတြ ဟာတယ္ဆိုေတာ့ ဘာပဋိစၥသမုပၸါဒ္တုံး ... (တဏွာ ပဋိစၥသမုပၸါဒ္ပါဘုရား)။<br/>       အင္း -ခင္ဗ်ားတို႔ အိမ္ျပန္မွာကို ဘုန္းႀကီးက စိုးရိမ္တယ္ ..(မွန္ပါ့) ဦးမာဒင္ အိမ္ျပန္မွာ စိုးရိမ္တယ္ ... (မွန္ပါ့) ဦးလွဘူး မစိုးရိမ္ထိုက္ဘူးလား ... (စိုးရိမ္ထိုက္ပါတယ္ဘုရား)။<br/>       ဟ... အိမ္ျပန္တာ ဘုန္းႀကီးက ဘာစိုးရိမ္စရာ ရွိသလဲ ... အို .. ဒီႏွစ္ခုက သြားေတာ့မလို႔ ... (မွန္ပါ့) ရိပ္မိပလား ... (ရိပ္မိပါၿပီဘုရား)။<br/>       ခင္ဗ်ားတို႔ ကိုယ့္အိမ္ကိုယ္ျပန္တာကို မသထာလို႔ မဟုတ္ပါ ဘူး ... (မွန္ပါ့) ... အိမ္ျပန္တာလား၊ အပါယ္ျပန္ တာလားဆိုတာ ... (အပါယ္ျပန္တာပါဘုရား) ရွင္းပလား  (ရွင္းပါၿပီဘုရား) အံမယ္ေလး... ေၾကာက္စရာႀကီးပါကလား... (မွန္ပါ့)။<br/>       သုံးမ်ိဳးစလုံးဟာ ...(သမုဒယနဲ႔ ဒုကၡခ်ည့္ပါဘုရား) ေကာင္း ၿပီ၊ သုညတဆိုက္သြားရင္ သမုဒယနဲ႔ ဒုကၡခ်ဳပ္တယ္ ... (မွန္ပါ့) ဒါျဖင့္ ႏွစ္ခုခ်ဳပ္ရင္ ႏွစ္ခုေပၚမွာပဲ (မွန္ပါ့)။<br/>       ႏွစ္ခုခ်ဳပ္ရင္ ...(ႏွစ္ခုေပၚမွာပါဘုရား) အင္း ... ဒါျဖင့္ ဒကာဒကာမတို႔ သမုဒယနဲ႔ ဒုကၡခ်ဳပ္သြားတယ္ဆိုရင္ နိေရာဓနဲ႔ မဂၢင္ေပၚဖို႔ပဲ ... (မွန္ပါ့ဘုရား) ရွင္းပလား ... (ရွင္းပါၿပီ ဘုရား)။<br/>       ေအး ... ဒါေၾကာင့္ ႐ို႐ိုေသေသ က်ိဳးက်ိဳးႏြံႏြံ လိုလိုခ်င္ခ်င္ သံသရာေဘးေၾကာက္ၿပီး သကာလ ကိုင္း ... ဒကာဒကာမတို႔ နာၾက၊ အလုပ္ျပေတာ့မယ္ (မွန္ပါ့) ကဲ ... အလုပ္ျပေတာ့မယ္ ေသေသခ်ာခ်ာၾကည့္ၾက။ ။<br/>       ဒကာဒကာမတို႔ သႏၲာန္မွာ ေဝဒနာလဲ သုံးမ်ိဳးပဲရွိတယ္ ... (မွန္ပါ့ဘုရား) အလြန္ဆုံး ငါးမ်ိဳးရွိတယ္ ထားလိုက္ပါေတာ့၊<br/>       သို႔ေသာ္ သုံးမ်ိဳးထဲ ေပါင္းလိုက္ရင္လဲ အတြင္းဝင္သြားလို႔ ဘုရားက သုံးမ်ိဳးပဲလို႔ ေဟာလိုက္ပါတယ္ ... (မွန္ပါ့ဘုရား)။ ။<br/>       ကိုင္း ဒကာဒကာမတို႔ ကိုယ္ေပၚမွာ ယားမယ္၊ နာမယ္ ေအာင့္မယ္ဆိုတာ ဘာေဝဒနာတုံး (ဒုကၡေဝဒနာပါ ဘုရား)။<br/>       အင္း ... ဒုကၡေဝဒနာ သိသြားကတည္းက ဒါပုဂၢိဳလ္ သတၱဝါ ေပ်ာက္ေနၿပီ (မွန္ပါ့ဘုရား) ပုဂၢိဳလ္သတၱဝါေပ်ာက္ၿပီ ဒကာဒကာမ တို႔ ... (မွန္ပါ့) ဒီကတည္းက ပုဂၢိဳလ္သတၱဝါေပ်ာက္တယ္ဆိုတာ ငါေပ်ာက္တာပဲ ... (မွန္ပါ့ဘုရား) ငါတစ္ခု ဆိတ္သုဥ္းသြားၿပီ ...(မွန္ပါ့) ေဝဒနာေပၚတာကို ေဝဒနာေပၚမွန္း သိရင္ ငါတစ္ခု ဆိတ္သုဥ္းသြားၿပီ (မွန္ပါ့ဘုရား)။<br/>       သို႔ေသာ္လည္း ဒကာဒကာမေတြ ေဝဒနာေပၚတာ ေဝဒနာ ေပၚမွန္းသိရင္ ငါေပ်ာက္ၿပီ ...(မွန္ပါ့) ေဝဒနာကိုး ဒကာသစ္ရ (မွန္ပါ့) ငါဟုတ္ေသးရဲ႕ လား (မဟုတ္ပါဘုရား)။<br/>       ဒီေဝဒနာကေလးကို တစ္ခါ ဦးမာဒင္က ေစာင့္ဆိုင္းၿပီး နည္း နည္းၾကည့္လိုက္ေတာေပါ့ဗ်ာ (မွန္ပါ့) ၾကည့္လိုက္ေတာ့ ေဝဒနာ ကေလး၏ သက္တမ္းကလဲ ၁ နဲ႔ ၂ ပဲရွိတယ္ (မွန္ပါ့) ၁-မွာ ျဖစ္ၿပီး ၂ မွာပ်က္ရွာတယ္ ... (မွန္ပါ့) မပ်က္ဘူးလား (ပ်က္ပါ တယ္ဘုရား)။<br/>       ဒါျဖင့္ အပ်က္ျမင္လိုက္တယ္ ... (မွန္ပါ့) အပ်က္ျမင္လိုက္ ေတာ့ ငါ့ဥစၥာရွိေသးရဲ႕ လား ...(မရွိပါဘုရား)။<br/>       ဟာ ... ဒါျဖင့္ အျဖစ္ျမင္ရင္ ငါျပဳတ္တယ္ ... (မွန္ပါ့ ဘုရား) အပ်က္ျမင္ရင္ ငါ့ဥစၥာျပဳတ္တယ္ ... (မွန္ပါ့) ေသခ်ာ ပလား (ေသခ်ာပါၿပီဘုရား)။<br/>       အျဖစ္ျမင္ရင္ ... (ငါ့ျပဳတ္တယ္)၊ အပ်က္ျမင္ရင္ ... (ငါ့ဥစၥာ ျပဳတ္ပါတယ္ဘုရား)။<br/>       ေၾသာ္ ... ဒါျဖင့္ ဒို႔ဟာ ျဖစ္ပ်က္ျမင္ဖို႔ အေရးႀကီးတယ္ ... (မွန္ပါ့) ဦးမာဒင္ ဒီေရာက္တာပဲ ...(ေရာက္ပါတယ္) ဒီ ေရာက္တာပဲ၊ ဒီကလြဲလို႔ ေဟာလို႔ မရဘူး ... (မွန္ပါ့) သုံးဆယ့္ တစ္ဘုံထဲမွာ ရွိတာကလဲ ျဖစ္ပ်က္ပဲ ရွိတာကိုး (မွန္ပါ့) ဒီျပင္ဟာက တန္ဆာသာဆင္ေနရတယ္ ဒကာဒကာမတို႔ ဒါရႈဖို႔ ပါပဲ ... (မွန္ပါ့ဘုရား)။<br/>       ကဲ ... ဒကာဒကာမတို႔ ငါက ဒိ႒ိ၊ ငါ့ဥစၥာက တဏွာ ... (မွန္ပါ့) ငါ ငါ့ဥစၥာ မျပဳတ္လို႔ ရွိရင္လဲ ပဋိစၥသမုပၸါဒ္ တန္းတာပဲ (တန္းပါတယ္ဘုရား)။ <br/>       ဘယ့္ႏွယ့္ေၾကာင့္ ငါ-ငါ့ဥစၥာ မျပဳတ္သတုံးလို႔ ေမးတဲ့အခါလဲ ဒီက ဓမၼအေပၚ၌ သုညတမျဖစ္ဖို႔ ... (မွန္ပါ့) ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။<br/>       ဓမၼအေပၚ၌ (သုညတမျဖစ္လို႔ ပါ) ဓမၼအေပၚ၌ သုညတ မျဖစ္လို႔ လို႔ ေသေသခ်ာခ်ာမွတ္ပါ... (မွန္ပါ့ဘုရား)။<br/>       ဒါျဖင့္ ယားတယ္ ဘာေဝဒနာတုံး.. (ဒုကၡေဝဒနာပါ)<br/>       ဪ ... တိုင္း ယားတိုင္း ဒါ-ဒုကၡေဝဒနာပါကလား... ဒါဒုကၡေဝဒနာပါကလားလို႔ သိေနလို႔ရွိရင္လဲ ဒကာဒကာမတို႔ ေဝဒနာအလုပ္သာ ျဖစ္ေတာ့တယ္၊ ငါ့အလုပ္မရွိဘူး... (မရွိပါ ဘုရား) ဒီကတည္းက ငါျပဳတ္ၿပီ-(မွန္ပါ့) မျပဳတ္ေသဘူးလား(ျပဳတ္ပါတယ္ဘုရား)။<br/>       ကဲ-ယားတတ္ၾကပလားခင္ဗ်ားတို႔- (ယားတတ္ပါၿပီ) ယား တိုင္းယားတိုင္းဒါဘာေဝဒနာတုံး-(ဒုကၡေဝဒနာပါ) သို႔ေသာ္လဲ ဒုကၡေဝဒနာေတာ့ သိၿပီဆိုေတာ့ ဦးမာဒင္ ဘာျပဳတ္သြားသတုံး (ငါျပဳတ္သြားတယ္) ငါျပဳတ္သြားတယ္- (မွန္ပါ့) ငါျပဳတ္ၿပီေနာ္(မွန္ပါ့ဘုရား)။<br/>       ငါျပဳတ္တယ္၊ ေစာင့္ၾကည့္-ေစာင့္ၾကည့္ ဒကာဒကာမတို႔ ဝိပႆနာဆိုတာ ေစာင့္ၾကည့္ရတဲ့ အလုပ္မ်ိဳး -(မွန္ပါ့)ေစာင့္ၾကည့္ေတာ့ ေဝဒနာကေလးကလဲ ေပ်ာက္ပ်က္သြားတာပဲ - (မွန္ပါ့) ေပ်ာက္ပ်က္မသြားဘူးလား (ေပ်ာက္ပ်က္သြားပါတယ္ဘုရား) ေပ်ာက္ပ်က္သြားေတာ့ ငါ့ဥစၥာ မဟုတ္လို႔ ေပ်ာက္တာ - (မွန္ပါ့ဘုရား)။<br/>       အင္း - ေပ်ာက္သြားေတာ့ ဘာျပဳတ္သြားပါလိမ့္၊ ငါ့ဥစၥာျပဳတ္ သြားပါတယ္၊ တဏွာျပဳတ္တယ္ - (မွန္ပါ့) ငါ့ဥစၥာဆိုတဲ့ တဏွာ ျပဳတ္တယ္- (မွန္ပါ့ဘုရား)။<br/>       ဒါျဖင့္ ေပၚလာတယ္လို႔ သိလို႔ရွိရင္ ငါျပဳတ္တယ္ - (မွန္ပါ့) ပ်က္သြားၿပီလို႔ သိရင္... (တဏွာျပဳတ္ပါတယ္) ငါ့ဥစၥာျပဳတ္တယ္ (မွန္ပါ့) သေဘာက်ပလား ... (က်ပါၿပီဘုရား)။<br/>       ဒါကေလးရွင္းေနေအာင္ ဦးမာဒင္ ေျပာရဦးမယ္(မွန္ပါ့) ေျပာရမယ္- ေျပာရမယ္၊ ဒီဥစၥာကေလးဟာ ဪ... ဒို႔ျဖစ္ပ်က္ အလြန္ေက်းဇူးမ်ားတာပါကလားဆိုတဲ့ဥစၥာ ဒကာဒကာမတို႔ ယေန႔ ရွင္းရွင္းလင္းလင္းႀကီး နားလည္ရတဲ့အတြက္ ေသေပ်ာ္တဲ့တရား ... (မွန္ပါ့) ေသေပ်ာ္တဲ့တရားလို႔ ေသေသခ်ာခ်ာ ဆုံးျဖတ္ ခ်က္ခ်ပါ ... (မွန္ပါ့ဘုရား)။<br/> (ဆက္လက္ေဖာ္ျပပါမည္)<br/> ~~~~~~~~~~~~</p>
