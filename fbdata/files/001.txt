<p>ေက်းဇူးေတာ္ရွင္ အဂၢမဟာပ႑ိတ<br/> မိုးကုတ္ဆရာေတာ္ဘုရားႀကီး ကိုယ္တိုင္ ပဋိစၥသမုပၸါဒ္​စက္ဝိုင္းစာရြက္ကို ႐ွင္းလင္းေဟာျပေတာ္မူေသာတရားျဖစ္သည္။<br/> ~~~~~~~~~~~~~</p>
<p> ခႏၶာပဋိစၥသမုပၸါဒ္ျဖစ္စဥ္<br/> တရားေတာ္ (အပိုင္း-၁)</p>
<p> (၁၇-၁၁-၆၁)</p>
<p>         ဒကာဒကာမတို့ ကိုယ့္စာရြက္ ကိုလဲ ကိုယ္ၾကည့္ပါ ၊ဒီက ျပတာကိုလဲ ၾကည့္ပါေနာ္၊(မွန္ပါ့ဘုရား)။<br/>         ဒီဘက္က ဒကာ ဒကာမေတြ နံပါတ္မထိုးရေသးလို႔ရွိရင္ အတိတ္အေၾကာင္း ငါးပါး ဆိုတာက ၁- နံပါတ္ကေလးထိုး ၾကပါေနာ္၊ ကိုယ့္ဟာကိုယ္ အခုထိုးလိုက္ပါ၊  ဒီဘက္က ပစဳၥပၸန္အက်ိဳးဆီက ၂-ကေလးထိုးလိုက္ပါ၊  ဒီဘက္က ပစဳၥပၸန္ အေၾကာင္းျခင္းရာ ငါးပါး ဆီက ၃- ကေလးထိုးပါ၊  ဒီက အနာဂတ္ အက်ိဳး အျခင္းရာ ငါးပါး ဆီက ၄- ကေလးနံပါတ္ ထိုးလိုက္ပါ ၊ (မွန္ပါ့ဘုရား) ။<br/>       ဒါအခုထိုးရမွာ ၊ အခုထိုးရမွာ၊ ေနာက္မွထိုးလို႔မျဖစ္ဘူး၊ ေတာ္ေတာ္ၾကာ ၁-၂-၃-၄  နဲ႔ ေျပာေတာ့ နားမလည္ဘဲေနမွာ စိုးလို႔ ၊( မွန္လွပါ ဘုရား) ဒကာၾကြယ္ -ထိုးေနာ္၊ (မွန္ပါ့)<br/> ၁-၂-၃-၄     ဆိုတာ သူ႔အတန္းနဲ့သူထိုးဖို႔ ဒီပံုစံ ႀကီးျမင္သျဖင့္လဲ ဒီအတိုင္းၾကည့္ထိုးလဲ ဒကာႀကြယ္ တို့ရပါတယ္ ၊ (မွန္ပါ့) တရားနာ ပါ- တရားနာပါ ၊ ျပလဲျပမယ္ ၊ တရားလဲနာရ လိမ့္မယ္ေနာ္ ၊ (မွန္ပါ့ ) ။ <br/>       ျမတ္စြာဘုရားသခင္ ကိုယ္ေတာ္ျမတ္ႀကီးဟာ ဘုရား ျဖစ္တယ္ဆိုတာ ဒကာ ဒကာမ ေတြဘုရား အျဖစ္သို႔ အရယူလာခဲ့တယ္ဆိုတာ ဘုန္းႀကီးတို့ဒကာ ဒကာမ ေတြသိပါ ျပီ ၊  (မွန္ပါ့ ဘုရား) ။<br/>       ေဩာ္- ကိုယ္ေတာ္ျမတ္ႀကီးဟာ ဘယ့္ႏွယ့္ေၾကာင့္ အလံုးစံု သိတဲ့ သဗၺညဳတဥာဏ္ ေတာ္ႀကီး အလံုးစံု ဝဋ္ဒုကၡ ကၽြတ္တဲ့ ကိုယ္ေတာ္ႀကီး ျဖစ္သြားပါလိမ့္မလဲ လို့ဒကာ ဒကာမ ေတြက စဥ္းစား ခန္းထုတ္ေတာ့ ကို ပဋိစၥသမုပါၸဒ္ ျပတ္သြားလို့ ဘုရား ျဖစ္သြားတယ္လို့ မွတ္ပါေနာ္ ၊ (မွန္ပါ့) ။ <br/>       ဘာေၾကာင့္ ဘုရားျဖစ္ ပါလိမ့္ ၊ (ပဋိစၥသမုပါၸဒ္ ျပတ္သြားလို့ ဘုရားျဖစ္ပါတယ္ ဘုရား) ပဋိစၥသမုပါၸဒ္ ျပတ္သြားလို့ ဆိုတဲ့ အဓိပၸာယ္ေနာ္ ၊ (မွန္လွပါ ဘုရား ) ။<br/>       အဲ့ဒီေတာ့ ပဋိစၥသမုပါၸဒ္ ျပတ္မွပဲ ကိုယ္ေတာ္ျမတ္ႀကီး ဘုရား အျဖစ္သို႔  ငါသည္ကားလို႔ ဆိုရင္ " ဝိဓူပယံ တိ႒တိ မာရေသနံ သူရိေယာဝ ၾသဘာသယမႏၱလိကၡံ " ဆိုျပီး ငါသည္ ေနဝန္း , လဝန္းႀကီးလိုေပၚထြန္းျပီး<br/> သကာလ ဥာဏ္ေတာ္ ယွဥ္ ျပီး သကာလ လင္းရတယ္ဆိုတဲ့ ဥစၥာ ကိုလဲ ကိုယ္ေတာ္ျမတ္ႀကီး သူ႕ဟာသူ ဝမ္းေျမာက္ ေတာ္မူတယ္ ၊ (မွန္လွပါ ဘုရား ) ။ <br/>       အဲ့ဒီေတာ့ ကိုယ္ေတာ္ျမတ္ႀကီး ဘုရား ျဖစ္တဲ့ လမ္းစဥ္ကို က်ဳပ္တို႔က က်င့္ ရေတာ့ မယ္ဆိုေတာ့ သူ႔လို ဘုရားမျဖစ္ျငားေသာ္လဲ သူလဲ ေသာတပန္ကစ , ေတာ့ က်ဳပ္တို႔ လဲ ေသာတာပန္ ကစ , ရမယ္ ၊(မွန္လွပါ ဘုရား) <br/>       အဲ့ဒီကဲ့သို႔ ေသာတာပန္ကစ , ရေတာ့ ေသာတာပန္ျဖစ္ခ်င္လဲဆိုင္ရာ ပဋိစၥသမုပၸါဒ္ ဒကာ ဒကာမ တို့ ျပတ္ရလိမ့္ လို႔ မွတ္ထားၾကပါ ၊ (မွန္လွပါ ဘုရား ) ဆိုင္ရာ ပဋိစၥသမုပါၸဒ္ ကို၊ (ျပတ္ရမွာပါ ဘုရား ) မျပတ္ရင္ ျဖစ္ကို မျဖစ္ဘူးဆိုတဲ့ အဓိပၸာယ္ ပဲေနာ္ ၊ (မွန္ လွပါ ဘုရား) ။<br/>       အဲ့ဒီေတာ့ ဘုန္းႀကီး တို႔ဒကာ ဒကာမ ေတြထဲမွာ တဲ့ ၊ ဒီခႏၶာႀကီးက ဘာခႏၶာ ႀကီးတံုးလို႔ ကိုယ့္ဟာကိုယ္ပဲ ေဝဖန္ၾကည့္လိုက္လို႔ရွိရင္ ျဖင့္ ပဋိစၥသမုပါၸဒ္ ခႏၶာ ႀကီးလို႔ မွတ္လိုက္ စမ္းပါ ( မွန္လွပါ ဘုရား) ဒီခႏၶာ ႀကီးက ဘာပါလိမ့္ ၊ ( ပဋိစၥသမုပါၸဒ္ ခႏၶာ ႀကီးပါ ဘုရား ) ။ <br/>      ပဋိစၥသမုပါၸဒ္ ခႏၶာ ႀကီး ဆိုတာ သိေနၾကျပီတဲ့ ၊  ပဋိိစၥသမုပါၸဒ္ ခႏၶာႀကီး ဟာ ေၾသာ္ ခႏၶာ ႀကီးဟာ ဘဝစက္ လည္ေနတဲ့ ခႏၶာ ႀကီး ဆိုျပီး ပဋိစၥသမုပါၸဒ္  ခႏၶာႀကီး ဒကာ ဒကာမ ေတြက သိေနေတာ့ ယခု ဘဝ ျပီးရင္ ေနာက္ဘဝ သြားရမယ္ ၊ ( မွန္ ပါ့ ) ေနာက္ဘဝျပီး သကာလ တစ္ခါထပ္ျပီး အနာဂတ္ဘဝ သြားရမယ္ ( မွန္လွပါ ဘုရား ) အနာဂတ္ဘဝကေနျပီး ျပန္လွည့္ရမယ္ ၊ ( မွန္လွပါ ဘုရား) ။ <br/>       ေၾသာ္ - ဒါျဖင့္ ဒကာ ဒကာမ ေတြ ခႏၶာ ကိုယ္ႀကီး ဟာ ဒီဘဝက စုတိနဲ႔ ဟိုဘဝက ပဋိသေႏၶ နဲ႔ဆက္စပ္ ေနတာလ ဲ  ပဋိစၥသမုပါၸဒ္ ပဲ ၊ ( မွန္လွပါ ဘုရား ) စုတိနဲ႔ ပဋိသေႏၶ ဆက္ ေနတာလဲ ဘာပါလိမ့္ ၊ ( ပဋိစၥသမုပါၸဒ္ ပါဘုရား ) ကံနဲ႔ အက်ိဳးေပး ဆက္ေနတာေကာ ၊ ( ပဋိစၥသမုပါၸဒ္ ပါ ဘုရား ) ။<br/>     ကံနဲ႔အက်ဳိးေပး ဆက္ေနတာလဲ ပဋိစၥသမုပါၸဒ္ ပဲလို႔ ဘုန္းႀကီးတို့ ဒကာဒကာမ ေတြက မွတ္ထားေတာ့ အခု က်န္တဲ့ အက်ိဳးေပး ျပတ္သြားလို႔ ရွိရင္ လဲ ပဋိစၥသမုပါၸဒ္ ျပတ္တယ္ ၊ (မွန္လွပါ ) စုတိပဋိသေႏၶ ျပတ္သြားရင္လည္း ၊ (ပဋိစၥသမုပါၸဒ္ ျပတ္ပါတယ္ ဘုရား )။ <br/>        ပဋိစၥသမုပါၸဒ္ ျပတ္သြားတယ္လို႔ ဘုန္းႀကီးတို့ ဒကာ ဒကာမေတြက မွတ္ထားေတာ ့ ေၾသာ္-  ပဋိစၥသမုပါၸဒ္ ျပတ္ရင္ နိဗၺာန္ ပဲလို႔လဲ မွတ္လိုက္ ပါဦး၊ ( မွန္ပါ့ ဘုရား ) ။ ပဋိစၥသမုပါၸဒ္ ျပတ္ ရင္ ( နိဗၺာန္ ပါ ဘုရား ) ။<br/>      နိဗၺာန္ဆိုတာ ဒကာ-ဒကာမေတြ ေသေသခ်ာခ်ာ မွတ္ ထားေတာ့ ေၾသာ္-နိဗၺာန္ လိုခ်င္ရင္ျဖင့္ ခႏၶာ႔  ပဋိစၥသမုပါၸဒ္ ျပတ္ရမွာပါ ကလား လို႔ ဆိုတဲ့ အက်ဥ္းခ်ဳပ္စကား ကေလးမွတ္ ထားလိုက္စမ္းပါ ( မွန္လွပါ ဘုရား ) နိဗၺာန္လိုခ်င္ရင္ (ခႏၶာပဋိစၥသမုပါၸဒ္ ျပတ္ရမွာပါ ဘုရား ) အဲ- ခႏၶာ႔ ပဋိစၥသမုပါၸဒ္ မျပတ္လို႔ ရွိရင္နိဗၺာန္ မရပါဘူး ၊ <br/> ( မွန္လွပါ ) ခႏၶာ႔ ပဋိစၥသမုပါၸဒ္ ျပတ္မွသာလွ်င္ နိဗၺာန္ အစစ္ကို အနုပါဒိေသသနိဗၺာန္ ဆိုတာရနိုင္ပါတယ္ ၊ <br/> ( မွန္လွပါဘုရား) ။ <br/>       ဒါျဖင့္ ဒကာ ဒကာမ တို႔ ခႏၶာ႔ ပဋိစၥသမုပါၸဒ္ ျပတ္ဖို့ အေရးသည္ က်ဳပ္တို႔ နိဗၺာန္ေရာက္ဖို့အေရးပဲ ( မွန္ပါ့ဘုရား) <br/> ခႏၶာ႔ ပဋိစၥသမုပါၸဒ္ ျပတ္ေအာင္လုပ္နိုင္တဲ့ ပုဂၢိဳလ္ ဟာ အရင္ျပတ္ရင္ အရင္ နိဗၺာန္ရတာပဲ ၊ ( မွန္ပါ့ဘုရား)။ <br/>       အဲ့ဒီေတာ့ ဒီေနရာမွာ ခႏၶာ႔ ပဋိစၥသမုပါၸဒ္ ျပတ္နည္း ကိုမသိတာက ဘာလဲလို႔ ေမးလို႔ရွိရင္ ျဖင့္ - တဲ့ ၊ ဒကာ ဒကာမေတြ ယံုမွားသံသယ ရွိေနၾကတယ္ ၊ ေၾသာ္ - ဒို႔အေမ- ဒို႔အေဖေမြးထားလို႔ ဒို႔သားသမီး ျဖစ္လာတယ္လို႔ <br/> ဒီလို အယူရွိၾကတယ္၊ (မွန္ပါ့ဘုရား) ။<br/>     အေဖ-အေမေမြးလို႔သားသမီး မ်ားထြန္းကားလာတယ္လို႔ ယူၾကပါတယ္ ၊ (မွန္လွပါဘုရား ) ထိုကဲ့သို႔ ယူၾကေတာ့ အေဖ-အေမ သည္ သား သမီးတို႔ျဖစ္ ျခင္း၏ အေၾကာင္းလို႔ ဒကာ ဒကာမ ေတြထင္ၾကမွာပဲ ၊ (မွန္ပါ့ ) အေမ-အေဖသည္ သား သမီး ၏ျဖစ္ျခင္း၏ အေၾကာင္း လို႔ထင္ပါလိမ့္မယ္ ၊ (မွန္ပါ့ )။ <br/>     သို့ေသာ္ ခင္ဗ်ားတို႔ ထင္ထားသည္ကား -လို႔ ဆိုလို႔ရွိရင္ တစ္စိတ္တေဒသ မွန္၍အကုန္မမွန္ဘူးဆိုတာ ဆံုျဖတ္ခ်က္ခ်ပါ ၊ ( မွန္လွပါ ) အကုန္မမွန္ပါဘူး ၊ ( မွန္ပါ့ ) ။ <br/>     ဒကာ ဒကာမ ေတြစဥ္းစားၾကည့္ပါ -တဲ့ ၊ တစ္ခ်ိဳ႕မွာ အိမ္ေထာင္ရက္သားက်တာ ေတာ္ေတာ္ၾကာျပီ ၊သား သမီး တစ္ေယာက္မွ မထြန္းကားဘူး ၊ (မွန္လွပါ ဘုရား ) ဒီလိုဆိုတာေကာ မရွိဘူးလား၊ (ရွိပါတယ္ဘုရား ) ဦးသန္းေမာင္ ဒါေတြက ရွိတယ္ေနာ္ ၊ (မွန္လွပါ ) ။ <br/>      အဲ့ဒါ အေမ- အေဖ နဲ႔ မဆက္သြယ္ လို႔ဆိုတာလဲ ဒီေနရာ ကန့္ကြက္္ခ်က္ တစ္ခုဝင္လိမ့္မယ္ ဆို ဝင္ရမွာပဲ ၊ (မွန္လွပါ ဘုရား) မဝင္ရေပဘူးလား၊ ( ဝင္ရမွာပါ ဘုရား )။ <br/>       ဒါျဖင့္ ဒီဟာလဲ အယူမွန္ မဟုတ္ေသးဘူး ၊ (မွန္လွပါ )သေဘာပါပလား ၊ ( ပါ ,ပါျပီ )အေမ-အေဖ ေၾကာင့္ သား သမီးျဖစ္ရတယ္ဆိုတာ အယူဟုတ္မွန္သလား ၊ ( မဟုတ္ပါ ဘုရား )။  <br/>        တစ္ခ်ိဳ႕ သားသမီး တစ္ေယာက္မွ မထြန္းကားဘူးဆိုတာေတြလဲ အေမ အေဖေတြ ေသသြားေရာ ၊ သားသမီး မထြန္းကားတာေတြ ေထာက္ေတာ့ အေမ အေဖ ေၾကာင့္ ဆိုတဲ့စကားဟာ အင္း.... မမွန္ဘူးေဟ့ဆိုတာ သိပါတယ္ ၊ (မွန္ပါ့ သိပါတယ္ ဘုရား)။ <br/>       အဲ့ဒါေတာ့ ပယ္လိုက္ျပီ ၊ အေမ အေဖ ေၾကာင့္ ဆိုတာ ေဝးေသာအေၾကာင္းေတာ့ျဖစ္ပါတယ္ေနာ္ ၊ ( မွန္ပါ့ ဘုရား) အေမ အေဖ ေၾကာင့္ သားသမီး ခႏၶာ ငါးပါး ျဖစ္လာတယ္ ဆိုတဲ့ ဥစၥာ ဟာ ေၾသာ္ ....မမွန္ ေသးပါလား  ဆိုတာလဲ ယေန႔ ဆံုးျဖတ္ခ်က္ခ်လိုက္ ၊ ( မွန္ပါ့ ဘုရား)။ <br/>       တစ္ခါစဥ္းစားေတာ့လည္း ထာဝရဘုရားက ဖန္ဆင္းတယ္ လို႔ တစ္ခ်ိဳ႕ ခရစ္ယာန္ မဟာေဗဒင္ဆိုတဲ့ အယူဝါဒ ေတြမွာ ရွိေသးတယ္ ၊ (မွန္လွပါ ဘုရား) ဘယ္သူ ဖန္ဆင္းသတံုး ၊ (ထာဝရဘုရား က ဖန္ဆင္းပါသတဲ့ ဘုရား) ။<br/>        ထာဝရဘုရားက ဖန္ဆင္းတယ္ ဆိုျပီး သကာလ လူေတြနတ္ေတြ ျဗဟၼာေတြ ဟာ ထာဝရဘုရားက ဖန္ဆင္းတယ္ဆိုျပီး သကာလ ခရစ္ယာန္ မဟာေဗဒင္ အစရွိသည္ တို႔မွာ ယူျပီး သကာလ ထားတယ္ ၊ (မွန္ပါ့)။<br/>        အဲသည္ကဲ့သို႔ ဖန္ဆင္းတယ္လို႔ ယူထားတဲ့ အခါ က်လို႔ ရွိရင္လဲ အေၾကာင္းက မကုန္ပဲ ျဖစ္ေနတယ္ ၊ ( မွန္ပါ့) <br/> ထာဝရဘုရားက်ေတာ့ ဘယ္သူက ုဖန္ဆင္းသလဲ ဆိုတဲ့ ေမးခြန္းဟာ ထြက္လာတယ္ ၊ ( မွန္ပါ့ ) မထြက္လာ ဘူးလား ၊ ( ထြက္လာပါတယ္ဘုရား )။ <br/>         ဒါက်ေတာ့ -တဲ့ သူတို႔ မေျပာတတ္ျပန္ဘူး ၊ ( မွန္လွပါ )ေျပာတတ္ျပန္ ေတာ့ ဖန္ဆင္းတယ္ ဆိုတာလဲ မဟုတ္ေသးပါဘူး ၊ ( မွန္လွပါ ဘုရား )။<br/>          အေမ အေဖ ေၾကာင့္လည္း မဟုတ္ေသး၊ (မွန္လွပါ ဘုရား) ဖန္ဆင္းျခင္း ေၾကာင့္လည္း၊ (မဟုတ္ေသးပါ ဘုရား)။<br/>          တစ္ခါ ဟိႏၵဴေတြ က်ျပန္ေတာ့ လည္း ဒကာ-ဒကာမ ေတြမွတ္စရာ ကျဗဟၼာႀကီး ေျခာက္ေယာက္က ေမြးတယ္၊ လူဆင္းရဲမ်ား၊(မွန္ပါ့) ျဗဟၼာႀကီး ဝမ္းဗိုက္ထဲက ေမြးဖြားတယ္ ၊ လူခ်မ္းသာမ်ား ၊ (မွန္ပါ့) ျဗဟၼာႀကီး ဝမ္းထဲက ခြဲထြက္တဲ့ ပုဂၢိဳလ္ မ်ား၊ (မွန္ပ့ါ) ျဗဟၼာႀကီး ဦးေခါင္းက ေမြးတဲ့ ပုဏၰားမ်ား၊ (မွန္ပါ့) သူတို႔က ဒီလို ယူထား တယ္၊(မွန္ပါ့ ဘုရား) ျဗဟၼာႀကီးကပဲ အကုန္ေမြးထုတ္တာပဲ ၊ (မွန္ပါ့)။ <br/>        ဒီလို ဆိုျပန္ေတာ့လည္း ခုနင္က အေမးဟာ ထြက္လာဦးမွာပဲ၊ (မွန္ပါ့) ဦးသန္းေမာင္ ထြက္ရမယ္ ၊ (ထြက္ရပါမယ္ဘုရား) ၊ ၎ျဗဟၼာႀကီးကိုေတာ့ ဘယ္သူက တည္ေထာင္သတံုး ဆိုတဲ့ ေမးခြန္းထြက္လာတယ္၊ <br/> (ထြက္လာပါတယ္ဘုရား) မထြက္လာဘူးလား ၊ ( ထြက္လာပါတယ္ ဘုရား) ။ <br/>        အဲ့ဒီေတာ့လည္း အေျဖဟာ ေပ်ာက္သြား ဦးမွာပဲ ၊ (မွန္ပါ့) ဒကာၾကြယ္- ဘယ့္ႏွယ့္ ေျဖမလဲ ၊ (ေပ်ာက္သြား ပါမယ္ဘုရား) အေျဖေပ်ာက္ သြားလိမ့္မယ္ ဆိုတာလဲ ဧကန္ပဲ ဆိုတာ ယံုၾကည္ပလား ၊ (ယံုၾကည္ပါျပီ ဘုရား)။ <br/>        ဒါျဖင့္ ဘုန္းႀကီတို႔ ဒကာ ဒကာမ ေတြမွာျဖင့္ အင္း-ကိုယ့္အေမ အေဖ ေတြးလိုက္ျပန္လဲ အကုန္ ႏွံ႔စပ္တဲ့ စကားမဟုတ္ဘူး (မွန္လွပါ ဘုရား) ခရစ္ယာန္ ဘာသာကို ေတြးလိုက္ျပန္ေတာ့လဲ သံသယ ရွိစရာ ေပၚလာတယ္၊ (ေပၚလာပါတယ္ ) ဟိႏၵဴဘာသာ ကိုေတြးလိုက္ျပန္ေတာ့လဲ သံသယရွိစရာေပၚလာတယ္ ၊ (ေပၚလာပါတယ္ဘုရား)။<br/>         ဒါျဖင့္ သံသယနဲ႔ပဲ ဒို႔ဘယ္က လာပါလိမ့္မတံုး ဆိုျပီးေသသြား ၾကတယ္ ၊ (ေသသြားပါတယ္ ဘုရား) အင္း-ဒို႔ကိုဘယ္သူက လုပ္လိုက္လို႔ ဒို႔-ယခု ရုပ္ နာမ္ ခႏၶာ ႀကီး ရေနပါလိမ့္မလဲဆိုတဲ့ ဒကာၾကြယ္တို႔ ဦးသန္းေမာင္တို႔ဟာ ကိုယ့္ဟာကိုယ္ မသိတဲ့သေဘာမရွိဘူးလား ၊ (ရွိပါတယ္ ဘုရား) ။ <br/>           ကိုယ့္ဟာကိုယ္ သံသယ ရွိတယ္၊ ငါဘယ္ႏွယ့့္ေၾကာင့္ ဒီအျဖစ္ ဒီအႏွစ္သို႔ ေရာက္လာပါလိမ့္မတံုး ဆိုတဲ့ သံသယ, ဒကာ ဒကာမ တို႔ ရွိလာတယ္၊ (ရွိပါတယ္ဘုရား)။<br/>           အဲ့ဒါေတြက ဘုရားကလည္းမပြင့္, ဆရာေကာင္းကလည္းမေတြ႔ တဲ့အခါ က်ေတာ့ ဒီသံသယေတြ ဘယ္သူက ေဖ်ာက္ေပးမလဲ လို႔ ေမးလို႔ရွိရင္ ဒကာၾကြယ္-ဘယ္ႏွယ့္ေျဖပါ့မလဲ ၊ (ဘယ္သူမွေဖ်ာက္မေပးနိုင္ပါ ဘုရား) ေနာက္က ဒကာ ဒကာမ ေတြဘယ္သူမ်ားေဖ်ာက္ေပးနိုင္သတံုး၊ (ဘယ္သူမွေဖ်ာက္မေပးနိုင္ပါ ဘုရား)။<br/>           ေဖ်ာက္မေပးနိုင္ေတာ့ သံသယရွိတယ္ ၊ (မွန္ပါ့ ဘုရား)ေဩာ္....ငါသည္ကားလို႔ဆိုရင္ ဘယ္လိုငါပါလိမ့္<br/> မတံုး ဆိုတဲ့ဝိစိကိစ ာၦကလဲ ဝင္လာတယ္ ၊ (ဝင္လာပါတယ္ ဘုရား) ဝိစိကိစ ာၦ ဝင္လာေတာ့ ဒိ႒ိက ဝင္လာတယ္ ၊ <br/> (ဝင္လာပါတယ္) ဦးသန္းေမာင္ေရ....ဝိစိကိစ ာၦ ဝင္ေတာ့ကို ဒိ႒ိလဲ (ဝင္လာပါတယ္ ဘုရား) ။   <br/>            ဒိ႒ိကလဲ ငါသည္ ဘယ္လိုငါပါလိမ့္ မတံုး ၊ ဒီရုပ္နာမ္ ေတြဟာငါပါလားဆိုတဲ့ ဒိ႒ိေတြဟာ လာမွာပဲ၊ (လာမွာပါပဲ ဘုရား) အဲဒီကဲ့သို႔ ပဋိစၥသမုပါၸဒ္ကို နားမလည္လို႔ ရွိရင္ ဒိ႒ိ ဝိစိကိစ ာၦနဲ႔ ေသၾကရပါလိမ့္မယ္၊ (မွန္ပါ့ဘုရား) ဘာနဲ႔ေသၾကမလဲ ၊ (ဒိ႒ိ ဝိစိကိစ ာၦနဲ႔ေသၾကပါမယ္ဘုရား)။<br/>            ဒါျဖင့္ အားလံုး အပါယ္သြားရမယ္ ၊ (သြားရမွာပါပဲ ဘုရား) ဒကာ ဒကာမ တို႔ဒိ႒ိ ဝိစိကိစ ာၦ နဲ႔ခ်ည္းေသၾက ရေတာ့မယ္ဆိုေတာ့ အားလံုး အပါယ္သြားရမယ္၊ (သြားရပါမယ္) ရွင္းပလား ၊ (ရွင္းပါျပီ ဘုရား)။ <br/>            ဒါေၾကာင့္ ဒကာ ဒကာမ တို႔ဘယ္ႏွယ့္ေၾကာင့္ အပါယ္သြားတာ ဒီေလာက္မ်ားပါလိမ့္ မတံုးဆိုေတာ့ ပဋိစၥသမုပါၸဒ္ အ ေၾကာင္းအက်ိဳး နားမလည္လို႔၊ (မွန္လွပါဘုရား) ရွင္းၾကပလား၊ (ရွင္းပါျပီ ဘုရား)။<br/>            ဘယ္ႏွယ့္ေၾကာင့္ အပါယ္သြားမ်ားပါလိမ့္ ၊ (ပဋိစၥသမုပါၸဒ္ အေၾကာင္းအက်ိဳး နားမလည္လို႔ပါ ဘုရား) ေဩာ္ -ဒါျဖင့္အပါယ္ေလးပါ တံခါးပိတ္ တဲ့တရားဟာျဖင့္ပဋိစၥသမုပါၸဒ္ နားမလည္မႈဆိုတဲ့ဒိ႒ိဝိစိကိစ ာၦ သတ္မႈပဲ၊ (မွန္လွပါ ဘုရား) ေပၚလာျပီလား ၊ (ေပၚလာပါျပီ ဘုရား)။<br/>            ဘယ္ႏွယ့္ေၾကာင့္ ဒကာ ဒကာမေတြ အပါယ္သြား မ်ားပါလိမ့္မလဲဆိုရင္ ဘယ္ႏွယ့္ ေျဖၾကမလဲ ၊ (ဒိ႒ိ ဝိစိကိစ ာၦ မသတ္နိုင္လို႔ပါ ဘုရား) ပဋိစၥသမုပါၸဒ္ နားမလည္လို႔ပါ ၊ (မွန္ပါ့) ေဩာ္....ဒါျဖင့္ ဒို႔နားမလည္ထိုက္တဲ့ တရားတစ္ခုဟာ ဆရာဘုန္းၾကီးက ခ်ီးေျမွာက္ ရေတာ့မွာပဲ ဆိုျပီး ဝမ္းေျမာက္ပါတယ္၊ (မွန္လွပါ ဘုရား)။ <br/>              အင္မတန္ အေရးၾကီးပါျပီ_ တဲ့ ၊ ခါတိုင္းေတာ့ဒီလို အဝိုင္းနဲ႔ မျပဘဲနဲ႔ ပံုတန္းတန္းျပီး ျပေနတယ္ ၊ ခုေတာ့ ျဖင့္ ကုသိုလ္ လုပ္တဲ့ပုဂၢိဳလ္ကလဲပါလာျပန္ေတာ့ အင္း....စာရြက္ေတြေဝ ကမ္းတဲ့ ဒကာ ဒကာမ ေတြကလဲ အားလံုးသိေစခ်င္တဲ့ သေဘာနဲ႔ သူတို႔ ေဝၾက-ကမ္းၾကျပန္တယ္ ၊ တစ္ခါပံုစံႀကီးကို လုပ္ျပီး ေမာင္ထြန္းရင္တို႔ လဲျပေတာ့ သိဖို႔ရာ အေၾကာင္းေတြ ကုသိုလ္ျပဳျပန္ေတာ့ ဒကာ ဒကာမေတြမွာ ကံထူးတဲ့ပုဂိၢဳလ္ေတြလို႔ဆိုရမယ္ ၊ (မွန္လွပါ ဘုရား)။ <br/>             ဘာ့ေၾကာင့္တုန္း ၊ ဘယ္လိုကံထူးတာပါလိမ့္မတံုး ေမးတဲ့အခါ က်ေတာ့ ေဩာ္ -ပဋိစၥသမုပါၸဒ္ နားမလည္ေသာ ေၾကာင့္ ဒိ႒ိဝိစိကိစ ာၦမေသ,သစၥာလဲမသိ ၊ (မွန္လွပါဘုရား) ဒိ႒ိဝိစိကိစ ာၦ (မေသပါဘုရား) သစၥာ ေကာ ၊ (မသိပါဘုရား) သစၥာလဲမသိ၊ ဒိ႒ိဝိစိကိစ ာၦလဲ မေသေတာ့ သစၥာမသိေတာ့ သံသရာရွည္၊ ဒိ႒ိ ဝိစိကိစ ာၦ မပယ္နိုင္ေတာ့ အပါယ္သြား၊ (မွန္လွပါ ဘုရား) ဒီလိုမေနဘူးလား၊ (ေနပါတယ္ ဘုရား)။<br/>             အဲ့ဒီကဲ့သို႔ ေနတဲ့အတြက္ ယေန့သည္ ဒါဆက္ျပီး ဒကာ- ဒကာမေတြ တရားပြဲ ရက္ မပ်က္ေအာင္ပဲ ဂရုစိုက္ၾကေနာ္ ၊ (မွန္လွပါ ဘုရား) က်န္းမာေအာင္လဲ ေနၾကပါလို႔ ၊ ဒါ-နားလည္လို႔ရွိရင္နားလည္ကာ မတၱနဲ႔အပါယ္တံခါးပိတ္တယ္ ၊ (မွန္လွပါ ဘုရား) စူဠေသာတာပန္ ျဖစ္ရင္ တစ္ဘဝ,ႏွစ္ဘဝ အပါယ္တံခါး ပိတ္သြားတယ္ ၊(မွန္လွပါ ဘုရား)။ <br/>            ဒီအတိုင္းပဲျဖတ္လမ္းကို ဘုန္းႀကီး ကလဲေဟာလို႔ ျဖတ္လမ္းကို က်င့္လို႔ရွိရင္ေသာတာပန္ အမွန္တည္ပါလိမ့္မယ္၊ (မွန္ပါ့ ဘုရား) ။<br/>            ဒါေၾကာင့္ ဒကာ ဒကာမ ေတြသည္ ေဩာ္...ငါတို႔ဟာ အေရးႀကီးတဲ့ အခ်က္အလက္ေတြ အခုအခ်ိန္မွာ ေရာက္ေနေသာေၾကာင့္ သားေရး, သမီးေရး ,စီးပြားေရး ဆိုတာ ပဋိစၥသမုပါၸဒ္ လည္တဲ့လမ္း၊ (မွန္လွပါ ဘုရား) ဆရာသမား ဆီမွာ ခ်ဥ္းကပ္ျပီး သကာလ ဒီဟာၾကည့္ျပီး သကာလ ဒီအဝိုင္းႀကီး ၾကည့္ျပီးသကာလ ျဖတ္တဲ့ေနရာကေန ျဖတ္လိုက္တဲ့အခါ က်ေတာ့ ေဩာ္...ဒို႔သည္ကား လို႔ဆိုရင္ အဝိုင္းေျပး ျဖစ္မွာပဲ ၊ အခုေတာ့ျဖင့္ အဝိုင္းေျပးအျဖစ္မွ လြတ္ျပီးသကာလ အင္း-တက္စရာ ထိပ္တန္းေတြ ေတြ႔ျပီလို႔ဆိုရလိမ့္မယ္၊ (မွန္ပါ့ဘုရား) ရွင္းျပီေနာ္၊ (ရွင္းပါျပီ ဘုရား) ။<br/>            ဒါျဖင့္ ဘုန္းႀကီးတို႔ ဒကာ ဒကာမေတြ ခုနင္ကေျပာခဲ့တဲ့ ဟိႏၵဴ ဘာသာဝင္ေတြေျပာေနတဲ့ အသြားဟာလည္း မဟုတ္ဘူးလို႔ မွတ္လိုက္ပါ ၊ (မွန္လွပါ ဘုရား) ခရစ္ယာန္ေတြ ေျပာေနတဲ့ ထာဝရက ဖန္ဆင္းတာေတြလဲ မဟုတ္ဘူးလို႔ပဲ မွတ္လိုက္ ၊ (မွန္လွပါ ဘုရား) အေမ,အေဖေၾကာင့္ သားသမီးခႏၶာ ေတြျဖစ္လာတယ္ဆိုတာလဲ တစ္စိတ္တစ္ေဒသသာမွန္၍ အကုန္မမွန္ဘူးလို႔ မွတ္လိုက္ ၊ (မွန္လွပါဘုရား)။<br/>            ဒါျဖင့္ အမွန္အစစ္ ကိုရွာၾကပါစို႔၊ (မွန္လွပါ ဘုရား)အမွန္အစစ္ကို ရွာၾကပါစို႔ ဆိုေတာ့ ဒကာ ဒကာမ တို႔ဒါဟာ လိုရင္းအခ်က္ပဲ ဆိုတာ ဒကာၾကြယ္ -မွတ္ရေပလိမ့္မယ္၊ (မွန္လွပါ ဘုရား)။<br/>            ကဲ....ဒါျဖင့္ဒကာ ဒကာမတို႔ အခု ရ,ထားတဲ့တရားေဟာတဲ့ ဘုန္းႀကီး၏ ခႏၶာ၊ တရားနာေနၾကတဲ့ ဒကာ ဒကာမေတြ၏ ခႏၶာငါးပါး၊ (မွန္ပါ့) သေဘာက်ပလား၊ (က်ပါျပီဘုရား) ။<br/>             တရားနာၾကတာ ,ေနၾကတာ,ထိုင္ၾကတာ ဘယ္သူေတြပါလိမ့္၊ (ခႏၶာ ငါးပါးပါ ဘုရား)ေဩာ္-ခႏၶာငါးပါး ရုပ္နာမ္ ႏွစ္ပါးေတြပဲေနာ္၊ (မွန္ပါ့ဘုရား)။<br/>             ဘယ္သူတည္ေထာင္လို႔ ဒီအျဖစ္ ဒီေနရာ ေရာက္လာပါလိမ့္မလဲလို႔ ေမးတဲ့အခါက်ေတာ့ ဘယ္သူဆိုတဲ့ ပုဂၢိဳလ္ဟာ ရွာမေတြ႔ပါဘူး၊(မွန္ပါ့ ) ဘယ္သူဆိုတဲ့ ပုဂၢိဳလ္ဟာျဖင့္၊ (ရွာမေတြ႔ပါ ဘုရား)။<br/>             ေဩာ္-ဒါျဖင့္ ပုဂၢိဳလ္ မရွိကတည္းက ဒကာ ဒကာမ ေတြကမွတ္လိုက္တာေပါ့၊ ဓမၼရွိတယ္လို႔ မွတ္ ၊ (မွန္လွပါ ဘုရား) ပုဂၢိဳလ္ ကေတာ့ မဖန္ဆင္းပါဘူး ၊ (မွန္ပါ့)  ဓမၼကတည္ေထာင္တယ္လို႔ မွတ္လိုက္တာေပါ့၊ (မွန္လွပါဘုရား)ဘယ္လိုမွတ္ၾကမယ္ ၊ (ဓမၼကတည္ေထာင္ပါတယ္ဘုရား)။<br/>              ဓမၼက တည္ေထာင္တယ္လို႔ဘုန္းႀကီးတို႔ ဒကာ ဒကာမေတြကေသေသခ်ာခ်ာ မွတ္ပါေနာ္၊ (မွန္ပါ့) ဒါနဲ႔ ဘုရားသခင္ ကိုယ္ေတာ္ျမတ္ႀကီးသည္ ဘုရားျဖစ္တဲ့ေန႔မွာ ဓမၼက တည္ေထာင္တာ ေဟာခ်င္ေတာ့ သူဘယ္လိုစ, လာသတံုးဆိုတာ ပဋိစၥသမုပါၸဒ္ နိဒါနဝဂၢသံယုတ္ ပါဠိေတာ္မွာ လာပါတယ္၊ (မွန္ပါ့ဘုရား)။<br/>              ဘယ္လိုလာသတံုးလို႔ ေမးတဲ့အခါက်ေတာ့ ဒကာဒကာမ တို႔သတၱဝါေတြ အစငါရွာမယ္ဆိုျပီးသကာလ အနမတဂၢသံယုတ္ မ်ားမွာလဲ လာထားတယ္ ၊ (မွန္ပါ႔ ဘုရား)။<br/>              သတၱဝါေတြ အစရွာ လိုက္တာ ဥပမာ မယ္၊ ဦးသန္းေမာင္အစ,ေရွးဘဝက ဦးသန္းေမာင္က နတ္ျဖစ္ခဲ႔တယ္၊ ဟိုဘက္ဘဝက ျဗဟၼာျဖစ္ခဲ့တယ္၊ ဟိုဘက္ဘဝက တိရစာၦန္ေတြျဖစ္ခဲ႔ တယ္၊ ဒီလိုပုဂၢိဳလ္ အျဖစ္ေတြနဲ႔ ေရွာက္ေတြးလိုက္တာ ဒကာ-ဒကာမတို႔ ဘုရားျဖစ္တဲ့အခ်ိန္က ဦးသန္းေမာင္အေၾကာင္းကို ေတြး၊ အင္မတန္ႀကီးက်ယ္တဲ့ဥာဏ္ႀကီးနဲ႔ ေတြးတာ ဆံုးကိုမဆံုးနိုင္ဘူး၊ (မွန္လွပါ ဘုရား)ပုဂၢိဳလ္ အျဖစ္နဲ႔ ေတြးရင္ျဖင့္ ၊ (မဆံုးပါ ဘုရား)။<br/>              မဆံုးနိုင္ေအာင္ဘဲ အေသေတြ အေနေတြ မ်ားခဲ့တယ္လို႔ မွတ္လိုက္စမ္းပါ၊ (မွန္လွပါ ဘုရား) မဆံုးနိုင္ ေအာင္ဘဲ ၊(အေသေတြ အေနေတြ မ်ားခဲ့ပါတယ္ဘုရား)။<br/>              အေသေတြ အေနေတြ မ်ားခဲ့တယ္ဆိုတာျဖင့္ ဒကာ ဒကာမတို႔ ဘုရားေတာင္မွ ပုဂၢိဳလ္ သတၱဝါ၏ အစ မျမင္ဘူး ၊ (မွန္လွပါ ဘုရား) ပုဂၢိဳလ္အစေနာ္ ၊(မွန္လွပါ) ပုဂၢိဳလ္ဆိုတာ အထည္ စ,လို႔မွတ္လိုက္စမ္းပါ ၊(မွန္လွပါ)။<br/>             ဒီခႏၶာျဒပ္ႀကီး အစေရွာက္ေတြး လိုက္တဲ့ အခါက်ေတာ့ ဘယ္ခႏၶာကစ,တယ္ဆိုတာ ဘုရားျဖစ္တဲ့ေန႔ ကေတြး ၊ပရိနိဗၺာန္ စံသည့္တိုင္ ေအာင္ေတြး ၊ တစ္ေယာက္၏ျဖစ္ပ်က္္မႈေနာက္ဆုတ္ေတြးသြားတာ ဦးသန္းေမာင္ မကုန္ဘူး၊ (မွန္လွပါ ဘုရား)။<br/>            ဒါျဖင့္က်ဳပ္တို႔ခႏၶာေတြ ဘယ္ေလာက္ ရွည္ခဲ့သလဲ ဆိုရင္  ဘယ္ႏွယ့္ ေျဖၾကမလဲ၊ (မေရမတြက္နိုင္ပါ ဘုရား) မေရတြက္နိုင္ဘူး ၊(မွန္လွပါ) ဒကာၾကြယ္ ေရတြက္နိုင္ရဲ႕လား ၊(မေရတြက္နိုင္ပါ ဘုရား) အေသခ်င္းေတြ ျဖင့္စပ္ခဲ့ေပါ့ လို႔ဆိုရင္ ေကာ ၊ (ဆိုႏိုင္ပါတယ္ ဘုရား)။<br/>           ေအး-အေသခ်င္းစပ္ခဲ့ေတာ့ ဒီေျမေတြဟာ ဘယ္သူ႔ေျမေတြတုံုးလို႔ေမးလို႔ ရွိရင္ က်ဳပ္တို႔အသားထဲကျဖစ္တဲ့ <br/> ေျမေတြပဲ (မွန္လွပါ)ဘယ္ေလာက္မ်ား က်ဳပ္တို႔အေသမ်ားခဲ့တယ္ဆိုတာ ဒကာ ဒကာမေတြရွင္းၾကပလား၊ (ရွင္းပါ ျပီဘုရား) အေသဘယ္ေလာက္မ်ားခဲ့သလဲ၊ (မေရတြက္နိုင္ပါ ဘုရား)။<br/>            ဒီေျမေတြ ဒီေရေတြဟာ က်ဳပ္တို႔သည္ကားလို႔ ဆိုလို႔ရွိရင္ က်ဳပ္တို႔အသားအေသြးေတြကိုေျမခံျပီး သကာလ<br/> ျဖစ္လာတာ(မွန္ပါ့) သေဘာက်ပလား၊(က်ပါျပီ)။ <br/>            ေကာင္းျပီ-တဲ့ ၊ဒကာ-ဒကာမ တို႔ဒါျဖင့္ပုဂၢိဳလ္ သတၱဝါေတြကျဖင့္ ေျပးခဲ့ျပီေပါ့ ၊ (မွန္ပါ့)ေျပးလို႔ကို ဆံုးရဲ႕လား <br/> (မဆံုးပါ) ဦးသန္းေမာင္ ေနာက္ဆုတ္ေျပးလိုက္တာ ဆံုးေသးရဲ႕လား ၊(မဆံုးပါဘုရား)။   <br/>           ေနာက္က ဒကာဒကာမေတြ ေနာက္ဆုတ္ေျပးတာ ဘုရားသခင္ ကိုယ္ေတာ္ျမတ္ႀကီးဟာ အင္မတန္ ႀကီးက်ယ္တဲ့ဥာဏ္၊အင္မတန္လွ်င္ျမန္တဲ့ဥာဏ္နဲ႔ေျပးတာေတာင္ ပုဂၢိဳလ္အျဖစ္နဲ႔ေျပးရင္ ဆံုးေသးရဲ႕လား၊ (မဆံုးပါ ဘုရား)အဲ့ဒါေၾကာင့္_<br/> "  အနမတ ေဂါၢယံ ဘိကၡေဝ သံသာေရာ<br/> ပုဗၺေကာဋိ နပညာယတိ "<br/>           အယံသံသာေရာ -ဤ ခႏၶာ သံသရာ ႀကီးသည္ ၊ အနမ တေဂၢါ- မသိအပ္ေသာအစရွိ၏ ၊ ငါ-မသိပါဘူးကြာ ၊ <br/> ရွည္လိုက္တာလြန္လို႔၊ (မွန္ပါ့ဘုရား) သေဘာက်ပလား ၊ (က်ပါျပီ) ။<br/>              မသိအပ္ေသာ အစ,ရွိတယ္၊ မသိအပ္ေသာ အစရွိတယ္ဆိုကတည္းက ဒကာဒကာမေတြ အစ,ရွာမေတြ႔<br/> ဘူး၊ (မွန္ပါ့) ခႏၶာေတြနဲ႔သာ ေျပးလို႔ရွိရင္ ဦသန္းေမာင္ ဘာတဲ့၊ (အစမရွိပါဘုရား) အစ,ရွာမေတြ႕ဘူးဆိုတာ ဒကာ, ဒကာမေတြ ရွင္းေလာက္ပါျပီ၊ (ရွင္းပါျပီ ဘုရား) ။<br/>               အင္း....ဟင္း...ဒကာၾကြယ္ တစ္ေယာက္ကိုပဲ ေနာက္ဆုတ္ေတြးလိုက္လို႔ရွိရင္ ျဖင့္ ဘုရားျဖစ္တဲ့ေန႔က ေတြး၊ ပရိနိဗၺာန္သာစံစရာရွိတယ္၊ သူမ်ားေျပာေဟာခ်ိန္လဲမေပးနိုင္ေတာ့ဘူး ၊ ဒါေတာင္ မဆံုးဘူး၊ (မွန္လွပါဘုရား)။<br/>                 သတၱဝါအစ ဘယ္ေလာက္ရွည္ခဲ့တယ္ဆိုတာျဖင့္ ဒကာ ဒကာမေတြ ေျပးကိုေျပးလို႔ မဆံုးဘူဆိုတဲ့ အ ေသေတြထပ္ အေနေတြထပ္ ဆိုတာ ေျပာဖို႔လိုေသးလား၊(မလိုပါဘုရား) အဲ့ဒါေၾကာင့္ ဒကာ ဒကာမတို႔ သံသရာ ရွည္ခဲ့တယ္ဆိုတာ သေဘာက်ပလား ၊ (က်ပါျပီ ဘုရား)။<br/>               ေဩာ္....ေနာက္ထပ္လဲ ဒကာ,ဒကာမေတြ သံသရာရွည္ေၾကာင္း ကိုႀကိဳးစား ေနၾကဦးမယ္၊ ထြက္လမ္း ကို မရွာေတာ့ပါ ဘူးဆိုရင္ျဖင့္ ဒီေျမေပၚ ကိုယ့္ အရိုးအသားေတြက ျဖစ္တဲ့ေျမေပၚမွာ ကိုယ့္သစ္ပင္စားေသာက္တဲ့ သစ္ပင္ေတြစိုက္ျပီး သကာလ ကိုယ့္အသား အရိုးျဖစ္တဲ့ ေျမေပၚမွာ ကိုယ္စားေကာင္းတဲ့ သစ္ပင္ေတြစိုက္ျပီး ဦးသန္းေမာင္ စားရံုပဲရွိတယ္၊ (မွန္လွပါ ဘုရား)။<br/>                အဲဒါမွ ေျမပိုင္ျဖစ္တယ္၊ (မွန္လွပါ ဘုရား) ကိုယ့္အသား အရိုးကျဖစ္တဲ့ ေျမ၊ (မွန္ပါ့ဘုရား) ဒါေလာက္ ရွည္ခဲ့ပါတယ္ ဒကာ ဒကာမတို႔ ၊(မွန္ပါ့ ဘုရား) ဒီေျမေတြဟာ ဘယ္သူကျဖစ္တဲ့ေျမလို႔ဆိုၾကမလဲ ၊ (ကိုယ့္အသား အရိုးကျဖစ္တဲ့ေျမပါ ဘုရား)။<br/>                ဒီေျမေပၚမွာ ေပါက္တာေတြ ဘယ္သူစားေနရသတံုးဆိုေတာ့ ဒီအသားအရိုး ကိုနဂိုကစြန္႔ပစ္ထားခဲ့တဲ့  ကိုယ့္ေျမပိုင္လုပ္ျပီးသကာလ စားေနၾကတယ္ ဆိုရင္ေကာ လြဲပါ့မလား ၊ (မလြဲပါ ဘုရား)။ <br/>               ေဩာ္-ဒို႔မွာျဖင့္ ေၾကာက္စရာ ႀကီးပါကလား ၊ ကိုယ့္အသား အရိုး ေျမလုပ္ျပီး ဒီအေပၚမွာ အပင္စိုက္စားျပီး ေတာ့မွ စားတဲ့ ပုဂၢိဳလ္ က ဒီအေပၚမွာ ေျမၾသဇာ ျဖစ္ေအာင္ျပန္ျမွဳပ္ ၊(မွန္လွပါ ဘုရား) တစ္ခါ ဒီအေပၚမွာပဲ ျပန္ျဖစ္ ဆိုေတာ့ ဦးသန္းေမာင္-ဒီေျမဟာ ေျမေကာင္းလား -ေျမမေကာင္းလား၊(ေျမမေကာင္းပါ ဘုရား)။<br/>               ဘယ္လို ကမၼဝါ ဖတ္ဖတ္ မေကာင္းဘူးဗ် ၊ (မွန္လွပါ ) ခင္ဗ်ားတို႔က အိမ္ကေလးေဆာက္မယ္ၾကံ ၊ ကမၼဝါေလး ကူပါဦး ၊ ဘာေလး ညာေလး အႏၱရာယ္ ကင္းေအာင္၊ ေဘးရွင္းေအာင္လို႔ ေျပာၾကတယ္၊ (မွန္ပါ့ ဘုရား) ဒီအသားအရိုး က ျဖစ္တဲ့ေျမေတြကို ဘယ္ေတာ့မွ မဂၤလာ ရွိတဲ့ေျမလို႔ဆိုရမလဲ၊ (မရပါ ဘုရား) သေဘာက်ပလား၊ (က်ပါျပီ)။ <br/>              ဒါျဖင့္ ေျမႀကီး,ႀကီးပြားေရးကို ျဖင့္ေနာက္ထပ္မလုပ္ပါနဲ႔ေတာ့၊ (မွန္လွပါဘုရား) ဘယ္လိုအမိန္႔ေပးပါလိမ့္၊ ေျမႀကီးႀကီးပြားေရးကိုျဖင့္ ေနာက္ထပ္ မလုပ္ပါနဲ႔ေတာ့ ဦးသန္းေမာင္ လူျဖစ္ရပါလို၏၊ လူ႔ျပည္ အႀကိမ္ႀကိမ္ ခံစားရ ပါလို၏ ဆိုတာနဲ႔ ေျမႀကီး ႀကီးပြားေရး ျဖစ္ပါလို ၏၊(မွန္လွပါ ဘုရား) သေဘာက်ပလား၊(က်ပါျပီ)။<br/>              လူ႕ျပည္အႀကိမ္ႀကိမ္ျဖစ္ရပါလို၏ ဆိုရင္(ေျမႀကီး ျဖစ္ရပါလို၏) နတ္ျပည္ အႀကိမ္ႀကိမ္ ခံစားရပါလို၏ ဆိုရင္ျဖင့္ ခဏခဏေသရပါလို၏ ၊(မွန္ပါ့) နတ္က်ေတာ့ အထည္မက်န္ ဘဲကိုး၊(မွန္လွပါ)။<br/>              နတ္ျပည္ အႀကိမ္ႀကိမ္ ျဖစ္ရပါလို၏ လို႔ဆုေတာင္း တဲ့ပုဂၢိဳလ္က်ေတာ့နတ္ျပည္မွာ အဖန္ဖန္ ေသျခင္းဆိုးနဲ႔ ေသရပါလို၏ ၊ (မွန္ပါ့ဘုရား) ရွင္းျပီးလား၊ (ရွင္းပါျပီ)။<br/>              ျဗဟၼာ့ျပည္ ျဖစ္ရပါလို၏ ဆုေတာင္းေတာ့လဲ ျဗဟၼာ့ျပည္ မွာေသျခင္းအမ်ိဳးမ်ိဳး နဲ႔ပံုေျပာင္းျပီး မသာႀကီးခ် အျဖစ္နဲ႔ ေသရပါလို၏၊ (မွန္လွပါ ) ဒီလိုဆုေတာင္း တာနဲ႔ေကာ ထူးေသးရဲ႔လား၊ (မထူးပါ ဘုရား) ။<br/>             အဲဒါေၾကာင့္ ဘုန္းႀကီးတို႔ ဒကာ ဒကာမေတြ လူ႔ ျပည္ဆုေတာင္းလည္း ေျမႀကီး ,ႀကီးပြားေရးပဲ၊(မွန္ပါ့ ဘုရား) နတ္ျပည္ဆုေတာင္းေတာ့ အေသထပ္ဖို့ ပဲ ၊ (မွန္ပါ့) ျဗဟၼာ႔ျပည္ ဆုေတာင္းေတာ့ မသာႀကီးခ် ဖို႔ပဲ ၊ (မွန္ပါ့) အထည္ႀကီးေသ ၊ (မွန္ပါ့ ) သေဘာပါပလား၊ (ပါ,ပါတယ္ ဘုရား)။ <br/>              ဒါျဖင့္ ေျမႀကီး, ႀကီးပြားေရး ႀကိဳက္သလား၊ အဖန္ဖန္ ေသတာႀကိဳက္သလား ၊ မသာႀကီးခ် ႀကိဳက္သလား လို႔ေမးရင္ ဘယ္ႏွယ့္ေျဖမလဲ၊ (ဘာမွ မႀကိဳက္ပါ ဘုရား)။ <br/>               အင္း-ေတာ္လာျပီ ၊ ေတာ္လာျပီ ၊ ဘယ္ဟာမွ မႀကိဳက္ေတာ့ပါဘူးဆိုတဲ့ ဥစၥာကေလးဟာလဲ ဦးသန္းေမာင္ တစ္သံတည္းထြက္လာတာ ဘုန္းႀကီးတို႔ ေက်နပ္ျပီ ၊ (မွန္လွပါ ဘုရား) အေသသည္ " မရဏမိၸ ဒုကၡသစၥံ " လို႔ ဒကာ ဒကာမ ေတြသိတယ္ ၊(မွန္ပါ့ ဘုရား) ေသတာဘာတဲ့တံုး ၊ (မရဏမိၸ ဒုကၡ သစၥံပါဘုရား)။<br/>             ေဩာ္.... ဒါျဖင့္ တပည့္ေတာ္တို႔ ေနာက္ထပ္ ဒုကၡ မေရာက္ခ်င္ေတာ့ဘူးဘုရား ၊ ဒုကၡကိုအခု ဒီဘဝနဲ႔ပဲ သိမ္းခ်င္တယ္ဆိုတာ တရားတစ္ပြဲလံုး သေဘာတူသလား၊ (တူပါတယ္ ဘုရား) ကဲသေဘာတူလို႔ ရွိရင္ ဒကာ ဒကာမတို႔ က်ဳပ္တို႔ ဒိ႒ိနဲ႔ဝိစိကိစ ာၦ အရင္သတ္ၾကေပတာ့ ၊(မွန္ပါ့ ဘုရား)  ဒိ႒ိနဲ႔ဝိစိကိစ ာၦ အရင္သတ္ၾက ပါစို႔၊ (မွန္ပါ့ဘုရား) ။<br/>             ကိုင္း- ဒါျဖင့္ ဒကာ ဒကာမတို႔ ဒီပံုစံႀကီး ၁-နံပါတ္ကိုၾကည့္ရမယ္ေနာ္၊ (မွန္ပါ့ ) ၁-နံပါတ္ၾကည့္တဲ့ အခါ က်ေတာ့ ေဟာဒီ အတိတ္အေၾကာင္း ျခင္းရာငါးပါး ဆိုတာ အတိတ္က ျဖစ္ခဲ့တယ္ ၊(မွန္ပါ့ ဘုရား)။ <br/>          အတိတ္အေၾကာင္းျခင္းရာ ငါးပါးဆိုတာ ဘယ္တုန္းက ျဖစ္တာတံုး ၊ (အတိတ္တုန္းက ျဖစ္ပါတယ္ ဘုရား)  လြန္ခဲ့တဲ့ဘဝမ်ားစြာက ျဖစ္ခဲ့တယ္လို႔ မွတ္လိုက္စမ္းပါ၊ (မွန္လွပါ ဘုရား) ၁-နံပါတ္မွာ ဖတ္လိုက္ေတာ့ ဘာေတြ႔ သတံုး၊ (အတိတ္အေၾကာင္းျခင္းရာ ငါးပါးပါဘုရား)။ <br/>         အင္း....အတိတ္ အေၾကာင္း ျခင္းရာငါးပါး လို႔ ဒကာ ဒကာမေတြက ေတြ႔ပါတယ္၊ (မွန္ပါ့ဘုရား) အင္း... ဒါဘယ္တုန္းကျဖစ္ခဲ့တာလဲလို႔ ေမးဖို႔လိုေသးလား (မလိုပါဘုရား) မလိုေတာ့ဘူး ဦးလွဘူး ၊ အတိတ္ကျဖစ္ခဲ့တာ၊ (မွန္လွပါ)ရွင္းပလား၊ (ရွင္းပါျပီ)။<br/>          ဒါျဖင့္  အတိတ္ကျဖစ္ခဲ့တယ္ဆိုတဲ့ ၁- နံပါတ္ ဒကာဒကာမေတြျမင္ရပါျပီ၊ (ျမင္ရပါျပီ ဘုရား) ဘယ္သူက အတိတ္တုန္းက ပုဂၢိဳလ္ သတၱဝါကတည္ေထာင္တာလား ေမးရလိမ့္မယ္ေနာ္ ၊ (မွန္ပါ့) ခႏၶာကိုယ္ကို ဓမၼကတည္ ေထာင္တာလားလို႔ ေမးရလိမ့္မယ္ ၊(မွန္လွပါ )။<br/>         အဲ့ဒီေတာ့ ဒကာဒကာမေတြ အေျဖထြက္ပါ ၊ က်ဳပ္ ခႏၶာ ႀကီးကို ပုဂၢိဳလ္ သတၱဝါက တည္ေထာင္တာ မဟုတ္၊ (မွန္လွပါ ဘုရား) ဓမၼကတည္ေထာင္တာ ၊ (မွန္လွပါ ဘုရား) ရွင္းပလား၊ (ရွင္းပါျပီ ဘုရား)။ <br/>          အခုတရားနာေနတဲ့ ဒကာ ဒကာမ ေတြဆိုတဲ့ ခႏၶာ ငါးပါး (မွန္လွပါ ) ဘယ္သူတည္ေထာင္တာပါလိမ့္မတံုး ၊ (ဓမၼက တည္ေထာင္တာပါ ဘုရား) ။ <br/>          အဲ ဓမၼကတည္ေထာင္ တာလို႔ဆိုေတာ့ ဘယ္တံုးကတံုး ေမးေတာ့ မွ အတိတ္က၊ (မွန္ပါ့) ဒီမွာ အတိတ္ အေၾကာင္းငါးပါး ၊ ခင္ဗ်ားတို႔ ကိုျဖစ္ေစတဲ့ အေၾကာင္းငါးပါး ၊ (မွန္လွပါဘုရား) ရွင္းၾကပလား ၊ (ရွင္းပါျပီ ဘုရား)။ <br/>           အတိတ္အေၾကာင္း ငါးပါးဆိုတာ ဒကာဒကာမေတြ ျဖစ္ေစတဲ့အေၾကာင္း ငါးပါး ၊ (မွန္လွပါ ဘုရား) အတိတ္ အေၾကာင္းငါးပါးဆိုတာဘာပါလိမ့္ ၊ (တပည့္ေတာ္ တို႕ကိုျဖစ္ေစတဲ့အေၾကာင္းငါးပါး ပါဘုရား) အဲ့ဒီ အေၾကာင္း ငါးပါးက ခႏၶာကို ျဖစ္ေစတယ္လို႔မွတ္ပါ ၊ (မွန္လွပါ ဘုရား) သိၾကား ျဗဟၼာ-ဘုရား ကလာျပီး ဖန္ဆင္းတယ္လို႔ မယူလိုက္ပါနဲ႔ ၊ (မွန္လွပါ ဘုရား) ဒကာၾကြယ္ -သေဘာပါပလား၊ (ပါ,ပါျပီဘုရား)။ <br/>            အဲ့ဒါ ဘယ္သူတုံးလို႕ ေမးတဲ့အခါက်ေတာ့မွ ဒကာ ဒကာမေတြဒီမွာ ၾကည့္ပါ ၊ အဝိဇၨာ ,သခါၤရ , တဏွာ, ဥပါဒါန္ ဘဝ၊ (မွန္ပါ့ဘုရား)  ဒါ သတၱဝါ တည္ေထာင္တဲ့ တရား ငါးခုပဲ၊ (မွန္ပါ့ဘုရား)  ဘယ္သူပါလိမ့္ဗ်ာ ၊ (အဝိဇၨာ, သခါၤရ, တဏွာ ,ဥပါဒါန္ , ဘဝပါ ဘုရား)။ <br/>            အို-ဒီေန႔ တရားသည္ ဒကာ ဒကာမ တို႔ အလြန္အဖိုးတန္ျပီ၊ (မွန္ပါ့ ဘုရား) ဘာျဖစ္လို႔တံုး ဆိုေတာ့ ဆရာေျပာသံၾကား မဟုတ္ဘူး ၊ မ်က္ျမင္ေရာ ေျပာသံေရာ တစ္ခါတည္း ႏွစ္ခုစလံုး အိမ္ေရာက္ပါေတာ့မယ္၊ ငါတို႔၏ ဆုေတာင္းကိုလဲ ငါတို႔ သိျပီဆိုတဲ့ ဥစၥာလဲ ဒကာဒကာမေတြ ထင္ထင္ရွားရွား ပဲ ဥာဏ္ထဲေပၚလာပါတယ္ ၊ (ေပၚလာ ပါတယ္ ဘုရား) ။ <br/>            ဒကာ ဒကာမေတြ  အတိတ္ကဘာေတြမ်ား ဒကာဒကာမေတြ လုပ္ခဲ့ပါလိမ့္မတံုး ေမးတဲ့အခါက်ေတာ့ အတိတ္က အဝိဇၹာ,သခါၤရ,တဏွာ,ဥပါဒါန္,ဘဝ ေတြလုပ္ခဲ့တယ္၊ (မွန္ပါ့ဘုရား)  အတိတ္က ဘာေတြလုပ္ခဲ့သလဲ ၊ (အဝိဇၨာ,သခါၤရ,တဏွာ,ဥပါဒါန္,ဘဝ ေတြလုပ္ခဲ့ပါတယ္ ဘုရား)။<br/>            ေဩာ္-ဟုတ္ျပီတဲ့ ၊ ဒကာ ဒကာမ တို႔ အတိတ္ကဒီငါးမ်ိဳးတည္ေထာင္ ခဲ့ေတာ့ ဦးသန္းေမာင္ ေရ ဒီငါးမ်ိဳး၏ သေဘာကိုတည္ေထာင္ တတ္တဲ့တရားသေဘာ ငါးမ်ိဳး ကိုဒကာၾကြယ္ ရွင္းျပဦးမယ္ ၊(မွန္လွပါ ဘုရား)။ <br/>             အားလံုးဒကာ ဒကာမေတြ အတိတ္က တည္ေထာင္တတ္တဲ့ တရား ဘယ္ႏွစ္ပါးပါလိမ့္၊ (ငါးပါး ပါဘုရား) ဒါ ျဖင့္ ဘယ္သူပါလိမ့္ ဗ်ာ ၊ (အဝိဇၨာ ,သခါၤရ,တဏွာ,ဥပါဒါန္,ဘဝ ပါဘုရား) ။     <br/>            အို-ေနရာက်လိုက္တာ၊ ဒကာ ဒကာမ ေတြအဝိဇၨာ သခါၤရ တဏွာ ဥပါဒါန္ ဘဝဆိုတာ ေပၚလာတယ္၊ (ေပၚလာပါတယ္ ဘုရား) ေပၚလာတဲ့ အခါက်ေတာ့ ေဩာ္-ဒါေတြဟာ ဒကာ ဒကာမေတြက ဒီေန႔ခပ္နားလည္လည္ နဲ႔ခပ္ၾကမ္းၾကမ္း ေျပာတဲ့ ေန႔လို႔ မွတ္ပါေနာ္၊ (မွန္လွပါ ဘုရား) တေန႔ထက္တေန႔ေတာ့ စိပ္လာလိမ့္မယ္၊ (မွန္ပါ့)။<br/>             အဲ့ဒီလြန္ခဲ့တဲ့ အတိတ္ဘဝက အဝိဇၹာ ဆိုတာကလဲ ဒကာ ဒကာမေတြ သစၥာေလးပါးမသိဘူး၊ (မွန္ပါ့) အဝိဇၹာ ဆိုတာ ဘာတံုး ၊ (သစၥာေလးပါး မသိတာပါ) ေဩာ္-အတိတ္ဘဝက က်ဳပ္တို႔ ေခါင္းေဆာင္ေနတာ အဝိဇၨာ ေခါင္းေဆာင္ေနတာ ၊ (မွန္လွပါ ဘုရား) အင္း-ဟင္း သူကလဲ ဘာမသိတာတံုး ၊ (သစၥာေလးပါး မသိတာပါဘုရား) ။<br/>            ေဩာ္-ဒါျဖင့္က်ဳပ္တို႔ အလြန္ယုတ္မာတဲ့ ေခါင္းေဆာင္ႀကီးဟာ က်ဳပ္ တို႔သႏၱာန္မွာ ကိန္းခဲ့တယ္ ၊ (မွန္လွပါ ဘုရား) ေအာင္းခဲ့ အေၾကာင္း၊ သစၥာက (မွန္တာပါ) ဦးသန္းေမာင္ သမုဒယက၊ (အေၾကာင္းပါ) သစၥာက (မွန္တာပါ) ။<br/>               ေကာင္းျပီ-တဲ့၊အေၾကာင္းမွန္ႀကီးကို မင္းတို႔လုပ္ထားတဲ့အတြက္-တဲ့ ၊ မင္းတို႔သည္ကား လို႔ဆိုရင္ သမုဒယသစၥာ အေၾကာင္းကိုျဖင့္ မင္း တို႔လုပ္ထားျပီး၊(မွန္ပါ့)ဒါေၾကာင့္ ဘယ္တုန္းက လုပ္တာတံုး မသိမွာ စိုးလို႔ လြန္ေလျပီးေသာ အတိတ္ကာလက၊ (မွန္လွပါ) ေပၚၾကပလား (ေပၚပါျပီ) ဘယ္တုန္းက သမုဒယသစၥာ လုပ္ပါလိမ့္၊ (လြန္ေလျပီးေသာ အတိတ္ကာလကပါ ဘုရား)။<br/>              ဒါ့ေၾကာင့္ဒကာ ဒကာမတို႔ ဒီၾကားနဲ႔ ဒီၾကား ကိုအတိတ္အေၾကာင္းတစ္လႊာဆိုတာ ေပၚလာတယ္၊ မေပၚေသးဘူးလား၊ (ေပၚပါတယ္ ဘုရား) အတိတ္အေၾကာင္း ဘာတဲ့ ၊ (တစ္လႊာပါဘုရား)။<br/>              ေဩာ္-ဒါျဖင့္ ဒကာ ဒကာမတို႔ ဒီအခန္းမွာ ရွိသည့္ အတိတ္အေၾကာင္းျခင္းရာ ငါးပါးဆိုတာ အဝိဇၹာ , သခါၤရ, တဏွာ ,ဥပါဒါန္ ,ကမၼဘဝ၊ (မွန္ပါ့) ဘယ္ကာလတုန္းလို႔ေမးေတာ့ လြန္ေလျပီးေသာ အတိတ္ကာလက၊ (မွန္ပါ့)။ <br/>              ဒါေၾကာင့္ အတိတ္အေၾကာင္းတစ္လႊာဆိုေတာ့ ဒါကတစ္လႊာ၊ဒါကတစ္လႊာ၊ဒါကတစ္လႊာ၊ဒါကတစ္လႊာ၊<br/> မို႔ ဒါပထမအလႊာျဖစ္သြားတယ္ ၊ (မွန္ပါ့) ရွင္းပလား(ရွင္းပါျပီ) ဟာ-ဦးသန္းေမာင္ႀကီး ဒီအတိတ္အေၾကာင္း တစ္လႊာ လို႔ဆိုတာ (သေဘာက်ပါျပီဘုရား) ဘာသစၥာပါလိမ့္၊ (သမုဒယသစၥာပါ)။<br/>             ေဩာ္-ခင္ဗ်ား တို႔လွဴတာတန္းတာ ေပးတာကမ္းတာ သည္ကားလို႔ဆိုရင္ ျဖင့္နိဗၺာန္ကိုမသိ ၊ နိဗၺာန္ ေရာက္ေၾကာင္း ကုသိုလ္ႀကီး မလုပ္တတ္တဲ့ အတြက္ သမုဒယသစၥာ သြားျဖစ္တယ္၊ (မွန္လွပါ) ဘာျဖစ္သြားသလဲ ၊ (သမုဒယသစၥာ သြားျဖစ္ပါတယ္ဘုရား) နာလိုက္တာဗ်ာ ၊ (မွန္ပါ့ဘုရား) ဘာသစၥာသြားျဖစ္သလဲ၊ (သမုဒယ သစၥာ သြားျဖစ္ပါတယ္) အားလံုးဒကာ ဒကာမေတြျမင္ၾကရဲ႕လား၊ (ျမင္ပါတယ္ ဘုရား)။ <br/>             ခင္ဗ်ားတို႔ ေနာက္ဘဝက သစၥာေလးပါမသိတဲ့ အဝိဇၨာေၾကာင့္ ကုသိုလ္ကိုျပဳလာတယ္၊ လူ႕ျပည္ကို တဏွာနဲ႔ ဆုေတာင္းတယ္၊ ဥပါဒါန္နဲ႔ စြဲလမ္းတယ္၊ ကာယကံ ဝစီကံနဲ႔ အားထုတ္တယ္၊ (မွန္လွပါ) အဲဒီ ငါးခုဟာ ဘာသစၥာတံုး၊ (သမုဒယ သစၥာပါ ဘုရား)။ <br/>              ဦးသန္းေမာင္ေရ-ဒီမွာမျပရင္ ဒီလိုမွဒကာ ဒကာမ ေတြမသိၾကလို႔ ရွိရင္ ဒီသမုဒယ သစၥာႀကီးကိုပင္လွ်င္ က်ဳပ္ကုသိုလ္ႀကီးပဲ ၊ က်ဳပ္ေတာ့ျဖင့္ နိဗၺာန္နဲ႔နီးေပါ့လို႔ဆိုခ်င္လဲ ဆိုၾကမယ္၊ (မွန္ပါ့ဘုရား)။<br/>              သို႔ေသာ္ နိဗၺာန္နီးသလား ၊ ဘာသစၥာ ျဖစ္ေနသလဲ၊ (သမုဒယသစၥာ ျဖစ္ေနပါတယ္ဘုရား) နိဗၺာန္နီးရင္ မဂၢသစၥာ ျဖစ္ရမယ္ဗ် (မွန္လွပါ) အခုေတာ့ ဘာသစၥာျဖစ္ေနသလဲ (သမုဒယသစၥာ ျဖစ္ေနပါတယ္)ကဲဦးသန္းေမာင္ ႀကီးရွင္းသြားျပီ၊ (ရွင္းပါျပီ ဘုရား) ရွင္းျပီေနာ္၊ (မွန္ပါ့)။ <br/>               ေအး ေနာက္က ဒကာ ဒကာမေတြ မေသလို႔ ၾကားၾကရတယ္ေနာ္၊ (မွန္ပါ့) မေသလို႔ၾကားၾက ရတယ္၊ အင္မတန္ဘုန္းကံပါရမီရွိလို႔သာလွ်င္ ဒီအေၾကာင္းသိရတယ္၊ နို႔မဟုတ္လို႔ရွိရင္ ခင္ဗ်ားတို႔ အခုေျပာတဲ့အတိုင္း  ေဩာ္- ဒီဘဝ ခ်မ္းသာတာကလဲ မျဖစ္ေလာက္ေသးဘူး၊ ေနာက္ဘဝ ခ်မ္းသာမႈကို အလိုရွိေသးတယ္ဆိုတဲ့ သေဘာေတြက ဒကာ ဒကာမတို႔ မလာေသးဘူးလား၊ (လာပါတယ္ ဘုရား)။<br/>              လာလို႔ရွိရင္ျဖင့္ ဒီဘဝခ်မ္းသာတာ နည္းနည္းရွိတယ္၊ ေနာက္ဘဝခ်မ္းသာတာ ဒီထက္အေရးႀကီးဖို႔လို မယ္ဆိုတာ မသိလို႔ျပဳတာ၊ (မွန္ပါ့ ဘုရား) မသိလို႔ျပဳျပီးေတာ့ေတာင္းတဲ့ တဏွာ၊ (မွန္ပါ့) မရအရ စြဲလမ္းတဲ့ ဥပါဒါန္ (မွန္ပါ့) မရမေနနိုင္ဘူး ဆိုတဲ့ အားထုတ္တဲ႔ ကံ၊ (မွန္ပါ့) သေဘာက်ပလား၊ (က်ပါျပီ)။<br/>             ဒါျဖင့္ဘုန္းႀကီးတို႔ ဒကာဒကာမေတြမွာ ဘာသစၥာေတြႀကိဳးစားခဲ့သလဲ၊(သမုဒယသစၥာေတြ ႀကိဳးစားပါတယ္) ေဩာ္ သမုဒယသစၥာေတြ ႀကိဳးစားခဲ့တယ္ေနာ္၊ (မွန္ပါ့) ဘယ္တုန္းကႀကိဳးစားတာလဲ၊ (အတိတ္ဘဝ တုန္းက ႀကိဳးစားတာပါ)။<br/>            ဒီၾကည့္ လြန္ေလျပီးေသာ အတိတ္ကာလက၊ (မွန္ပါ့) ေပၚၾကပလား၊ (ေပၚပါျပီ) ဘယ္ကာလပါလိမ့္ ၊ (လြန္ ေလျပီးေသာ အတိတ္ကာလကပါ ဘုရား) ဒါေၾကာင့္ ဒီဥစၥာ အတိတ္အေၾကာင္းတစ္လႊာ၊(မွန္ပါ့) ဘာသစၥာတဲ့လဲ၊ (သမုဒယသစၥာ ပါ ဘုရား)။<br/>             ကဲ....ဒါျဖင့္ခင္ဗ်ားတို႔ သည္ကားလို႔ဆိုလို႔ရွိရင္ ျဖင့္မသိလို႔လွဴတဲ့အလွဴဟာမသိတာက အဝိဇၨာ၊လွဴတာက သခါၤရ ၊(မွန္ပါ့) ေတာင္းတာက၊(တဏွာပါ ဘုရား) စြဲလမ္းတာက၊(ဥပါဒါန္ပါ ဘုရား) အားထုတ္တဲ႔ ကာယကံ, ဝစီကံ၊ (ကမၼာဘဝပါဘုရား) ေပၚၾကပလား၊ (ေပၚပါျပီဘုရား) ဘာသစၥာေတြ ေရွးကလုပ္ခဲ့သလဲ၊(သမုဒယသစၥာေတြ ေရွးက လုပ္ခဲ့ပါတယ္ဘုရား)။            ေဩာ္.... ဒါျဖင့္ဒကာ ဒကာမတို႔ဒီသမုဒယသစၥာေတြသာ ခင္ဗ်ားတို႔ ဆရာကလဲ ဖြင့္မေပး၊ ဘုရားကလဲ မေဟာ ၊ကိုယ့္အေရးအရာနဲ႔ ကိုယ့္ဘာသာ ေနၾကမယ္ဆိုရင္ ျဖင့္ခင္ဗ်ားတို႔ သမုဒယသစၥာ ပဲ ထပ္လုပ္မယ္၊ (မွန္ပါ့) မလုပ္ေပဘူးလား၊ (လုပ္ပါတယ္ ဘုရား)ဒါျဖင့္ေၾကာက္စရာ ေကာင္းလိုက္တာ ၊ (ေကာင္းပါတယ္ ဘုရား) ဒကာ- ဒကာမတို႔ သမုဒယသစၥာ ဆိုတာအေၾကာင္း၊ ဒုကၡ သစၥာ ဆိုတာက ၊ (အက်ိဳးပါဘုရား)။<br/>             ဒါျဖင့္ ခင္ဗ်ားတို႔ဘာအက်ိဳးမ်ားၾကပါလိမ့္ ၊ (ဒုကၡသစၥာ အက်ိဳးမ်ားပါတယ္ ဘုရား) ဟင္း.....ဦးသန္းေမာင္ သြားျပီ (မွန္ပါ့) သြားျပီ -သြားျပီ ။<br/>             ဒကာ-ဒကာမေတြ သမုဒယသစၥာ ဆိုတာ ဘာတဲ့၊ (အေၾကာင္းပါဘုရား) ဒီအေၾကာင္းက ဘယ္အက်ိဴး ေပးတတ္ပါလိမ့္၊ (ဒုကၡသစၥာ အက်ိဳးေပးပါတယ္ ဘုရား) ဒုကၡသစၥာ အက်ိဳးေပးတတ္ တယ္ဆိုတာ ေသခ်ာပလား (ေသခ်ာပါျပီ)။ </p>
