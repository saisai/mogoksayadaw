(၁၀-၃-၆၁)

#သႏၲာပေ႒ာ အပိုင္း(၄)

ဒုကၡသစၥာ၏ အနက္ (၃)သႏၲာပေ႒ာ
တရားနာရင္း ကြၽတ္တမ္းဝင္နည္း
ေဟာၾကားသည့္ေန႔ (၉-၁၂-၅၇)

ေက်းဇူးေတာ္ရွင္အဂၢမဟာပ႑ိတ
မိုးကုတ္ဆရာေတာ္ဘုရားႀကီး မႏၲေလးၿမိဳ႕၌ ေဟာၾကားေတာ္မူေသာ တရားေတာ္

ထင္းက (၅)ပါး

အံမေလး ဒါျဖင့္ ထင္းနဲ႔ေလာင္စာ၊ ထင္းနဲ႔မီး၊ ဘယ္သူမ်ားသလဲ ဆိုေတာ့ ထင္းတုံးက ငါးပါးပဲရွိပါတယ္၊ ငါးတုံးပဲရွိတယ္ ... (မွန္ပါ)။ ေလာင္စာမီးက တစ္ေထာင့္ငါးရာ ... (မွန္ပါ)။

ေလာင္စာမီးက (၁၅၀၀)

ေလာင္စာမီးက တစ္ေထာင့္ငါးရာ ... (မွန္ပါ)၊ မီးနဲ႔ထင္းနဲ႔ မွ်ရဲ႕ လား ... (မမွ်ပါဘူးဘုရား)။
ဒါေၾကာင့္ ခင္ဗ်ားတို႔ ကိုယ္ဟာ ဖ်တ္ခနဲ၊ ဖ်တ္ခနဲ တစ္ခါတည္း ေလာင္တာ ရိပ္မိၿပီလား ... (ရိပ္မိပါတယ္ဘုရား)။
ေတေဇာမီးက ေလာင္လိုက္၊ ကိေလသာမီးကေကာ ... (ေလာင္ လိုက္ပါဘုရား)၊ ကိေလသာမီးက ဘာေလာင္သလဲဆိုေတာ့ နာမ္လည္း ေလာင္လိုက္၊ ႐ုပ္ေကာ ... (ေလာင္ပါတယ္ဘုရား)။
နာမ္လည္းေလာင္၊ ႐ုပ္လည္းေလာင္၊ သေဘာက်ရဲ႕လား ... (မွန္ပါ)၊ ဒီထဲ ဇရာမီးက ေလာင္လိုက္၊ မိဘ႐ိုးရာကပါလာတဲ့ ခႏၶာေတေဇာ မီးကေကာ ... (ေလာင္ပါတယ္ဘုရား)၊ ဥတုဇမီးကေကာ ... (ေလာင္ပါ တယ္ဘုရား)။
အံမေလး! ဒကာ ဒကာမတို႔ ေတြ႕ထားတဲ့ ဆုကျဖင့္ ေလာင္ဆဲမတၱပဲ ရွိပါလား ... (မွန္ပါ ဘုရား)၊ အဲဒီေလာင္ဆဲမတၱကို၊ ဪ ... သႏၲာပေ႒ာ - ဆင္းရဲမီးျဖင့္ သီးသီးေတာင္ေျပာင္ အၿမဲေလာင္ကြၽမ္း ေနေသာ အနက္သေဘာသည္ လည္းေကာင္းဆိုေတာ့၊ ဒါကို မီးေလာင္ေနတယ္၊ မီးေလာင္ေနတဲ့ ခႏၶာႀကီး မီးေလာင္ခံေနရတဲ့ ခႏၶာကိုယ္ႀကီးဆိုၿပီး သကာလ သူ႔ျဖစ္ပ်က္ကို ျဖစ္ပ်က္ရႈေပး ... (မွန္ပါ)၊ သေဘာက်ရဲ႕လား ... (က်ပါတယ္ဘုရား)။

ဘာျဖစ္လို႔ျဖစ္ပ်က္ေနရတုံး

ျဖစ္လိုက္ ပ်က္လိုက္၊ ျဖစ္လိုက္ ပ်က္လိုက္ ဒီအတိုင္းခ်ည့္ေနတာပဲ ... (မွန္ပါ)။ ဒါ ဘာျဖစ္လို႔ ျဖစ္ပ်က္ေနရတုံးဆိုေတာ့ မီးေလာင္လို႔ကြ (မွန္ပါ)။
တစ္ခုေသာ ႐ုပ္ထဲပါတဲ့ ေတေဇာက သူ႔႐ုပ္သူေလာင္၊ ဟို႐ုပ္ အစားထိုး၊ ထိုးၿပီးေလာင္ျပန္ၿပီ၊ နာမ္ဓမၼေတြကလည္း တစ္ခုကခ်ဳပ္ၿပီး တစ္ခုက အစားထိုးသြား၊ တစ္ခုက ဘာျပဳလို႔ခ်ဳပ္သြားရသတုံး၊ အို... ဇာတိမီး၊ ဇရာမီးေၾကာင့္၊ တခ်ိဳ႕ ဒကာ ဒကာမေတြက်ေတာ့ ဇာတိမီး၊ ဇရာမီးေၾကာင့္၊ တခ်ိဳ႕က်ေတာ့ ေတေဇာမီးေၾကာင့္ ဇာတိ၊ ဇရာ၊ မရဏဘက္ထား လိုက္ပါေတာ့ မထူးေတာ့ပါဘူး ... (မွန္ပါ)။ ။
ဇာတိ၊ ဇရာမီးေကာ၊ ေတေဇာမီးေကာ မေလာင္ဘူးလား ... ။ (ေလာင္ပါတယ္ဘုရား)။ ဒါျဖင့္ မီးေလာင္တာ မေသခ်ာဘူးလား ... (ေသခ်ာပါတယ္ဘုရား)။
အဲဒီမီးေလာင္တာႀကီးျမင္ေတာ့ ဒါႀကီးဟာ ကံေကာင္းလို႔ျဖစ္တာလို႔ ဆိုမလား၊ ဒုကၡ ေရာက္တာ လို႔ဆိုမလား ... (ဒုကၡေရာက္တာပါဘုရား)။

ငရဲခံေနရတာနဲ႔အတူတူပဲ

မီးေလာင္လိုက္၊ ေျပာင္လိုက္၊ အစားထိုးလိုက္ ေျပာင္လိုက္ အစား ထိုးလိုက္ဆိုေတာ့ ငရဲခံေနရတာနဲ႔ အတူတူပဲ ... (မွန္ပါ)။ ငရဲခံေနရ တာသည္ ဒယ္အိုးထဲက်လိုက္ ဝိညာဥ္ခ်ဳပ္ သြားသလိုလိုရွိလိုက္၊ ဟုတ္လား။
ကံက မကုန္ေသးေတာ့ဝိညာဥ္က အစားထိုးျပန္ေတာ့ အနာခံရမွ ၿပီးမွာကိုးဗ်... (မွန္လွပါ)၊ အနာမခံဘဲနဲ႔ ငါးေပ်ာ္သလို အေသေပ်ာ္ ဆိုရင္ေတာ့ ဘယ္သူျဖစ္ျဖစ္ဗ်ာ တစ္ခါေသတာ ဘာအေရးႀကီး သတုံး၊ မဟုတ္ဘူး၊ အသက္က၊ ဝိညာဥ္က ျပန္ျပန္လာေသးတယ္၊ ရိပ္မိၿပီလား ... (ရိပ္မိပါတယ္ ဘုရား)။
ဝိညာဥ္ခ်ဳပ္ေအာင္လုပ္လိုက္ ေနာက္ဝိညာဥ္သစ္က အနႏၲရနဲ႔ အစားထိုးလိုက္၊ ဥပနိႆယက ထိုးလိုက္ ကံက ထိုးလိုက္၊ ဒီလိုမေနေပဘူးလား ... (ေနပါတယ္ဘုရား)။
အဲဒီလို ထိုးလိုက္ေတာ့ ဒီပုဂၢိဳလ္သည္ ဒီခႏၶာငါးပါးႀကီးသည္ ေလာင္စာအစစ္ဟုတ္ မဟုတ္ ... (ဟုတ္ပါတယ္ဘုရား)၊ ရွင္းၿပီလား (ရွင္းပါၿပီဘုရား)။

ေပ်ာက္လိုက္ အစားထိုးလိုက္

ဒါျဖင့္ ေလာင္စာအစစ္ျဖင့္ အေလာင္ခံေနရေသာေၾကာင့္ ဘာသစၥာ ဖြဲ႕မတုံး ...(ဒုကၡသစၥာပါ ဘုရား)၊ ဒီလိုဒုကၡသစၥာျမင္ရမယ္တဲ့၊ ေလာင္လိုက္ ေပ်ာက္ေပ်ာက္ သြားလိုက္၊ အစားထိုးလိုက္၊ ေပ်ာက္လိုက္ အစားထိုးလိုက္ ဆိုေတာ့၊ ေနာက္ဆုံးပိတ္က်ေတာ့ သစၥာေရာ အနိစၥေရာတြဲသြားတယ္။ အနိစၥဆိုတာ အျခားမွတ္မေနနဲ႔၊ ဒုကၡဆိုတာ တျခားမွတ္မေနနဲ႔ ... (မွန္လွ ပါဘုရား)။
အနတၱဆိုတာေကာ ... (တျခားမမွတ္ရပါဘုရား)၊ တျခားမွတ္ မေနနဲ႔ေတာ့ ခင္ဗ်ားတို႔ ခဏ ခဏ ေလာင္လိုက္၊ ေျပာင္လိုက္၊ အစားထိုး လိုက္မွတ္ပါ၊ ရွင္းၿပီလား ... (ရွင္းပါၿပီဘုရား)။
ေကာင္းၿပီ ဒါျဖင့္ ဒါက ခႏၶာငါးပါးရလို႔ေနာ္ ... (မွန္ပါ)၊ ခႏၶာ ငါးပါးရလို႔ ခင္ဗ်ားတို႔ ေလာင္စာနဲ႔ မီးတြဲလ်က္ႀကီးျဖစ္ ရပါလို၏လို႔ ဦးခင္ေမာင္တို႔ ေတာင္းထားတဲ့ဆုေပါ့ဗ်ာ ... (မွန္လွပါဘုရား)။ ကဲျပည့္ ၿပီလား ... (ျပည့္ပါၿပီဘုရား)။

သာမညဘုန္းႀကီးနဲ႔ေတြ႕ရင္

ဒကာ ဒကာမေတြ သာမညဘုန္းႀကီးနဲ႔ ေတြ႕ရင္ မႏုႆတၱဘာေဝါ ဒုလႅေဘာ၊ အံမာ အံမာ အရေတာ္ေနတာ၊ ေပ်ာ္ေပ်ာ္ေနလိုက္ဦးမယ္မ်ား လုပ္မေနနဲ႔၊ သစၥာက်ေတာ့ ေပ်ာ္ဖို႔ကိုမပါဘူး၊ ပါေသးရဲ႕ လား ... (မပါ ပါဘူးဘုရား)။
အဲ-ဒါျဖင့္ ကိုထြန္းဦး တရားနာကတည္းက ကိေလသာ ဘယ့္နဲ႔ေန လဲ ... (ေျခာက္ပါတယ္ ဘုရား)၊ အေသအခ်ာနာၾကည့္ေတာ့မွ ေန႔တိုင္း အေလာင္ခံေနရတာပဲ၊ က်ဳပ္ေျပးလႊားေနတာေတြဟာ ကိုယ့္စရိတ္နဲ႔ ကိုယ္ေျပးတယ္လို႔ ေအာက္ေမ့တယ္။
ဘယ္ဟုတ္မလဲ ေလာဘကတြန္းလိုက္၊ ေဒါသကတြန္းလိုက္ မခံခ်င္ လို႔သြားတဲ့ေနရာလည္း ရွိေသးတာကိုး ... (မွန္ပါ)၊ ရလိုလို႔ သြားတဲ့ေနရာ ေကာ...(ရွိပါတယ္ဘုရား)၊ ခံသာလို႔ သြားတဲ့ ေနရာေကာ (ရွိပါတယ္ဘုရား)။
ဟ! ဒီပုဂၢိဳလ္ဘာျဖစ္ေနတုံး၊ အို ကိေလသာမီးေလာင္ၿပီး မပူတဲ့ေနရာ မေနႏိုင္လို႔ ေျပးတာ ... (မွန္ပါ)၊ ရွင္းၿပီလား ... (ရွင္းပါၿပီဘုရား)။
စိုးရိမ္လို႔ေျပးေတာ့ ေသာကမီးေလာင္တာပဲ ... (မွန္ပါ)၊ ဟုတ္လား၊ ဇရာဘက္ေျပးလည္း ပရိေဒဝမီးေလာင္တာပဲ ... (မွန္ပါ)။ ဒကာ ဒကာမတို႔ ခင္ဗ်ားတို႔ ေျပးရလႊားရတာသည္ ႐ိုး႐ိုးေျပးလား၊ ပ်ာယာ ခတ္ၿပီး မီးဟပ္လို႔ ေျပးတာလား ... (ဗ်ာယာခတ္မီးဟပ္လို႔ ေျပးတာပါ ဘုရား)၊ ရွင္းၾကၿပီလား ... (ရွင္းပါၿပီဘုရား)။

ျဖည္းျဖည္းဆိုရင္ လြဲလိမ့္ဦးမယ္

ေကာင္းၿပီ ဒါက လက္ရွိခႏၶာႀကီး ေလာင္တာေနာ္ ... (မွန္ပါ)၊ ခင္ဗ်ားတို႔ ရွင္းျပပါဦးမယ္၊ ဒီေလာင္တာဟာ ဒီေလာက္ကိစၥမရွိေသးပါဘူး (မွန္ပါ)၊ ခင္ဗ်ားတို႔ ဆုရွည္ႀကီးမ်ား ေတာင္းထားလို႔ နိဗၺာန္ ေျဖးေျဖးမွ ယူ မယ္လို႔ ခင္ဗ်ားတို႔ အႀကံဉာဏ္မ်ား ေပၚလို႔ရွိရင္ ေကာင္းေကာင္းႀကီး လြဲပါ လိမ့္ဦးမယ္။
ဘယ္လိုေကာင္းေကာင္းႀကီး လြဲမတုံးဆိုေတာ့ ဒီဘဝျပဳထားတဲ့ ဒါနေလး၊ သီလေလး၊ တရားနာထားတာေလးေတြ မရွိဘူးလား ... (ရွိပါ တယ္ဘုရား)၊ သဒၶါ၊ သီလ၊ သုတ၊ စာဂ၊ ပညာဆိုတဲ့ သူေတာ္ေကာင္းရတနာ ေလးေတြ ဝမ္းထဲ တစ္ခါတစ္ခါ မကိန္းဘူးလား ... (ကိန္းပါတယ္ဘုရား) ကိေလသာ မရွိတဲ့အခ်ိန္ ... (မွန္ပါ)။
အဲေတာ့ ဒီရတနာေလးေတြ၊ ဆရာကေပးထားတာေလးေတြ၊ ကိုယ္က ဆည္းပူး ထားတာ ေလးေတြ၊ ခုနက ဉာဏ္ကေလးနဲ႔ ထုတ္ထားတာ ေလးေတြ ... (မွန္ပါ)။ ဘယ္ေရာက္ကုန္တုံး ... ကိေလသာမီးေလာင္လို႔ ေျပာင္ျပန္ၿပီ ... (မွန္ပါ)။
သူေတာ္ေကာင္း ရတနာေတြ ဘယ္ေရာက္ကုန္တုံး ... (ကိေလ သာ မီးေလာင္ သြားပါတယ္ ဘုရား)။ ဘယ္ေတာ့ ပါရမီျပည့္မတုံး ... ရပ္ ရင္း ေလာင္ရင္း၊ ရပ္ရင္း ေလာင္ရင္း ... (မွန္လွပါ)။
ဆရာသမား ဘုန္းႀကီးမ်ားနဲ႔ ေတြ႕လို႔၊ သာမည ေတာ္ေသးရဲ႕၊ ဒီေလာက္ပဲတတ္ႏိုင္လို႔ ဒီေလာက္ပဲခ်ီးေျမႇာက္တယ္ဆိုဦးေတာ့၊ ခင္ဗ်ားတို႔ အိမ္က်ေတာ့ ေသာက၊ ဗ်ာပါဒစိတ္ေတြက ဝင္မလာေပဘူးလား... (ဝင္ လာပါတယ္ဘုရား)။
သူကလည္း ဟဒယဝတၳဳေပၚ ကိန္းရတာ ... (မွန္လွပါ)၊ ေသာက ဗ်ာပါဒကလည္း ဘယ္ေပၚကိန္းသတုံး ... (ဟဒယဝတၳဳေပၚပါဘုရား)။

သူေတာ္ေကာင္းရတနာေလးေတြ

ဒါျဖင့္ ဟိုကမီး...(မွန္ပါ) ဟုတ္လား၊ အဲဒီမီးကို ဒီကေပးလိုက္တဲ့ သူေတာ္ေကာင္း ရတနာေလး ေတြ၊ နိဗၺာန္ေရာက္ေၾကာင္းေလးေတြ၊ သစၥာတရား နာထားတာေလးေတြ၊ သစၥာတရား ျမင္ထားတာ ေလးေတြ မေပါက္ေျမာက္ေသးေတာ့ကို၊ ဒါေလးေတြက သဒၶါ၊ သီလ၊ သုတ၊ စာဂ၊ ပညာေလးေတြက ခႏၶာကိုယ္ထဲမွာ ခုလိုအခ်ိန္မွာ မရွိဘူးလား... (ရွိပါတယ္ဘုရား)။ ။
ရွိပင္ရွိျငားေသာ္လည္း သားေရး၊ သမီးေရး၊ စီးပြားေရး ရႈပ္လာတဲ့ အခါက်ေတာ့ ဒီထဲမွာ ေလာဘ၊ ေဒါသ၊ ေမာဟ လာၿပီလား၊ မလာဘူးလား ... (လာပါတယ္ဘုရား)။
လာသည္နဲ႔ တစ္ၿပိဳင္နက္တည္း သူတို႔ ဘယ့္ႏွယ္ေနေသးသတဲ့... (ေလာင္သြားပါတယ္ ဘုရား)။

ျပည့္မည္ႀကံလိုက္၊ မီးေလာင္လိုက္

အဲဒါ ဘုရားအဆူဆူတို႔ေဟာသည္တိုင္ေအာင္ နာရဖို႔ခဲယဥ္းပါ တယ္၊ ဒကာ ဒကာမတို႔ မဟုတ္ဘူးလား ... (ဟုတ္ပါတယ္ဘုရား) ထိုက္ တန္တဲ့ပါရမီေတြလည္းရွိၾကပါရဲ႕၊ ပါရမီျပည့္မည္ ႀကံရင္ ဦးခ်စ္ခ ဘာျဖစ္ ရင္းျဖစ္ေနလဲ... (ေလာင္ရင္းျဖစ္ေနတယ္ဘုရား)။
ဒါျဖင့္ သံသရာထဲမွာ ပါရမီမျပည့္လို႔ထြက္ရပ္လမ္း မဝင္ရေတာ့ပါ ဘူးဆိုရင္ျဖင့္၊ ခင္ဗ်ားတို႔ကလည္း ရရင္းမီးရႈိ႕ ရင္းဆိုေတာ့ ဘယ္ျပည့္မွာတုံး (မျပည့္ပါဘုရား)၊ ကဲ ဦးဘၾကည္ ရိပ္မိပလား ... (ရိပ္မိပါၿပီဘုရား)။
ခႏၶာကိုယ္တင္ေလာင္သလား၊ သူေတာ္ေကာင္းရတနာပါေလာင္ သလား ... (သူေတာ္ေကာင္း ရတနာပါေလာင္ပါတယ္ဘုရား)၊ ဒါျဖင့္ နာလိုက္တဲ့ျဖစ္ျခင္းဗ်ာ၊ မေျပာပါနဲ႔ေတာ့။ ။

သူေတာ္ေကာင္းရတနာပါ ေလာင္ပစ္တယ္

အင္း... သူေတာ္ေကာင္း ရတနာပါေလာင္ပစ္လိုက္တယ္ဆိုေတာ့၊ သစၥာမသိခင္တုန္းကျဖင့္ ေလာင္မွန္လည္းမသိဘူး၊ ေလာင္တာလည္း ဧကန္ပဲ၊ အရင္းေတြ အကုန္ရႈံးဗ်ာ၊ သေဘာက်ပလား ... (က်ပါၿပီဘုရား) ပါလာတဲ့ အရင္းေတြဘယ့္ႏွယ္ေနတုံး ဦးဘၾကည္ ... (ရႈံးပါတယ္ဘုရား)။
ရႈံးလိုက္တဲ့ျဖစ္ျခင္းမွ ခင္ဗ်ားတို႔ခႏၶာရႈံး၊ သူေတာ္ေကာင္းရတနာ အထုပ္အထည္ေတြေကာ ရႈံးပါတယ္ဘုရား) ရႈံးတယ္၊ ဒါဘယ့္ႏွယ္ေၾကာင့္ အရႈံးႀကီး ရႈံးရပါလိမ့္လို႔ ေမးတဲ့အခါက်လို႔ရွိရင္၊ သစၥာသိတဲ့ဉာဏ္မလာေတာ့ ဘူး။

သစၥာသိတဲ့ဉာဏ္

သစၥာသိတဲ့ဉာဏ္လာေတာ့ သစၥာသိတဲ့ဉာဏ္ ဒီအထဲမွာ ကိန္းေန တယ္၊ သစၥာရႈရင္း သစၥာသိရင္း၊ သစၥာရႈရင္းသစၥာသိရင္းဆိုေတာ့ ကိေလသာ ဝင္ခြင့္ရေသးရဲ႕လား ... (မရပါဘုရား)၊ မရေတာ့ဘယ္သူ႔ေလာင္တုံး ... (ေလာင္စရာမရွိပါဘုရား)၊ ေလာင္စရာ မရွိေတာ့ဘူး၊ ကိေလသာ ထြက္ေျပး ရေတာ့တယ္၊ သူကႏိုင္သြားတယ္၊ မဂ္ဉာဏ္ကသာႏိုင္သြားေတာ့တယ္၊ ဒကာ ဒကာမတို႔ က်န္တာက ႏိုင္ေသးရဲ႕လား ... (မႏိုင္ေတာ့ပါဘုရား)။
ဒါေၾကာင့္မဂ္ဉာဏ္သည္ ဘယ္ေလာက္ႏိုင္တယ္ဆိုတာဘုန္းႀကီးရွင္း ျပမယ္၊ ဒီဘဝမွာ ခင္ဗ်ားတို႔တစ္ေထာင့္ငါးရာကိေလသာရွိတယ္ဆိုတာ အထင္အရွားပဲ၊ ဒါ ဒုကၡသစၥာပဲကြ ဉာဏ္ကသာဆုံးျဖတ္ခ်က္ခ်ပါ၊ ျဖစ္တာ လည္း ဒုကၡပဲ၊ ပ်က္တာလည္း (ဒုကၡပါဘုရား)။
အဲ “ဒုကၡေမ၀ ဥပၸဇၨတိ ဒုကၡံ နိ႐ုဇၨမာနံ နိ႐ုဇၨတိ” ဒုကၡျဖစ္၍ ဒုကၡ ပ်က္တာမွတစ္ပါး ခင္ဗ်ားတို႔ ခႏၶာကိုယ္ထဲ ဘာမွ မရွိဘူးတဲ့ ... (မရွိပါ ဘုရား) ရိပ္မိပလား (ရိပ္မိပါၿပီဘုရား)၊ ျဖစ္ေပၚလာတာလည္း ဘာေတြတုံး (ဒုကၡသစၥာပါဘုရား) ပ်က္သြားတာလည္းဘာေတြတုံး ... (ဒုကၡေတြပါ ဘုရား)။

ျဖစ္ပ်က္မွတပါး ဘာမွမရွိ

ခင္ဗ်ားတို႔ သႏၲာန္မွာ ျဖစ္ပ်က္မွတစ္ပါး ဘာေတြရွိေသးသတုံး (ဘာမွမရွိပါဘုရား)၊ ဒါျဖင့္ အဲဒီျဖစ္တာလည္းအားလုံး (ဒုကၡပါဘုရား) ပ်က္ တာေရာ (ဒုကၡပါဘုရား) ဘယ္ဒုကၡႀကိဳက္သတုံး ... (ဘယ္ဒုကၡမွမႀကိဳက္ ပါဘုရား) ဘယ္ဒုကၡမွ မႀကိဳက္ဘူး။ ။
ႏွစ္ခုစလုံးမႀကိဳက္ဘူးဆိုၿပီး သူ႔ကိုပိုင္းျခားလိုက္၊ မင္းကိုဒုကၡမွန္းသိၿပီ၊ ျဖစ္တာလည္း တို႔မႀကိဳက္ေတာ့ဘူး၊ ပ်က္တာေရာ ... (မႀကိဳက္ေတာ့ပါ ဘုရား)၊ ဒါ သံယုတ္ပါဠိေတာ္မွာ ဒီအတိုင္းလာတယ္၊ ဒုကၡပိုင္းျခားပုံရိပ္မိ ပလား (ရိပ္မိပါၿပီ)။ ကစၥာယနအႏြယ္ကိုေဟာတာ (မွန္ပါ့ဘုရား)။
ကစၥာယနအႏြယ္ကို ဘုရားသခင္ကိုယ္ေတာ္ျမတ္ႀကီးက “ဒုကၡေမဝ ဥပၸဇၨမာနံ ဥပၸဇၨတိ၊ ဒုကံၡ နိ႐ုဇၩမာနံ နိ႐ုဇၨတိ” ဒုကၡျဖစ္၍ ဒုကၡပ်က္တာမွ တစ္ပါး မင္းတို႔ခႏၶာကိုယ္ထဲ ဘာမွမရွိဘူးတဲ့ ရွင္းပလား (ရွင္းပါၿပီဘုရား)။
ျဖစ္တာလည္း ဘာတုံး (ဒုကၡပါဘုရား) ဒုကၡသစၥာပဲ၊ ပ်က္တာေကာ (ဒုကၡပါဘုရား) ဒုကၡကို ခင္ဗ်ားတို႔ပဲ စဥ္းစားၾကည့္ပါတဲ့၊ သစ္ပင္ေလးတစ္ပင္ စိုက္ၾကည့္ပါလို႔ ဘုန္းႀကီးကေျပာတယ္၊ မ်ိဳးေစ့ေလးတစ္ေစ့စိုက္ၾကည့္ ဦးဘၾကည္ရ။
စိုက္ၾကည့္ေတာ့ အၫြန႔္ေလးကကိုင္းၿပီး ထြက္ကတည္းက ဒီအပင္ လဲမွလဲပါ့မလားလို႔ ေမးဖို႔လိုေသးသလား ... (မလိုပါဘုရား) ဘာေၾကာင့္ မလိုတုံးဆိုေတာ့၊ ပ်က္မည့္ဘက္သြားေနတာ၊ ဒီမွာလည္း ျဖစ္ကတည္းက ပ်က္မည့္ဘက္ မ်က္ေစာင္းထိုးေနတာ။

သခ်ိဳင္းမ်က္ေစာင္းထိုးေမြးလာတာ

႐ုပ္ဓမၼေလးေတြက ျဖစ္တယ္ဆို ဘယ္ကိုမ်က္ေစာင္းထိုးေနတုံး၊ (ပ်က္မည့္ဘက္ မ်က္ေစာင္းထိုး ပါတယ္ဘုရား)၊ နာမ္ဓမၼကလည္း ျဖစ္ၿပီးေတာ့ ဘယ္မ်က္ေစာင္းထိုးတုံး ... (ပ်က္မည့္ဘက္ပါဘုရား)၊ အဲ သခ်ႋဳင္း မ်က္ေစာင္းထိုးေမြးလာတာနဲ႔ အတူတူပဲ၊ ရိပ္မိပလား ... (ရိပ္မိပါၿပီဘုရား)။
အဲဒီေတာ့ ဒကာ ဒကာမေတြ ဒီခႏၶာႀကီးဟာ နာမ္ဓမၼေတြၾကည့္ လိုက္ျပန္လည္း သခ်ႋဳင္း မ်က္ေစာင္းထိုးေနတာ၊ ထြက္လာလို႔ရွိရင္ မ်က္ေစာင္း ထိုးတဲ့အတိုင္း အေရာက္သြားတာပဲ၊ မသြားဘူးလား သြားသလား (သြားပါ တယ္ဘုရား)။
ဒါေၾကာင့္ ဘုရားသခင္ကိုယ္ေတာ္ျမတ္ႀကီးက ခင္ဗ်ားတို႔သႏၲာန္ျဖစ္တဲ့ ႐ုပ္ဟာလည္း ျဖစ္တာလည္း ဒုကၡ၊ ပ်က္တာလည္း ဒုကၡ၊ နာမ္ေတြကေရာ ျဖစ္တာလည္း ဒုကၡလို႔ခင္ဗ်ားတို႔ၾကည့္ေပး၊ ၾကည့္မေပးသင့္ဘူးလား ... (ေပးသင့္ပါတယ္ဘုရား)။
ၾကည့္ေပးလိုက္ရင္ ျဖစ္ဒုကၡပ်က္ဒုကၡဆိုေတာ့၊ နတ္ကိုၾကည့္လိုက္ ျပန္လို႔ရွိရင္လည္း ဒုကၡပဲ၊ ျဗဟၼာကိုၾကည့္လိုက္ျပန္ေကာ ... (ဒုကၡပါဘုရား) သုံးဆယ့္တစ္ဘုံမွာျဖင့္ ဒုကၡခ်ည္းပဲ ... (မွန္လွပါ ဘုရား)။

ဒုကၡျမင္တဲ့ဉာဏ္လာမယ္

ေတာေတြ ေတာင္ေတြ ေရေတြၾကည့္လိုက္ျပန္ေတာ့ေကာ ... (ဒုကၡပါဘုရား)၊ ကိုယ့္ခႏၶာ ဒုကၡျဖစ္ရင္ က်န္တာေတြ ဒီအထဲ သြင္းလာတာ ပဲ၊ သေဘာပါၾကပလား ... (ပါပါတယ္ဘုရား)၊ အဲဒီေတာ့ ဒီဒုကၡျမင္တဲ့ ဉာဏ္ကေလးက လာမလား မလာဘူးလား (လာပါမယ္ဘုရား) ဒုကၡျမင္တဲ့ ဉာဏ္လာမယ္။
ဒီ ဒကာ ဒကာမေတြ ဒုကၡျမင္တဲ့ဉာဏ္သည္ သူလာတဲ့အခ်ိန္ ဘာ ျဖစ္ၾကသတုံးဆိုေတာ့၊ ဒုကၡကိုႀကိဳက္တာေတာ့ ဘယ္သူကႀကိဳက္တာတုံးလို႔ ေမးေတာ့ ဝိပလႅာသ သတၱိရွိလို႔ တဏွာက ႀကိဳက္တာ၊ ဟုတ္ပလား (မွန္လွပါ ဘုရား)။ ဘယ္သူႀကိဳက္တာတုံး ... (တဏွာကႀကိဳက္တာပါဘုရား) တဏွာက ႀကိဳက္တာတဲ့။
တဏွာကႀကိဳက္ေတာ့ ေရွ႕က တဏွာႀကိဳက္ကို အခုဆရာဘုန္းႀကီး က သစၥာအနာခိုင္းတယ္၊ ဒါဒုကၡသစၥာလို႔ပိုင္းျခားတယ္ခင္ဗ်ားတို႔ကိုေနာ္။ ခင္ဗ်ားတို႔သႏၲာန္႐ုပ္နဲ႔ နာမ္ရွိတယ္၊ ႐ုပ္ကလည္း ျဖစ္ပ်က္၊ နာမ္ကေရာ (ျဖစ္ ပ်က္)။

ဒုကၡသစၥာဆိုတာ

ႏွစ္ခုစလုံးျဖစ္တာလည္း ဒုကၡ၊ ပ်က္တာလည္းဒုကၡ၊ နာမ္ကလည္း ဒုကၡသစၥာ၊ ႐ုပ္ကလည္း (ဒုကၡသစၥာဘုရား) ဒုကၡသစၥာဆိုတာကေတာ့ ေလာကုတၱရာျဖစ္တဲ့နာမ္႐ုပ္ပါ ဒုကၡသစၥာပဲ။ သစၥာနဲ႔ဖြဲ႕ လိုက္လို႔ရွိရင္ ေလာကုတၱရာ ေရာက္ေနလို႔ျဖစ္ပ်က္ ၿငိမ္းသြားၿပီလို႔ ေအာက္ေမ့မေနပါနဲ႔။ နိဗၺာန္မေရာက္ေသးသ၍ ဒုကၡသစၥာခ်ည္းပဲ။
ေကာင္းၿပီ ဒါျဖင့္ ဒီဟာျဖစ္တာပ်က္တာ၊ နာမ္ေလးၾကည့္လိုက္ျပန္ ေတာ့လည္း ျဖစ္တာနဲ႔ ပ်က္တာပဲရွိတယ္၊ ႐ုပ္ကေလးၾကည့္လိုက္ျပန္ေတာ့ ေကာ ... (ျဖစ္တာနဲ႔ပ်က္တာပါဘုရား)၊ ျဖစ္တာနဲ႔ပ်က္တာရွိေတာ့၊ ျဖစ္တာပ်က္တာကိုပင္ ဘုရားကျဖစ္ဒုကၡ ပ်က္ဒုကၡကြ။
ဘာေဟာထားခဲ့တုံး ဒကာ ဒကာမတို႔ ... (ျဖစ္ဒုကၡပ်က္ဒုကၡပါ ဘုရား) ျဖစ္တာလည္း ဒုကၡ၊ ပ်က္တာလည္းဒုကၡပဲ၊ ဘုရားက မပိုင္းျခားဘူးလား (ပိုင္းျခားပါတယ္ဘုရား) ပိုင္းျခားတယ္ ဆိုတဲ့ အတိုင္း က်ဳပ္တို႔က ဉာဏ္ နဲ႔ၾကည့္လိုက္ေတာ့ ဟုတ္သားပဲ။ ျဖစ္ၿပီးပ်က္တာမွတစ္ပါး ခႏၶာကိုယ္ထဲမွာ ဘာေဝတဗၺနဲ႔ ပြားၾကည့္လိုက္ေတာ့၊ ဦးဘၾကည္ ဘာေတြ႕မယ္ထင္တုံး... (ျဖစ္ဒုကၡ ပ်က္ဒုကၡပါ ဘုရား)။
ျဖစ္ပ်က္ေတြ႕မယ္၊ ျဖစ္ပ်က္ေတြ႕ ေတာ့ အျဖစ္ကလည္း ဘာသစၥာ (ဒုကၡသစၥာပါဘုရား)၊ အပ်က္ကေရာ ... (ဒုကၡသစၥာပါဘုရား)။

ပထမဝိပႆနာဉာဏ္

ဒုကၡသစၥာလို႔ေတြ႕လာတဲ့တစ္ေန႔က်ေတာ့ ပထမဝိပႆနာဉာဏ္က ယထာဘူတဉာဏ္လည္း ထိုက္တန္သေလာက္ ေတြ႕သြားတယ္၊ နိဗၺႏၵဉာဏ္ ကေရာ (ေတြ႕ပါတယ္ဘုရား) ထိုက္တန္ သေလာက္ ေတြ႕တယ္။
ဒါေပမယ့္ ဒုကၡေတာ့၊ မပိုင္းျခားႏိုင္ေသးဘူး၊ ပိုင္းျခားႏိုင္ရဲ႕လား (မပိုင္းျခားႏိုင္ေသးပါဘုရား)၊ မပိုင္းျခားႏိုင္ေသးဘူး။
“ဒုကၡပရိညာဘိ သမေယန အဘိသေမတိ” ဆိုခဲ့တဲ့အတိုင္း ဒုကၡကို ပိုင္းျခားလိုက္ေတာ့ အရင္တုန္းကျဖစ္ပ်က္သာ ေအာက္ေမ့ေနတာ မဟုတ္ပါ လားေဟ့ ... ျဖစ္ဒုကၡ ပ်က္ဒုကၡပါလား ... (မွန္ပါ့ဘုရား) အရင္တုန္းကေတာ့ ျဖစ္ပ်က္သာ ေအာက္ေမ့ေနတာ။

သစၥာမျဖစ္ေသးဘူး

ျဖစ္ပ်က္ဆိုေတာ့ အနိစၥ၊ ဒုကၡ၊ အနတၱတင္ျဖစ္တယ္၊ ျဖစ္ၿပီးပ်က္တာ အနိစၥလို႔မဆိုႏိုင္ဘူးလား (ဆိုႏိုင္ပါတယ္ဘုရား) ျဖစ္ၿပီးပ်က္တာကို ဒုကၡလို႔ ေကာ (ဆိုႏိုင္ပါတယ္ဘုရား) ျဖစ္ၿပီးပ်က္တာကို အစိုးမရတဲ့ အနတၱလို႔ေကာ (ဆိုႏိုင္ပါတယ္ဘုရား)။
အဲဒါက အနိစၥ၊ ဒုကၡ၊ အနတၱသာျဖစ္ေသးတယ္၊ ဒကာ ဒကာမတို႔ သစၥာမျဖစ္ေသးဘူးတဲ့၊ သစၥာမျမင္ေသးရင္ မဂ္မျဖစ္ေသးဘူးျဖစ္ေတာ့ ျဖစ္ပါ ရဲ႕ ေလာကီမဂ္ငါးပါးသာျဖစ္တယ္။ အနိစၥ၊ ဒုကၡ၊ အနတၱျမင္လို႔ရွိရင္ျဖင့္ ဘာသာလ်င္ျဖစ္တယ္ ... (ေလာကီမဂ္ငါးပါးသာျဖစ္ပါတယ္ဘုရား)။
ဒါျဖင့္ “ေလာကုတၱရာ အ႒ဂႋေကာမေစၦ”ဆိုတဲ့အတိုင္း ဒကာ ဒကာမတို႔ ရွစ္ပါးျပည့္ဖို႔ဆိုတာ ကေတာ့ ဒုကၡပိုင္းျခားမွျပည့္မယ္ ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။

ဒုကၡပိုင္းျခားႏိုင္ရင္ ရွစ္ပါးျပည့္မယ္

ဒုကၡပိုင္းျခားႏိုင္ရင္ ဘာတုံး ... ဒကာ ဒကာမတို႔ (ရွစ္ပါးျပည့္ဖို႔ ပါဘုရား) ဒုကၡ မပိုင္းျခား ႏိုင္ေသးရင္ ... (ရွစ္ပါးမျပည့္ေသးပါဘုရား) ဘယ္ေတာ့မွ ရွစ္ပါးျပည့္လိမ့္မယ္လို႔မေအာက္ေမ့နဲ႔၊ ဒါျဖင့္ ဘုန္းႀကီးက ခတ္ၾကမ္းၾကမ္းနဲ႔ ဒကာ ဒကာမတို႔ကို ေဟာတယ္၊ ဒီတရားဟာ အေရလည္ လာၿပီ ေဟာလို႔လြယ္သြားၿပီ၊ မင္းတို႔အနိစၥ၊ ဒုကၡ၊ အနတၱက နိဗၺာန္မေရာက္ ဘူး (မွန္လွပါဘုရား)။

နိဗၺာန္ျမင္တဲ့တရားမဟုတ္

နိဗၺာန္၏ေရွ႕ေျပး နိဗၺာန္သာေရာက္ေအာင္ပို႔ႏိုင္တယ္၊ နိဗၺာန္ျမင္တဲ့ တရား မဟုတ္ဘူး (မွန္လွပါဘုရား)၊ အနိစၥ၊ ဒုကၡ၊ အနတၱျမင္တဲ့ဉာဏ္သည္ နိဗၺာန္ျမင္ပါရဲ႕ လား ... (မျမင္ပါဘုရား) ရွင္းပလား (ရွင္းပါၿပီ)။

နိဗၺာန္ေရာက္ေၾကာင္းတရား

ဒါျဖင့္ အနိစၥ၊ ဒုကၡ၊ အနတၱသည္ နိဗၺာန္ေရာက္ေၾကာင္းတရားသာ ဆိုတယ္တဲ့၊ နိဗၺာန္ကို တကယ္ မ်က္ေမွာက္ျပဳႏိုင္တဲ့တရားဟုတ္ပါရဲ႕လားလို႔ ေမးရင္ (မဟုတ္ပါဘုရား) ၾကည့္ကို မၾကည့္ ႏိုင္ဘူး၊ သူကျဖစ္ပ်က္ေနတုန္း၊ ေတဘူမကသခၤါရ အာ႐ုံျပဳေနတယ္ ... (မွန္လွပါဘုရား)။

အသခၤတ အနားမသီႏိုင္ဘူး

ဒါျဖင့္ မဂ္ငါးပါးထဲ သခၤတအာ႐ုံဆိုေတာ့ အသခၤတအနားမသီႏိုင္ ဘူး၊ သီႏိုင္ပါ့မလား (မသီႏိုင္ပါဘုရား) မသီႏိုင္ေတာ့ေနာက္ထပ္ ပြားမ်ား ၿပီး သကာလ ျဖစ္ပ်က္ျမင္ေအာင္ၾကည့္ပါ၊ ျဖစ္ပ်က္မုန္းေအာင္ၾကည့္ပါ။

ျဖစ္ပ်က္ဆုံးေအာင္႐ႈမွ နိဗၺာန္ေရာက္မွာ

ျဖစ္ပ်က္မုန္းေအာင္ၾကည့္ၿပီးသကာလျဖစ္ပ်က္ဆုံးေအာင္ ရႈမွသာ လွ်င္ နိဗၺာန္ေရာက္မွာကိုး၊ မဆုံးလို႔ရွိရင္ျဖင့္ နိဗၺာန္ေရာက္ပါ့မလား ... (မေရာက္ပါဘုရား) မေရာက္ေတာ့၊ ျဖစ္ပ်က္ဆုံးခ်င္ တဲ့အခ်ိန္၊ ဉာဏ္ရင့္လာတဲ့အခ်ိန္ က်ေတာ့ ... ျဖစ္တာေလးကလည္း ဒုကၡသစၥာေလးပဲ။ ပ်က္တာေလးကေရာ ... (ဒုကၡသစၥာေလးပါဘုရား)။
ဪ ... ဒီဥစၥာ ဒုကၡလည္းဟုတ္တယ္၊ သစၥာလည္းဟုတ္တယ္၊ ဆင္းရဲတာလည္း သူ႔ထက္ဆင္းရဲတာ မရွိေတာ့ဘူး၊ သစၥာလည္း မွန္လိုက္တဲ့ ျဖစ္ျခင္း၊ သူႏွိပ္စက္ေနတဲ့ တရားေတြက ပီဠန႒၊ သခၤတ႒၊ သႏၲာပ႒ေတြက သူ႔မီးခ်ည္းရွိေနတာပဲ ... (မွန္လွပါဘုရား)။
ပီဠန႒ေကာ မႏွိပ္စက္တတ္ဘူးလား ... (ႏွိပ္စက္တတ္ပါတယ္ ဘုရား)၊ သခၤတ႒ေရာ အႏွိပ္စက္မခံရဘူးလား ... (ႏွိပ္စက္ခံရပါတယ္ ဘုရား)၊ သႏၲာပ႒ဆိုတဲ့မီးေတြကေရာ (ေလာင္ပါတယ္ ဘုရား)။
ေၾသာ္-ဒီ႐ုပ္နာမ္ႏွစ္ပါးသည္ကားဆိုလို႔ရွိရင္၊ ႐ုပ္ရႈတဲ့ပုဂၢိဳလ္က ႐ုပ္ ေပါ့ဗ်ာ၊ နာမ္ရႈတဲ့ ပုဂၢိဳလ္က နာမ္ေပါ့ဗ်ာ၊ အဲဒီကဲ့သို႔ ႐ုပ္နာမ္ေတြ တစ္ခုခုကို မဲၿပီး လိုက္ၿပီးရႈလိုက္ၿပီဆိုမွျဖင့္ သူတို႔ႏွစ္ခုဟာ မခြဲေကာင္းတဲ့တရားကိုးဗ် (မွန္လွပါဘုရား)။
“ဥေဘာ အေညာညနိႆိတာ ဧကသၼႎ ဘိဇၨမာေန ဥေဘာပိ ဘိဇၩႏၲိ” ဆိုတဲ့အတိုင္း တစ္ခုပ်က္တာျမင္လို႔ရွိရင္၊ သူေရာတစ္ခါတည္းတြဲလ်က္ပါသြား တာပဲ။ သူတို႔က အညမညကိုးဗ် (မွန္လွပါဘုရား)။

႐ုပ္နာမ္က အညမည

နာမ္နဲ႔႐ုပ္နဲ႔ အညမညမွီေနၾကတာ၊ ေတာင္ေဝွးႏွစ္ေခ်ာင္း ဒီလိုစု ေထာင္ထားသလို၊ ေျမေပၚမွာ ထားရေတာ့တာေပါ့ဗ်ာ၊ တစ္ေခ်ာင္းဆြဲလိုက္ ႏွစ္ေခ်ာင္းစလုံးလဲမွာပဲ၊ မလဲဘူးလား ... (လဲပါတယ္ ဘုရား)၊ အဲဒီေတာ့ ႐ုပ္ပ်က္ရင္ နာမ္ပ်က္တယ္လို႔ဆုံးျဖတ္ခ်က္ခ်ပါ၊ ဒကာ ဒကာမေတြ ရွင္းပလား (ရွင္းပါၿပီဘုရား)။
ေတာင္ေဝွးႏွစ္ေခ်ာင္း အဖ်ားခ်င္းစုစည္းထားစမ္းပါ၊ ႏွစ္ခုထိပ္တိုက္ ေနလို႔ တည္ေနတာကိုးဗ်၊ ထိပ္တိုက္ေနလို႔တည္ေနတာ၊ တစ္ေခ်ာင္းဆြဲလိုက္ေတာ့ ႏွစ္ခုထိပ္တိုက္စရာရွိေသးသလား ... (မရွိပါဘုရား)၊ မရွိေတာ့ တစ္ခုမျပဳတ္ဘူးလား ... (ျပဳတ္ပါတယ္ဘုရား)။
ဒါျဖင့္ ႐ုပ္ကိုမွီေနတဲ့နာမ္၊ နာမ္ကိုမွီေနတဲ့႐ုပ္၊ မဆိုႏိုင္ဘူးလား ... (ဆိုႏိုင္ပါတယ္ဘုရား)။

သဟဇာတနိႆယ

သဟဇာတနိႆယ က်ေတာ့ နာမ္ကိုမွီေနတဲ့႐ုပ္၊ ပုေရဇာတ နိႆယ က်ေတာ့ ႐ုပ္ကိုမွီေနတဲ့နာမ္ ... (မွန္လွပါဘုရား) ဘာထူးေသး သတုံး ခင္ဗ်ားတို႔ ... (မထူးပါဘုရား) သေဘာက်ပလား ... (က်ပါၿပီ ဘုရား)။
ပ႒ာန္းနည္းနဲ႔ေကာကိုက္ပလား ... (ကိုက္ပါတယ္ဘုရား) သဟဇာတဆိုေတာ့ ဒီနာမ္ျဖစ္ရင္ ဒီ႐ုပ္မျဖစ္ေပဘူးလား ... (ျဖစ္ပါတယ္ ဘုရား) ကဲ ... ဒါသဟဇာတနဲ႔ ေထာက္ျပတာ ... (မွန္လွပါ ဘုရား)။

ပုေရဇာတနိႆယ

ပုေရဇာတနဲ႔က်ေတာ့ ဒီကေနၿပီးသကာလ ပုေရဇာတပစၥေယာဆို ေတာ့ သူမလာလို႔ရွိရင္ ဒီနာမ္သည္ကားေသဖြယ္ရာရွိတယ္၊ မရွိဘူးလား (ရွိပါတယ္ဘုရား)။
သူက ေရွ႕ကတစ္ခါတည္း ပုေရဇာတျဖစ္ၿပီးသကာလ ေရွ႕ကေနၿပီး ေထာက္ပံ့ကူညီလို႔ မွီစရာရွိလို႔သာလ်င္ သူ႔အသက္သည္၊ နာမ္ဓမၼေလး အသက္ရွည္တာ၊ ႏို႔မို႔ရင္ရွည္ပါ့မလား ... (မရွည္ပါဘုရား) ျဖစ္ပ်က္မွီစရာ မရွိရင္ သူေပၚႏိုင္ပါ့မလား ... (မေပၚႏိုင္ပါဘုရား)။
ဒါျဖင့္ ဘုန္းႀကီးတို႔ ဒကာ ဒကာမေတြ ဉာဏ္ေရာက္ၿပီးျဖစ္လို႔၊ သူတို႔ ႏွစ္ခုတစ္ခုပ်က္ရင္ ဘာပါလိမ့္ ... (ေနာက္တစ္ခုလည္း ပ်က္ပါတယ္ ဘုရား) ႏွစ္ခုပ်က္ပဲ၊ ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။ ။
ပ်က္ေတာ့ကိုသူတို႔ ႏွစ္ခုသည္ျဖစ္တာလည္းရွိတယ္၊ ပ်က္တာလည္း ရွိတယ္ဆိုေတာ့ ဒုကၡမွတစ္ပါးဘာရွိေသး ... (မရွိပါဘုရား)။
ဪ... ဒါဒုကၡအစစ္ပဲလို႔ဆုံးျဖတ္ခ်က္ခ်လိုက္စမ္းပါ။ မင္းနဲ႔ျဖင့္ ေနခ်င္တဲ့ သတၱိ မရွိေတာ့ပါဘူး လို႔ဆိုရင္ျဖင့္ ဒုကၡခ်ဳပ္ၿပီ၊ မခ်ဳပ္ေသးဘူးလား (ခ်ဳပ္ပါတယ္ဘုရား)။

ဒုကၡနဲ႔ သမုဒယနဲ႔ခ်ဳပ္သြားတယ္

ဘာျဖစ္လို႔ခ်ဳပ္သတုံးလို႔ ေမးလို႔ရွိရင္၊ သမုဒယ အရွိန္အေစာ္ မရွိလို႔၊ သူနဲ႔ပတ္သက္တဲ့ သမုဒယ အရွိန္အေစာ္ မရွိလို႔တဲ့၊ ရွင္းပလား (ရွင္းပါၿပီ ဘုရား)။
ဒါျဖင့္ ခ်ဳပ္သြားတာ၊ သစၥာဘယ္ႏွစ္ပါးတုံး. . . (ဒုကၡနဲ႔ သမုဒယပါ ဘုရား)၊ သမုဒယနဲ႔ဒုကၡ။
ဒါျဖင့္ ရႈေနတဲ့ဉာဏ္ဟာ ဘယ္သူနဲ႔တည့္ရမွာပါလိမ့္မတုံးဆိုေတာ့ ... ဒုကၡမရွိတာနဲ႔ သြားတည့္မယ္၊ ဘာနဲ႔သြားတည့္မယ္ ... (ဒုကၡမရွိတာနဲ႔ သြားတည့္ပါမယ္ဘုရား)။

ဒုကၡမရွိတာ နိေရာဓသစၥာ

ဒုကၡမရွိတာက ဘာသစၥာ ... (နိေရာဓသစၥာပါဘုရား) နိေရာဓ သစၥာက ဘယ္သူ႔နိေရာဓါလဲ ... (ဒုကၡနိေရာေဓါ ပါဘုရား) ကိေလသ နိေရာေဓာ ေကာ ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။
ဒုကၡကလည္း ဆက္သြယ္ေသးသလား ... (မဆက္သြယ္ပါဘုရား)၊ ကိေလသာနဲ႔ေကာ ... (မဆက္သြယ္ပါဘုရား)။
ဒါျဖင့္ “တဏွာနိေရာဓါ နိဗၺာနံ၊ ဒုကၡနိေရာဓါ နိဗၺာနံ” - ေဟာဒီမယ္ ခင္ဗ်ားတို႔ ရႈပါ၊ ရႈဉာဏ္နဲ႔ကို သြားကိုက္တယ္၊ မကိုက္ဘူးလား ... (ကိုက္ပါ တယ္ဘုရား)။

နိဗၺာန္သည္ခႏၶာအဆုံးမွာရွိတယ္

ဒါျဖင့္ နိဗၺာန္သည္ကားဆိုလို႔ရွိရင္ ခႏၶာအဆုံးမွာရွိတယ္ဆိုေတာ့၊ ေဟာ ဒီအဆုံးမွာ နိဗၺာန္ရွိတယ္ ... (မွန္လွပါဘုရား) ရွင္းပလား (ရွင္းပါ ၿပီဘုရား)။
နိဗၺာန္သည္ ခႏၶာထဲမွာမရွိဘူး၊ ခႏၶာအဆုံးမွာရွိတယ္ ... (ရွိပါ တယ္ဘုရား) ေက်နပ္ပလား ... (ေက်နပ္ပါၿပီဘုရား)။
ကိုင္း-ယေန႔ ဒီတြင္ေတာ္ၾကစို႔ ... ။
သာဓု ... သာဓု ... သာဓု။
