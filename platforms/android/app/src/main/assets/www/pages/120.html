မွန္းေျခေပါက္အလုပ္ အပိုင္း(၂)
(၁၀-၃-၆၁)

#လႉနည္းသင္ (ကထိန္အႀကိဳ) အပိုင္း(၃)
(၂၁-၁၁-၆၁)

အသံဖိုင္ေခါင္းစဥ္ = ပဋိစၥသမုပၸာဒ္ ႏွင့္လႉနည္းသင္တရားေတာ္
စာအုပ္ေခါင္းစဥ္ = ဒါနခန္း (ကထိန္အႀကိဳ)
~~~~~~~~~~~~

မသိလို႔ လႉတာကေတာ့ ဟုတ္ပါတယ္တဲ့။ ၁,၂,၃,၄အကြက္ေတြ လွည့္သြားတယ္ ...... (လွည့္သြားပါတယ္ ဘုရား) သိလႉကေတာ့ကို ၁ ... ၿပီးေတာ့ ၂ ... က်ေတာ့ ကိစၥတုံးတယ္ ... (မွန္လွပါဘုရား) ၁ ... က မဂၢသစၥာ ... (မွန္ပါ့) ၂ ... က (နိေရာဓသစၥာပါဘုရား) ေျပာင္းျပန္ ျပန္မွတ္ရမယ္ .. (မွန္ပါ့) ရွင္းပလား ..... (ရွင္းပါၿပီဘုရား)။

သိတာက မဂၢသစၥာ၊ သေဘာက်ပလား ... (က်ပါၿပီ ဘုရား) သိလို႔လႉတာက..... (မဂၢသစၥာပါဘုရား) ရတာက.... (နိေရာဓသစၥာပါဘုရား) ဘယ္ေလာက္ ေနရာက်သလဲ ...... (မွန္လွပါ) နိဗၺာန္ရတယ္.. (မွန္ပါ)။
ဒါျဖင့္ ဒါန သီလက သံသရာရွည္တာလား၊ သိမႈ, မသိမႈ ေၾကာင့္ရွည္တာလား.....(သိမႈ, မသိမႈေၾကာင့္ သံသရာရွည္တာ ပါဘုရား) မွတ္ထား .. ၊ ေနာက္ ဒါန သံသရာရွည္တယ္လို႔ မသုံးနဲ႔ .. (မွန္ပါဘုရား)။
မသိမႈေၾကာင့္ ရွည္တာ ... (မွန္ပါ) သိမႈရွိတဲ့ ပုဂၢိဳလ္က်ေတာ့... (မရွည္ပါဘုရား) မရွည္ပါဘူး၊ ၁ ... က မဂၢသစၥာ၊ ၂ ... က နိေရာဓသစၥာ၊ ဒီဘက္ သြားေသးရဲ႕လား..... (မသြားပါ ဘုရား)။ ။
ကိုင္း...... ဒါျဖင့္ ဦးသန္းေမာင္ႀကီး ေနရာက်ပလား.... (က်ပါၿပီဘုရား) ဒကာသစ္ ဘယ့္ႏွယ္ ေရးေပးထားသလဲ မသိလို႔လႉတာ ဘာသစၥာ..... (သမုဒယသစၥာပါဘုရား)။
ေကာင္းၿပီ ..... ရ, ေတာ့ ဘာသစၥာလဲ .. (ဒုကၡသစၥာ ပါဘုရား) သိလို႔လႉရင္ ဘာသစၥာ ... (မဂၢသစၥာပါဘုရား) ရေတာ့ ဘာသစၥာ ... (နိေရာဓသစၥာပါဘုရား) ေအး ... ဒါနဲ႔ ကိုက္ေအာင္လုပ္ၾက၊ ဒါနဲ႔ ကိုက္ေအာင္လုပ္..... (မွန္ပါ)။
ကဲ ... ဒကာႂကြယ္ ... ေနရာက်ပလား ...... (က်ပါၿပီဘုရား) ဒါေနာက္ကို အားလုံး ျပင္တတ္ၾကပလား ...... (ျပင္တတ္ပါၿပီဘုရား)။
အဲ..... ဒါက ဆြမ္းတစ္ဇြန္း, ကြမ္းတစ္ယာကို လႉေစကာမူ ဒီစိတ္ကေလးေတာ့ ထားၾကပါ.. (မွန္လွပါဘုရား) အႀကီး အက်ယ္ဆိုရင္ျဖင့္ ဆိုဖြယ္မရွိေတာ့ဘူး အမ်ားႀကီးပဲ ဒီဥစၥာကို။ ခႏၶာ ႏွလုံးသြင္းၾကပါ...... (မွန္လွပါဘုရား) ခႏၶာ ႏွလုံးသြင္း လိုက္တဲ့အခါက်လို႔ရွိရင္ျဖင့္ ...... တဲ့၊ ခႏၶာက ျပတယ္ .... (မွန္ပါ)။
ဒကာႂကြယ္... ခႏၶာက ထိုင္ၿပီးရင္ ျပတယ္.. (ျပပါ တယ္ဘုရား) ေတာ္ေတာ္ၾကာ က်င္ငယ္ စြန႔္ခ်င္လာတယ္ ...... (လာပါတယ္ဘုရား) က်င္ႀကီးစြန႔္ခ်င္တာေကာ..... (လာပါတယ္ ဘုရား) အင္း ... ဟင္ ... စြန႔္ၿပီး ျပန္ဆာေလာင္ မြတ္သိပ္ တာက ... (လာပါတယ္ဘုရား) ဘာသစၥာ ေတြခ်ည္း လာသလဲ.... (ဒုကၡသစၥာေတြခ်ည္း လာပါတယ္ဘုရား)။
ဒီအထဲကေနၿပီး ယားတယ္၊ နာတယ္၊ ေအာင့္တယ္၊ ကိုက္တယ္၊ ခဲတယ္၊ ေအာင့္တယ္၊ က်ဥ္တယ္၊ ေညာင္းတယ္..... (မွန္ပါ) ဘာေတြျပသလဲ.... (ဒုကၡေတြ ျပပါတယ္ဘုရား)။
အဲဒီ ဒုကၡသစၥာေတြကို ဦးသန္းေမာင္က အရင္ၾကည့္လိုက္၊ မလႉခင္ .... (မွန္လွပါဘုရား) ဒီဒုကၡမွ လြတ္ရပါလို၏ ဆိုၿပီးလႉဒါန္း .. (မွန္ပါဘုရား) ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)
ဒီဒုကၡမွ ..... (လြတ္ရပါလို၏ ဘုရား) ခင္ဗ်ားတို႔ဟာက အလကားပါ၊ အလႉလုပ္ မ႑ပ္တိုင္ ျပၿပီး ဟိုေျပးဒီေျပး မ႑ပ္ တိုင္တက္သလို (မွန္ပါဘုရား)ဘယ္ဒါေတာ့ ႏွလုံးသြင္းတာ မဟုတ္ဘူး ... (မသြင္းပါဘုရား) အလကားေထြရာ ဗ်ာပါမ်ားေနတာ .. (မ်ားပါတယ္ဘုရား)။
ဒကာႂကြယ္ ဗ်ာပါမ်ားေတာ့ သမုဒယသစၥာ လုပ္ေနတယ္ ..... (လုပ္ေနပါတယ္ဘုရား) သမုဒယသစၥာလုပ္ေတာ့ ေသသည္၏ အျခားမဲ့၌ ဘာသစၥာရမလဲ .. (ဒုကၡသစၥာ ရပါတယ္ဘုရား) ဟာ ... အလႉရွင္ ဒုကၡေရာက္ၿပီ...(မွန္ပါ) , ဘယ္သူ ဒုကၡေရာက္သလဲ .... (အလႉရွင္ ဒုကၡေရာက္ပါတယ္ ဘုရား) ရွင္းပလား .. (ရွင္းပါၿပီဘုရား)။
ကဲ..... ဒါျဖင့္ အလႉရွင္ ဒုကၡမေရာက္ေအာင္ ဘယ့္ႏွယ္ လုပ္မတုံးဆိုေတာ့ ဦးသန္းေမာင္ ခႏၶာစိုက္လိုက္ ... (မွန္ပါ့) ခႏၶာဉာဏ္နဲ႔ စိုက္လိုက္ေတာ့ ဘာေတြ ေတြသလဲ...(ဒုကၡသစၥာေတြ ေတြပါတယ္ဘုရား)။
ဟင္.. အဲဒီထဲ ဒုကၡသစၥာေတြ ေတြေတာ့ ရွိတာက ဒုကၡ သစၥာ၊ ေတြတဲ့ဉာဏ္က မဂၢသစၥာ ... (မွန္ပါ) ကိုယ့္ကိုယ္တိုင္ ေတြတာကိုး ...... (မွန္ပါ့ဘုရား) ေတြတဲ့ ဉာဏ္က ဘာသစၥာတုံး ....(မဂၢသစၥာပါ ဘုရား)။
အဲဒီ မဂၢသစၥာနဲ႔ ေလာကီမဂၢသစၥာ ျဖစ္ၿပီး သကာလေန ေတာ့ တကာတကာမတို႔ ကိုယ္တိုင္ျမင္တဲ့ ဒီဒုကၡႀကီးမွ ကြၽတ္ျခင္း, လြတ္ျခင္းကို အလိုရွိ၍ လႉဒါန္းပါ၏ ... (မွန္ပါ့ဘုရား) ရွင္းပလား .... (ရွင္းပါၿပီဘုရား)။
ကိုယ္တိုင္ျမင္တဲ့ ဒုကၡသစၥာႀကီးမွ ... (ကြၽတ္ျခင္း, လြတ္ျခင္းကို အလိုရွိ၍ လႉ ဒါန္းပါ၏) လႉဒါန္းပါ၏ ဆိုၿပီး သံဃာ့ လက္ေရာက္ေအာင္ ဒကာႂကြယ္ လႉလိုက္တာေပါ့ ........ (မွန္ပါ့ဘုရား) ဘုရားေက်ာင္းေဆာက္လဲ ဘုရားလႉလိုက္တာေပါ့ .... (မွန္ပါ့ဘုရား)။
ဒီလိုဆိုေတာ့ ဒုကၡေၾကာက္လို႔ လႉတဲ့အလႉ ... (မွန္ပါ့ ဘုရား) ဒုကၡစက္ဆုပ္လို႔ ... (လႉတဲ့ အလႉပါဘုရား) ဒါျဖင့္ မဂၢသစၥာနဲ႔ လႉတာ ... (မွန္ပါ့ဘုရား) ဒီဘက္ဘာသစၥာရသလဲ ... (နိေရာဓသစၥာ ရပါတယ္ဘုရား) ဒီဘက္သြားစရာ ရွိေသးရဲ႕လား ..... (မရွိပါဘုရား)။
ဒါျဖင့္ အဝိုင္းရပ္ၿပီ ... (ရပ္ပါၿပီ) ရပ္သြားၿပီဆိုတာ ဒကာႂကြယ္ ေပၚၿပီ .. (ေပၚပါၿပီ) ကဲ ... ဦးသန္းေမာင္ ကိုယ္ေတြ႕ပဲ မဟုတ္လား ... (မွန္ပါဘုရား)။
ကိုယ္ေတြ႔ပါပဲဆိုေတာ့ ေၾသာ္ ...... ဒီလို သိလိုက္ရတဲ့ အသိကေလးဟာ ဒကာႂကြယ္၊ဟို...... ေနာက္တုန္းကသိခဲ့ရင္လဲ ဒီဆရာနဲ႔ ဒီဒကာ မေတြ႕ ေတာ့ဘူး ... (မွန္ပါ) နိဗၺာန္ေရာက္သြားမွာပဲ .. (ေရာက္ပါတယ္ဘုရား) သို႔ေၾသာ္ .... မသိတဲ့ လူေတြျဖစ္ေနလို႔ ျပန္ေျပာေနရတဲ့ အဓိပၸာယ္ ေရာက္ပါတယ္ (ေရာက္ပါတယ္ ဘုရား) ရွင္းပလား ... (ရွင္းပါၿပီဘုရား)။
ကိုင္း .. ဒါျဖင့္ ဒီထက္ နက္နက္ကေလး တစ္ခါ ေျပာပါဦးမယ္ ..... (မွန္ပါဘုရား) ဒီထက္ နက္နက္ကေလးက ဘာပါလိမ့္မတုံးဆိုေတာ့ အဝိဇၨာရွိတဲ့ ပုဂၢိဳလ္ဟာ ... တဲ့။ သခၤါရဆိုတဲ့ ေစတနာေတြ, ကုသိုလ္ ေစတနာေတြလဲ လုပ္တာပဲ၊ အကုသိုလ္ ေစတနာေတြလဲ လုပ္တာပဲေနာ္ ... (မွန္ပါ) ဘာျဖစ္လို႔၊ မသိလို႔လုပ္တာ .. (မွန္ပါ၊ မသိလို႔လုပ္တာပါ ဘုရား)။
ဒါျဖင့္မသိလို႔ ကုသိုလ္လဲလုပ္၊ မသိလို႔အကုသိုလ္လဲ.. (လုပ္ပါတယ္ ဘုရား) မလုပ္ေပဘူးလား (လုပ္ပါတယ္ ဘုရား)
ေကာင္းၿပီ၊ တကာတကာမတို႔ မသိေသာ ပုဂၢိဳလ္သည္ကားလို႔ ဆိုရင္ျဖင့္ လုပ္ခ်င္တာ လုပ္တယ္လို႔ ဆိုတဲ့စကားမွန္, မမွန္ (မွန္ပါတယ္ ဘုရား)။
ကုသိုလ္လဲ လုပ္လိုက္တာပဲ၊ အကုသိုလ္ေကာ .... (လုပ္ပါတယ္ဘုရား) ဒါ... ဘယ္သူ လုပ္တာပါလိမ့္ .... (မသိတဲ့ ပုဂၢိဳလ္လုပ္တာပါ ဘုရား) မသိတဲ့ပုဂၢိဳလ္ ... (မွန္ပါ) ဒါျဖင့္ အဝိဇၨာေၾကာင့္ သခၤါရျဖစ္ရ တာပဲ.....(မွန္ပါ) ရွင္းပလား ...(ရွင္းပါၿပီ) မသိတဲ့ပုဂၢိဳလ္ဟာ ကုသိုလ္လဲ.....(လုပ္ပါတယ္) အကုသိုလ္ေကာ..... (လုပ္ပါတယ္ဘုရား)။
ဒါျဖင့္ ကုသိုလ္လဲ သူဟာ ဘုံဘဝ ဒုကၡသစၥာျဖစ္ေၾကာင္း လုပ္တာပဲ၊ အပါယ္ေလးပါး ေရာက္ေၾကာင္း အကုသိုလ္ေကာ... (လုပ္ပါတယ္ဘုရား) ဟာ ... ဘာျဖစ္လို႔ လုပ္ပါလိမ့္၊ သူဟာ (မသိတဲ့ အဝိဇၨာေၾကာင့္ပါဘုရား)။
ဟာ ... ဒါျဖင့္ ဟုတ္ၿပီ၊ မသိလို႔လုပ္တယ္.....(မွန္ပါ့) အဝိဇၨာပစၥယာ .. (သခၤါရာပါဘုရား) ဒါျဖင့္ မသိတာ ... (အဝိဇၨာပါဘုရား) ျပဳလုပ္တာ.. (သခၤါရပါဘုရား)။
အဲ... ကဲ ... ေသၾကစို႔ဆိုေတာ့ တကာတကာမတို႔၊ ေဟာဒီျမားကစပ္ျပတယ္၊ ေဟာဒီပဋိသေႏၶေနၿပီ.....(မွန္လွပါ) ဘာသစၥာရသလဲ .... (ဒုကၡသစၥာရပါတယ္ဘုရား)။
ဇာတိပိ ...... (ဒုကၡသစၥာပါဘုရား) ရွင္းပလား ..... (ရွင္းပါၿပီ) ဝိညာဏ္ဆိုတာ ပဋိသေႏၶဝိညာဏ္ဆိုေတာ့ ဇာတိပါပဲ ... (မွန္ပါ့) ဘာသစၥာရသလဲ .. (ဒုကၡသစၥာရပါတယ္) ေက်နပ္ပလား .. (ေက်နပ္ပါၿပီဘုရား)။
ကဲ....ဒါျဖင့္ ဒီလိုလုပ္ၾကစို႔၊ သိလို႔တကာတကာမေတြက လႉၿပီတဲ့၊ လႉခ်င္လဲလႉ.....(မွန္ပါ) သိလို႔ျဖစ္ပ်က္အားထုတ္တယ္ ... (မွန္ပါဘုရား)။
ဒါျဖင့္ သိလို႔ ျဖစ္ပ်က္အားထုတ္တာလဲ မဂၢသစၥာ (မွန္ပါ) သိၿပီးလႉတာလဲ (မဂၢသစၥာပါဘုရား) ရွင္းပလား.... (ရွင္းပါၿပီ) သိလို႔ အားထုတ္တာလဲ.....(မဂၢသစၥာပါဘုရား) အင္း ... ဟင္ ... သိၿပီး သကာလ လႉတာေကာ .. (မဂၢသစၥာပါ ဘုရား) ဒါျဖင့္ မဂၢသစၥာ အားထုတ္ေတာ့ကို တဲ့၊ ဒီဘက္က ဘာသစၥာရသလဲ .... (နိေရာဓသစၥာ ရပါတယ္ဘုရား) ဒါျဖင့္ သိလို႔ လႉတာလဲ နိေရာဓသစၥာ ... (မွန္ပါ) ရွင္းပလား ........ (ရွင္းပါၿပီ ဘုရား) အင္း ... ဟင္ ... သိလို႔ အားထုတ္ျပန္ရင္ ေကာ .. (နိေရာဓသစၥာပါ ဘုရား) သေဘာပါပလား ..(ပါ, ပါၿပီ)။
ဒါျဖင့္ တကာတကာမတို႔ အင္မတန္ ေနရာက်ပါၿပီ ...... (မွန္ပါ)။
ဒါျဖင့္ ဒီဘက္က ခႏၶာငါးပါးဟာ သိၾကား, ျဗဟၼာ, ဘုရားလာၿပီး ဖန္ဆင္းတာလား၊ အဝိဇၨာ သခၤါရတို႔ လုပ္လိုက္ တာလား ...... (အဝိဇၨာ သခၤါရတို႔ လုပ္လိုက္တာပါဘုရား)။
ဒါျဖင့္ သိၾကား, ျဗဟၼာ, ဘုရားလာၿပီး ဖန္ဆင္းတယ္ဆိုတဲ့ အယူမွားႀကီး ပယ္လိုက္ပါေတာ့ ... (မွန္ပါဘုရား) ဒိ႒ိျပဳတ္ၿပီ ... (မွန္ပါ, ျပဳတ္ပါၿပီ)။
ဒါျဖင့္ ... ဒီခႏၶာႀကီးရေနတာ အခုတရားနာေနတဲ့ တကာတကာမေတြ၊ တို႔ ဘယ္က လာပါလိမ့္မလဲ ဆိုတာေကာ သိပလား .. (သိပါတယ္ဘုရား) ဘယ္ကလာသလဲ .... (အဝိဇၨာ သခၤါရက လာပါတယ္ဘုရား)။
အတိတ္ဘဝက အဝိဇၨာ သခၤါရကလာတယ္..... (မွန္ပါ) တို႔ဟာ ဘယ္ကမွလာခဲ့တာ မဟုတ္ဘူး၊ ဘယ္သူ ဖန္တီးတာမွ မဟုတ္ဘူး၊ သေဘာက်ပလား.....(က်ပါၿပီ) ဘယ္ကလာခဲ့တာ တုံး (အဝိဇၨာ သခၤါရက လာခဲ့တာပါဘုရား)။
အဝိဇၨာ သခၤါရက လာတယ္ဆိုေတာ့ ဘယ္က လာပါလိမ့္ မလဲဆိုတဲ့ ဝိစိကိစၧာ ရွိေသးရဲ႕လား .. (မရွိပါဘုရား)။ ဒါျဖင့္ ဝိစိကိစၧာလဲေသၿပီ..(ေသပါၿပီဘုရား)ဒီခႏၶာႀကီးသည္ ကားလို႔ဆိုရင္ ဘယ္သူ ျပဳလုပ္တာပါလိမ့္ .... (အဝိဇၨာသခၤါရ ျပဳလုပ္တာပါဘုရား)။
ဟာ ... ဒါျဖင့္ သူတစ္ပါး ဖန္ဆင္းတယ္ဆိုတဲ့အယူေတြ ေကာ ရွိေသးရဲ႕လား ..... (မရွိပါဘုရား) ဒါျဖင့္ ဒိ႒ိလဲ ျပဳတ္ၿပီ ... (ျပဳတ္ပါၿပီဘုရား) ဝိစိကိစၧာေကာ .. (ျပဳတ္ပါၿပီဘုရား)။
အဝိဇၨာသခၤါရက ျပဳျပင္လိုက္ေတာ့ ဒီဘက္မွာ ပုဂၢိဳလ္ သတၱဝါ ေပၚသလားတဲ့၊ ဝိဉာဏ္, နာမ္႐ုပ္, သဠာယတန, ဖႆ, ေဝဒနာဆိုတဲ့ ခႏၶာငါးပါး ေပၚသလား ..... (ခႏၶာငါးပါး ေပၚပါတယ္ ဘုရား)။
ဒါျဖင့္ျပဳလုပ္တာလဲ ပုဂၢိဳလ္သတၱဝါမဟုတ္ဘူး....(မွန္ပါ) ျဖစ္ေပၚေနတာလဲ..... (သတၱဝါ မဟုတ္ပါ ဘုရား) ဒီလိုဆိုေတာ့ - ဒိ႒ိခြာပစ္လိုက္တယ္..(မွန္ပါ) ျပဳလုပ္တာလဲ ပုဂၢိဳလ္သတၱဝါ မဟုတ္ဘူး....(မဟုတ္ပါဘုရား) အဝိဇၨာသခၤါရပဲ.....(မွန္ပါ)။
ျပဳလုပ္လိုက္လို႔ အခု ခႏၶာကိုယ္ႀကီး ေပၚေနတာလဲ ဘာပါလိမ့္.. (ပုဂၢိဳလ္သတၱဝါ မဟုတ္ပါ ဘုရား) ပုဂၢိဳလ္သတၱဝါ မဟုတ္ဘူးဆိုတာ မသိဘူးလား .. (သိပါတယ္ဘုရား) အဲဒါ ပဋိစၥသမုပၸါဒ္ နားလည္တာနဲ႔ ဒိ႒ိကြာတယ္..(မွန္ပါဘုရား)။
ဝိစိကိစၧာေကာ.....(ကြာပါတယ္ဘုရား) ငါဘယ္ကလာပါ လိမ့္မတုံးဆိုေတာ့ ဘယ့္ႏွယ္ ေျဖၾကမလဲ.....(အဝိဇၨာ သခၤါရက လာပါတယ္ ဘုရား) အဝိဇၨာသခၤါရ ျပဳလုပ္လို႔ ေပၚလာကာ ..... (မွန္ပါ) ဒါျဖင့္ အဲသလို သိလိုက္ျပန္ေတာ့ ဝိစိကိစၧာရွိေသးရဲ႕လား ..(မရွိေတာ့ပါဘုရား)။
ဒါျဖင့္ ဦးသန္းေမာင္ ဝိစိကိစၧာသည္ ပဋိစၥသမုပၸါဒ္ နားလည္တဲ့အတြက္ အသိနဲ႔ မျပဳတ္ေသးဘူးလား .... (ျပဳတ္ပါ တယ္ဘုရား) အဲ ... အသိနဲ႔ ဒိ႒ိ ဝိစိကိစၧာျပဳတ္ေတာ့ စူဠေသာတာပန္ တည္ၿပီ ... (မွန္လွပါဘုရား) ဒိ႒ိဝိစိကိစၧာ ျပဳတ္ေတာ့ .. (စူဠေသာတာပန္ တည္ပါတယ္ ဘုရား)။
စူဠေသာတာပန္ တည္ၿပီးသကာလ ခုနက ေျပာခဲ့တဲ့ လႉလိုက္ေတာ့ ေသာတာပန္အလႉ သြားျဖစ္တယ္.... (မွန္လွပါ ဘုရား)ကဲ... ဘယ္ေလာက္အဖိုးတန္သလဲ... (တန္ပါတယ္ ဘုရား) ဘယ္သူ႔ အလႉျဖစ္သြားမလဲ ........ (ေသာတာပန္ အလႉသြားျဖစ္ပါမယ္ဘုရား)။
ဦးသန္းေမာင္ အေရးတႀကီး ေျပာေနတယ္.. (မွန္ပါ) ခင္ဗ်ားမွာ ကိစၥက လက္ငင္းႀကဳံေနလို႔ .. (မွန္ပါဘုရား) ကဲ ... ဒကာႂကြယ္ ရိပ္မိပလား .. (ရိပ္မိပါၿပီဘုရား) နက္ျဖန္ ဆိုရင္ပဲ ဒီ .. တကာ တကာမေတြက လက္ငင္းႀကဳံမယ္ (မွန္ပါ) ကဲ ..... ဒကာသစ္တို႔ေကာ ..... (ႀကဳံပါမယ္ဘုရား) ႀကဳံလို႔ရွိရင္ျဖင့္ ေၾသာ္ စူဠေသာတာပန္ ျဖစ္ၿပီးမွ လႉရလိမ့္မယ္ ... (မွန္လွပါဘုရား) ျဖစ္ေနၿပီတဲ့၊ တကာတကာမတို႔ အေၾကာင္းတရားကလဲသိၾကား,ျဗဟၼာလား၊ အဝိဇၨာ သခၤါရလား ... (အဝိဇၨာ သခၤါရပါ ဘုရား) အက်ိဳးတရားကလဲ ေယာက္်ား လား, မိန္းမလားတဲ့၊ ခႏၶာငါးပါးလား.....(ခႏၶာငါးပါး ပါဘုရား)။
ေၾသာ္ ...... အေၾကာင္းကလဲ တကာတကာမတို႔ အဝိဇၨာ သခၤါရ၊ အက်ိဳးကလဲ ခႏၶာငါးပါး ဆိုေတာ့ အေၾကာင္းအက်ိဳးပဲ ရွိတယ္ ဆိုတာလဲ ေသခ်ာၿပီ .. (ေသခ်ာပါၿပီဘုရား) ပုဂၢိဳလ္ သတၱဝါ ရွိေသးရဲ႕လား .. (မရွိပါဘုရား) ဘာရွိပါလိမ့္ (အေၾကာင္းအက်ိဳးပဲ ရွိပါတယ္ဘုရား)။ ။
ဒီအေၾကာင္းသည္ကား........လို႔ဆိုလို႔ရွိရင္ အေၾကာင္းက အဝိဇၨာသခၤါး၊ အက်ိဳးကဝိညာဏ္, နာမ္႐ုပ္, သဠာယတန,ဖႆ, ေဝဒနာဆိုေတာ့ ျပဳလုပ္တဲ့ ပုဂၢိဳလ္ေကာ ရွိေသးရဲ႕လား .... (မရွိပါ ဘုရား) ျပဳလုပ္လို႔ ေပၚလာတဲ့ ပုဂၢိဳလ္ေကာ .. (မရွိပါ ဘုရား)။
မရွိေတာ့ ပုဂၢိဳလ္ေပ်ာက္တဲ့ .. (မွန္ပါ) ပုဂၢိဳလ္ေပ်ာက္ ကတည္းကအေၾကာင္းလဲငါ, ဟုတ္ရဲ႕လား (မဟုတ္ပါဘုရား) အက်ိဳးကေတာ့ .. (ငါ, မဟုတ္ပါဘုရား) အဲ ... ဒါျဖင့္ အေၾကာင္း အက်ိဳးမွ်သာ ရွိတယ္လို႔ဆိုတာ မသိဘူးလား ...... (သိပါတယ္ဘုရား)။
အဲ .. ဒကာႂကြယ္ ဒီကဲ့သို႔ သိလိုက္ေတာ့ကို တဲ့၊ အေၾကာင္းအက်ိဳးသာ ရွိပါတယ္၊ ဘယ္သူ ျပဳလုပ္တာမွ မဟုတ္ဘူး ဆိုကတည္းက ဝိစိကိစၧာ ေသၿပီ .. (မွန္ပါဘုရား) အေၾကာင္း ကလဲ ဘာပါလိမ့္ ... (အဝိဇၨာသခၤါရပါဘုရား) အက်ိဳး ရ ထားတာကလဲ .. (ခႏၶာငါးပါးပါဘုရား) ပုဂၢိဳလ္သတၱဝါ ပါေသးလား ... (မပါ, ပါဘုရား) အေၾကာင္းထဲမွာလဲ မပါဘူး .....(မွန္ပါ) အက်ိဳးထဲမွာေကာ .. (မပါ, ပါဘုရား)။
ဒါျဖင့္ တကာတကာမတို႔သိေနၿပီ.....တဲ့၊ ပုဂၢိဳလ္သတၱဝါ ဆိတ္သုဥ္းသြားပါၿပီ.....(မွန္လွပါ) ဘယ္လိုပါလိမ့္..(ပုဂၢိဳလ္ သတၱဝါ ဆိတ္သုဥ္းသြားပါၿပီဘုရား) ပုဂၢိဳလ္သတၱဝါ ဆိတ္သုဥ္း သြားေတာ့ ဒိ႒ိက ျပဳတ္တယ္ ... (မွန္ပါဘုရား) အေၾကာင္း အက်ိဳးသိေတာ့ ဝိစိကိစၧာျပဳတ္တယ္..(မွန္ပါဘုရား) ပုဂၢိဳလ္ သတၱဝါမရွိဘူးဆိုေတာ့ .. (ဒိ႒ိျပဳတ္ပါတယ္ဘုရား) ဘာေသာတာပန္တည္တာလဲ .. (စူဠေသာတာပန္ တည္ပါတယ္ ဘုရား)။
အဲ ... စူဠေသာတာပန္ ျဖစ္သြားေတာ့မွ တကာ တကာမေတြက လႉလိုက္, တန္းလိုက္, ေပးလိုက္, ကမ္းလိုက္ေတာ့ ဘယ္သူက လႉတာတုံးေမးရင္ စူဠေသာတာပန္က လႉတာ (မွန္လွပါ ဘုရား) ရွင္းပလား ... (ရွင္းပါၿပီဘုရား) ဘယ္သူက လႉတာပါလိမ့္ (စူဠေသာတာပန္က လႉတာပါ ဘုရား)။
စူဠေသာတာပန္ဆိုေတာ့ အင္း..... သာမည ပုဂၢိဳလ္လား ...... သစၥာသိတဲ့ ပုဂၢိဳလ္လား ... (သစၥာသိတဲ့ ပုဂၢိဳလ္ပါဘုရား) အင္း ... ဟင္ ... တကာတကာမတို႔ ခႏၶာကိုယ္ႀကီးဟာ ဘာသစၥာတုံး .. (ဒုကၡသစၥာပါဘုရား) သိလုံးကေလး ..... (မဂၢသစၥာပါဘုရား)။
အဲဒီေတာ့ ခႏၶာကိုယ္က ဒုကၡသစၥာ၊ သိလုံးကေလးက မဂၢသစၥာဆိုတာ ကိုယ္ကိုယ္တိုင္ သိေနေတာ့ ဒီဒုကၡဝဋ္ႀကီးကို တပည့္ေတာ္ကိုယ္တိုင္ သိၿပီဆိုေတာ့ မဂ္နဲ႔သိၿပီ ... (မွန္လွပါဘုရား) ဒီဒုကၡဝဋ္မွ ကြၽတ္လိုလို႔ ဒုကၡဝဋ္ကြၽတ္ရာကိုသာ ရည္မွန္း၍ လႉဒါန္းေပးကမ္းပါ၏ ဆိုေတာ့ တကာတကာမတို႔ သစၥာသိၿပီး လႉတာ ... (မွန္လွပါဘုရား) ဒုကၡသစၥာသိၿပီး လႉလိုက္တယ္.. (မွန္ပါဘုရား)။
ဒုကၡသစၥာကိုမလိုခ်င္, မရခ်င္လို႔..... (လႉပါတယ္ဘုရား) လႉလိုက္တဲ့ အခါက်ေတာ့ကို ဒုကၡသစၥာမရေတာ့ နိေရာဓသစၥာပဲ က်ဳပ္တို႔ ရ, ရမယ္ .. (မွန္လွပါ) ရွင္းပလား .. (ရွင္းပါ ၿပီဘုရား)။
ဒါျဖင့္ တကာတကာမတို႔ လႉတတ္ပလား ... (လႉတတ္ ပါၿပီဘုရား)ကဲ... ဒါျဖင့္ နိဂုံးခ်ဳပ္ ေတာ့မယ္၊ တကာတကာမတို႔၊ မသိလို႔ လႉတာဘာသစၥာ......(သမုဒယသစၥာပါဘုရား) သေဘာ က်ပလား .. (က်ပါၿပီ) လႉလို႔ ရတာကေကာ ....(ဒုကၡသစၥာ ပါဘုရား) ရွင္းပလား .. (ရွင္းပါၿပီဘုရား)။
သိလို႔လႉတာ ဘာသစၥာ ... (မဂၢသစၥာပါဘုရား) လႉလို႔ ရတာ ဘာသစၥာ..... (နိေရာဓသစၥာပါ ဘုရား)။
ကိုင္း.. ဒါနသံသရာ ရွည္ေသးသလား၊ မရွည္ေတာ့ဘူး လား .. (မရွည္ပါဘုရား) မသိ, အသိသာ လိုရင္းျဖစ္တယ္ ......(မွန္ပါ) ရွင္းၾကပလား ... (ရွင္းပါၿပီဘုရား)။
ကိုင္း..... ယေန႔နာရီေစ့ၿပီ၊ ေတာ္ၾကဦးစို႔ .....။
